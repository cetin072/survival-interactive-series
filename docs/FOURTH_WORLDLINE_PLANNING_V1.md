## 1. 왜 새 작품을 기획하는가

### 1.1 상위목표

즐겁게 플레이하고 함께 이야기하며, 선택과 경험이 쌓이는 창작 자산을 남기는 것이 목적이다. 자동화 수·기능 수·발행량 자체를 게임의 성공으로 취급하지 않는다. 이 작품에 즉각적인 수익성을 강요하지 않는다.

### 1.2 사용자가 직접 확인한 문제

사용자는 서진우 시즌4에서 장면 전환, 위임, 다른 문제로 이동하는 플레이를 몇 차례 해봤지만 재미가 회복되지 않았다고 말했다. 처음 원했던 것은 문명이 무너지는 강렬한 아포칼립스를 충분히 통과한 뒤의 재건인데, 실제 체감은 재난 체험이 부족한 채 조직 운영·복구·경영으로 일찍 넘어갔다는 것이다.

따라서 현재 판단은 단순한 선택지·템포 보정만으로 같은 작품을 계속 권하는 것이 아니라, 기존 기록은 보존하고 새 작품의 장르 경험부터 공동 기획한다는 것이다. 이는 사용자 체감에 근거한 방향 수정이며 객관적인 인기·완성도 평가나 기존 데이터 삭제 지시가 아니다.

### 1.3 재발시키지 않을 진행

- 사람을 돕거나 좋은 결정을 내렸다는 이유만으로 자동으로 조직 책임자가 되게 하지 않는다.
- 지역의 작은 성공을 세계 전체의 안정화와 혼동해 아포칼립스를 조기에 끝내지 않는다.
- 반대로 성공할 때마다 새 재난으로 준비·관계·자원을 초기화하지 않는다.
- 반복 정산·회의·결재·이미 합의한 실행을 매번 중요한 선택처럼 되묻지 않는다.
- 위키·삽화·지식 글감을 생산하기 위해 본편을 특정 사건으로 유도하지 않는다.

## 2. 확정된 작품·서술 방향

| 항목 | 합의한 방향 |
| --- | --- |
| 전체 흐름 | 일상의 붕괴 → 여러 단계의 큰 재난과 생존 → 급격한 재난 국면 안정 → 옛 문명이 크게 후퇴한 세계에서 재건 |
| 초반 경험 | 강렬한 붕괴 속 탈출·도주·이동·생존. 뉴스 설명만으로 끝내지 않고 실제 장면으로 겪는다. |
| 재난 규모와 성과 | 인간이 막을 수 없는 세계적 재난과 개인의 선택으로 지킬 수 있는 성과를 분리한다. |
| 시간과 시즌 | 초기 충격은 빠르게 오고 후속 붕괴가 이어지는 방향. 분·시간·일 단위를 사건 밀도에 맞춰 조절한다. 시즌을 고정된 달력 길이에 묶지 않는다. |
| 후반 세계 | 현대 물건·시설·책·종자·사람의 지식은 부분적으로 남되 운영 인력·부품·공급망·연결 체계가 크게 상실된 세계를 지향한다. |
| 재건의 보상 | 오늘만 버티는 것에서 반복해서 쓸 수 있는 물건·방법·신뢰·생활로 발전한다. 무엇이든 하나씩 쌓이는 체감이 중요하다. |
| 시점 | 전지적 작가 시점. 주인공 외의 중요한 인물·장소·사회 상황도 비춘다. |
| 스포일러와 공동 창작 | 세계의 큰 흐름은 함께 알고 정해도 된다. 비밀 유지 자체보다 함께 만드는 재미를 우선한다. |
| 역할 분담 | 사용자는 방향·중요한 행동·위험 감수·주요 관계 결정을 맡는다. GM은 전문지식 확인·관찰 단서·구체적 실행·다중 시점 연출을 맡는다. |
| 유머 | 억지 유머를 자주 넣지 않는다. 인물과 상황에서 자연스럽게 생기는 분위기는 허용한다. |
| 시작 승인 | 세계관·주인공·초기 조건을 충분히 토론하고 별도 시작 의사를 확인하기 전에는 장면을 진행하지 않는다. |

시즌1~2의 본격적인 붕괴와 시즌3~4 무렵의 재건은 **희망하는 구조**이지 정확한 시즌 종료 시점이나 사건 순서를 확정한 시간표가 아니다.

전지적 서술은 주인공의 중요한 선택을 GM이 대신 확정하는 권한이 아니다. 독자가 아는 사실과 장면 속 인물이 알고 있는 사실도 구분한다.

## 3. 숙련과 생존 디테일

사용자가 좋아한 참고 감각은 《고블린 슬레이어》에서 느낀 ‘무엇을 관찰하고 왜 그 방법을 쓰는지 납득되는 전문적인 해결 과정’이다. 그 작품의 캐릭터·장면·잔혹한 소재를 복제하라는 뜻이 아니다.

- 핵심 흐름: 문제 발견 → 조건 관찰 → 지식과 경험으로 궁리 → 실행 → 통하거나 실패한 이유가 드러남.
- ‘그는 전문가였다’고 선언하기보다 전문가가 무엇을 먼저 보고 무엇을 하지 않는지 행동으로 보여준다.
- 자격증이나 직업 하나로 모든 분야에 능숙해지지 않는다. 자기 분야의 숙련과 재난 생존 경험을 구분한다.
- GM이 검색해 알게 된 사실을 주인공이 자동으로 아는 것으로 처리하지 않는다. 직업·동료·책·설명서·관찰·경험 등 지식의 경로를 갖춘다.
- 플레이어가 실제 전문지식을 모른다고 주인공의 직업적 지식을 사용할 수 없게 하지 않는다.
- 남은 물건을 찾기 → 상태 확인 → 수리·재사용·조합 → 유지 가능한 사용 → 필요할 때 직접 제작하는 순서를 우선 검토한다.
- 쓸 수 있는 현대 물건이 남아 있는데 분위기를 위해 매번 원시적인 방법부터 강제하지 않는다.
- 특이한 비법보다 원리·조건·한계·실패 비용이 납득되는 방법을 사용한다. 위험한 어로·독성 식물·전기·식수 등 현실 기술은 근거를 확인하기 전 생존 지식으로 보증하지 않는다. 해당 발언은 소재 예시이지 채택된 방법이나 실행 지침이 아니다.
- 익힌 방법은 더 자연스럽고 적은 수고로 사용하는 모습으로 성장시킨다. 해결된 반복 작업은 새로운 조건이 없다면 압축한다.
- 침묵·휴식·관계 장면도 둔다. 모든 장면을 기술 설명이나 새 위기로 채우지 않는다.

## 4. 주인공과 출발 조건

### 확정

- 성인 남성, 미혼, 자녀 없음, 현재 연인 없음.
- 자기 직업·분야에는 숙련이 있으나 아포칼립스는 처음이며 생존 경험을 쌓아 노련해진다.
- 의료계 직업은 제외한다. 현장직·사무직·군인·군 경력·어느 정도의 야외 경험 등 다른 후보는 열어둔다.
- 배경은 주인공에게 익숙한 한국 생활권이다. 정확한 도시·동네는 미정이다.
- 재난 전 평소의 일상은 한두 장면 정도 보여주는 방향이다.
- 초기 자원은 직장·집·이동 중 소지품 등 실제 시작 위치에 자연스럽게 있을 법한 범위에서 결정한다.
- 초반부터 보호 대상과 완성된 파티가 주어진 출발보다는, 고난과 협력을 거치며 소중한 관계가 생기는 출발을 선택했다.

### 미정 및 오해 방지

- 이름·나이·구체 직업·보직·경력·신체 조건·취미·성격의 세부는 아직 확정하지 않았다.
- 부모·형제의 존재, 관계, 위치, 생사, 재난 초기 연락 상태는 미정이다. 미혼이라는 이유로 가족이 전혀 없거나 고아인 인물로 만들지 않는다.
- 집에서 시작할지, 직장이나 이동 중 시작할지 미정이다. 집의 존속·접근성·귀가 가능성은 재난과 위치를 정한 후 판단한다.
- ‘현장형 직업’은 GM의 추천이지 채택된 직업이 아니다. 별도 배경 없이 만능 기술자·군사 전문가로 만들지 않는다.

## 5. 동료·인물·연애

### 동료와 사회

- 초반에는 소수로 움직인다. 얼굴·업무 정도만 아는 느슨한 관계가 적합하며 너무 친한 고정 파티로 시작하지 않는다.
- 첫 인물이 끝까지 함께할 필요는 없다. 목적지·이해관계 차이로 헤어지고, 이후 재회할 수 있다.
- 포스트 아포칼립스의 규모 확장은 실제 선택과 분위기에 따른다. 초반부터 길드·회사·대규모 공동체 운영을 자동 목표로 삼지 않는다.
- 동료의 장점·약점·버릇을 명확하게 준비하고 각자의 목적과 경계를 둔다. 역할 빈칸을 채우는 부품이나 자동 추종자로 만들지 않는다.
- 방식의 충돌, 사정을 숨긴 협력, 이해관계에 따른 동행·이탈 모두 가능하다. 의견 차이·독립적인 선택을 곧바로 배신으로 취급하지 않는다.
- 신뢰에는 시간이 들되, 충분히 쌓은 신뢰는 실제 안정으로 남긴다. 긴장 유지용 의무 배신은 배치하지 않는다.
- 돕고 싶지만 여력이 없는 사람과 자기 생존을 우선하는 사람, 위험한 사람 등이 함께 있는 사회를 지향한다. 선악을 정확한 인원 비율로 배치한다는 뜻은 아니다.

### 연애의 작품 방향

- 성인 등장인물 사이의 복수 히로인 관계가 가능하다. 단독 최종 히로인을 강제하지 않는 구도를 선호한다.
- 감정·연애·친밀한 관계가 실제로 발전할 수 있으며, 상호 합의 아래 비독점적인 관계도 가능하다.
- 히로인마다 성격·독립적 목적·관계가 깊어지는 계기를 다르게 둔다. 구조나 도움을 곧바로 호감·복종·관계의 대가로 환산하지 않는다.
- 특정 히로인·확정 연애·이별·결말은 아직 없다. 주요 관계 선택은 사용자와 인물의 실제 상호작용을 통해 형성한다.

## 6. 고난·실패·보상

- 부상·죽음·장비와 기회 상실·동료 이별·오래 남는 신체적 변화 등을 이야기의 가능성으로 허용한다.
- 다만 ‘가능’은 특정 인물이 반드시 죽거나 일정량의 손실을 강제한다는 뜻이 아니다.
- 좋은 판단과 준비로 지킬 수 있었던 것은 지킨다. 재난 규모와 개인의 생존 성과를 분리한다.
- 주인공이 대재난을 통과한 뒤 재건에 이르는 것이 원하는 큰 흐름이다. 구체적인 게임오버·재시도·영구 사망 규칙은 별도로 정하지 않았다.
- 재난의 강도와 묘사의 자극성은 별개다. ‘한계를 두지 않음’이라는 창작 취지를 모든 자극적 소재나 상세 묘사의 자동 승인으로 확대하지 않는다.

| 주된 원인 | 대규모 소행성 충돌 | 잠정 채택 |
| 충돌 지역 | 몽골 남부 고비사막 | 잠정 채택; 정확한 좌표·지질 미정 |
| 천체 규모 | 지름 약 2km를 검토 기준으로 사용 | 잠정 기준; 재검증·조정 가능 |
| 한국의 경로 | 초기 영향과 혼란 이후 대기·생활 기반·식량·기후 위기가 단계적으로 심해지는 흐름 | 희망하는 서사; 구체적 피해 검증 필요 |
| 이후 | 큰 재난이 약해져도 문명은 크게 후퇴하고, 남은 물건과 지식으로 재건 | 작품의 지향점; 실제 붕괴 정도는 시나리오 가정 |
| 판타지 요소 | 충분히 매력적인 하나의 큰 가정은 검토 가능 | 아직 채택 없음; 운석 속 생명체·물질·능력 부여 등 미확정 |

핵전쟁·급격한 침수 등의 대안도 논의했으나 현재 우선 후보는 충돌이다. 특정 운석 성분, 구성 밀도, 속도, 입사각, 충돌일, 한국 출발 지역은 확정하지 않았다.

### 7.2 확정된 선택: ③ 절충형 사전 인지

과학계·관계기관이 먼저 위험을 발견해 분석·대응하지만, 일반 시민에게 정확한 충돌 위험이 알려지는 것은 충돌이 임박했을 때이다.

- 사용자가 선택한 것은 이 **방식**이다.
- 과학계가 수주~수개월 전에 발견한다는 수치, 수일 전에 위험이 확정된다는 일정, 대중 경고가 정확히 하루 전이라는 주장은 GM의 제안이었다. 확정 시간표가 아니다.
- 조직적 은폐·음모가 원인이라는 설정도 채택하지 않았다. 관측 불확실성·판정 과정·공지 과정 등 실제 이유는 미정이다.
- 전지적 시점으로 관측·분석·대응 현장을 보여줄 수 있다. 주인공이 그 정보를 모두 미리 안다는 뜻은 아니다.

### 7.3 대화에 나온 수치: 재검증 전 사용 금지

이 표는 앞선 발언을 잊거나 확정 설정으로 오인하지 않기 위한 **미검증 추정 보관**이다. 이번 기록 작업에서 과학 검증·계산·출처 확인을 새로 수행하지 않았다.

| 앞선 대화의 개략치 | 현재 취급 |
| --- | --- |
| 서울 약 1,800km, 부산·김해 약 2,100km | 임의 후보 지점에 대한 개략 거리. 정확한 좌표 없이 확정하지 않음. 주인공의 도시를 지정한 것도 아님. |
| 지진파 약 4~8분 | 개략 도달 시간 주장. 파동 종류·거리·모형 확인 필요. 체감·피해 강도를 의미하지 않음. |
| 대기 압력파 약 1.5~2시간 | 개략 시간 주장. 전파 경로·대기·고도와 강도 확인 필요. 건물 붕괴 보장이 아님. |
| 먼지 약 1~3일 | 일반 황사 이동과의 유추가 섞인 후보치. 충돌 먼지의 고도·입도·풍장에 그대로 적용할 수 없음. |
| 수일~수주 공급망 혼란, 수주~수개월 환경·식량 위기 | 작품 시간표 후보이지 한국·전 세계의 붕괴 시점을 예측한 확정 사실이 아님. |
| 수개월~수년 뒤 안정화·재건 | 기후·먼지·식량·사회 조건 검증 필요. 세계 모든 지역이 같은 시점에 멸망·회복한다는 의미가 아님. |

검증할 핵심: 크기·밀도·속도·입사각, 충돌 좌표·표적 지질, 한국까지 각 영향의 **도착 시간과 피해 강도**, 대기 물질·기후·광합성 영향, 식량·에너지·물류의 버팀 여력, 생존 가능한 지역과 잔재, 발견과 경고의 개연성.

2km급 몽골 충돌이면 한국 도시가 즉시 붕괴하거나 전 세계 국가가 반드시 소멸한다는 인과는 아직 입증하지 않았다. 원하는 물리적 체험이 성립하지 않으면 지점·규모·첫 현장의 조건을 공동 조정한다. 다른 지역의 파괴를 전지적 카메라로 보여주되 주인공의 직접 생존 체험을 모두 뉴스로 대체하지 않는다.

## 9. 남은 결정과 다음 대화

우선 다음 후보를 비교하되 이미 선택한 사항은 다시 묻지 않는다.

1. **주인공 직업·나이:** 의료계를 제외하고 5~7개 후보의 관찰 방식·손기술·한계·성장 장면을 비교한다. 직업을 고르기 위해 실제 재난 장면을 진행하지 않는다.
2. **부모 등 기존 가족관계:** 존재·거리·재난 초기 정보 상태, 가족 구출이 서사를 독점하지 않도록 어떤 관계를 원하는지 논의한다.
3. **한국의 정확한 출발 무대·첫날 위치·집의 접근성·초기 자원:** 충돌 피해 검증과 서로 맞춰 정한다.
4. **충돌 조건과 첫 충격의 직접성:** 희망 장면을 과학적 가능성과 분리해 검토하고 필요할 때 후보를 수정한다.
5. **첫 동행자의 조합과 주요 NPC 성격:** 초기에는 약한 인연·소수 동행이라는 방향 안에서 구체화한다. 최종 파티·히로인·이별·배신을 미리 강제하지 않는다.
6. **후기 환경과 재건의 첫 성과:** 기술·물건·관계·주거 중 어떤 작은 축적을 먼저 경험할지 정한다.
