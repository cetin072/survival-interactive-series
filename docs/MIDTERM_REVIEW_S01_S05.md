# S01–S05 중간점검 — 생존 인터랙티브 프로젝트

작성 시점: S05 첫 플레이 종료 후
목적: 시즌 1~5의 실제 플레이를 기준으로 재미, 시스템, 반복 문제, Runtime 구조, 다음 단계의 우선순위를 재정의한다.

---

## 1. 총평
프로젝트의 핵심 아이디어는 유효하다.

5개 시즌을 거치며 작품 정체성은 다음으로 수렴했다.

> 현대 한국형 가족 생존 MUD
> = 가족 운영 + 두 거점의 장기 성장 + 이해관계 기반 협업 + 플레이어와 독립적으로 움직이는 재난세계

조작은 숫자 선택, 순차 복수선택, 가족 역할분담, 자유행동으로 단순하게 유지한다.

현재 가장 큰 문제는 시스템 부족이 아니다.
이미 필요한 시스템은 대부분 존재한다.

현재 핵심 병목은:
- 합리적인 대응이 너무 자주 모든 목표를 동시에 지키게 함
- 복수선택의 실제 기회비용 적용이 약함
- 강해진 외곽거점 때문에 비슷한 재난축의 난이도가 크게 낮아짐
- 장기 시즌에서 Phase 이름은 변해도 플레이 행동 종류가 반복되는 경우가 있음
- 가족이 역할은 수행하지만 먼저 행동·제안하는 자율성이 아직 약함
- 메인 재난이 끝난 뒤 후속 이슈를 같은 시즌에 오래 붙이는 경향

따라서 다음 단계는 **새 시스템 추가보다 현재 규칙의 실행 강도와 콘텐츠 다양성 개선**이다.

---

## 2. 시즌별 핵심 평가

### S01 — 불길
역할: 첫 유효 본편형 프로토타입.

강점:
- 재난 재확산과 2차 위험
- 가족 분산/합류
- 도심/외곽 거점 가치 변화
- 가족 의견 차이
- 정상사회 의무
- 재난 자체의 강한 박동

약점:
- 후반 `확인 / 대기 / 이동` 패턴 반복
- 선택 비용과 장기 회수가 아직 약함

판정:
**재난 드라마의 박동을 가장 선명하게 보여준 초기 기준점.**

### S02 — 단절
역할: 장기 운영과 거점 성장 시스템 발견.

강점:
- 창고, 물, 전력, 텃밭, 공구, 보수 등 거점 능력 성장
- 최씨 가구와 이해관계 기반 제한적 협업
- 도심/외곽 2거점 체계 확립

약점:
- 많이 루즈함
- 외생 압력 부족
- 정비·구매·비축 최적화 반복
- 좋은 준비가 메인 문제까지 제거
- 장기 Phase 상승 부족

판정:
**게임 재미는 실패했지만 장기 시스템 발견에는 크게 성공.**

### S03 — BLACKOUT
역할: S02의 압력 부족을 보완하고 확장 네트워크 가능성 검증.

강점:
- 물이 해결되면 연료, 회사, 의료, 외부인, 공공지원 등으로 압력 이동
- 준비가 사건을 지우지 않고 피해 감소와 선택권 증가로 작동
- 최씨 협업 고도화
- 가족 → 두 가구 → 마을 → 지역사회로 확장 가능한 구조 발견
- 정상사회 의무와 장기재난의 결합

약점:
- 마을 확장 과정에서 가족 4인 레이어의 존재감 약화
- 반복 실무 AUTO가 중반까지 충분히 강하지 않았음
- 자원 상태의 판단 가독성 부족

판정:
**장기재난 시스템의 가장 큰 발전 시즌.**

### S04 — 해협
역할: 전쟁·공급망·경제 압력 속 정상사회 지속성 검증.

강점:
- 회사, 병원, 학교, 정부가 사라지지 않고 형태를 바꾸며 적응
- 소득, 근무일, 가격, 공급망이 실제 플레이 압력으로 작동
- 가족 역할분화 개선
- Anchor 인물을 통한 기관 세계의 인간적 전달
- AUTO와 MUD Text Visual Grammar 개선

약점:
- `회사 → 병원 → 학교 → 외곽 → 뉴스 → 선택` 장면 틀 반복
- 복수선택이 너무 자주 모두 성공
- 전쟁 규모에 비해 강한 외생 Beat 부족
- 기관 권한 경계 오류 사례
- 저장과 상태 관리가 한때 과도함

판정:
**현실 세계 시뮬레이션은 크게 발전했지만 생존게임의 박동은 약해짐.**

### S05 — 신호가 끊긴 날
역할: Runtime v2~v3, TURN STATE GATE, AUTO, MUD UI 실전 정착.

강점:
- 가족 위치·동행 정합성 개선
- MUD Text Visual Grammar 본편 정착
- 반복 운영 AUTO 압축
- 정상사회 복귀 자체가 새로운 압력으로 작동
- 이장/최씨/플레이어 사이 소유권·위임 경계 안정

약점:
- `문제 → 조사 → 합리적 해결`이 너무 매끄럽게 반복
- 공용 관정 등 의미 있는 문제가 한 번의 정답으로 빠르게 소멸
- 강한 외곽거점 때문에 NORMAL 체감 난이도 하락
- 복수선택 비용이 여전히 약함
- 가족 자율제안 부족
- 메인 기반시설 장애 종료 뒤 보안 이슈까지 붙어 시즌 길이 과다

판정:
**운영 안정성은 최고 수준이지만 재미 압력은 다시 낮아짐.**

## 3. 확실히 유지할 것

### 3.1 쉬운 조작
불변 원칙:
`복잡한 세계를 단순한 입력으로 다룬다.`

유지:
- 숫자 단일선택
- `3 → 5 → 1` 순차 복수선택
- 필요 시 가족 역할분담
- 자유행동 자연어

입력 UX는 현재 프로젝트의 강점이다.
문제는 복수선택 허용 자체가 아니라 **기회비용 집행 강도**다.

### 3.2 두 거점 성장
외곽거점 성장과 도심의 정상사회 접근성은 장기 플레이 핵심 보상이다.
기존 능력을 난이도 조절 목적으로 임의 무효화하지 않는다.

거점 유지 노동은 AUTO,
새로운 능력·큰 트레이드오프만 직접 플레이한다.

### 3.3 최씨 협업과 확장 네트워크
협력과 공동소유를 분리한다.

장기 확장 구조:
`가족 핵심 파티 → 최씨 등 핵심 파트너 → 필요 시 마을/지역사회 네트워크`

확장 네트워크가 커져도 가족 4인은 감정·위험·개인 이해관계의 핵심 파티로 남는다.

### 3.4 정상사회 지속
국가·사회가 실제로 붕괴하지 않았다면 회사·학교·병원·행정·경제는 계속 작동하거나 형태를 바꾼다.

이 요소는 작품의 차별점이다.

### 3.5 MUD UI + AUTO
본편의 기본 시각층은 텍스트 기반 MUD UI다.
필요한 상태만 표시하고 전체 HUD를 반복하지 않는다.
반복 일상은 AUTO와 시간압축으로 넘긴다.

## 4. 반복 문제의 뿌리

### 4.1 기반시설 계열 과다
S02, S03, S05가 전력·통신·단수·연료·물류 축에서 상당히 겹쳤다.
그 결과 플레이어 전략도:
`정보확인 → 물/연료 확보 → 가족 합류 → 외곽거점 활용`
으로 수렴했다.

다음 시즌군에서는 같은 압력축을 연속 반복하지 않는다.

### 4.2 가족 합류 → 외곽 이동의 강한 중력
가족 위치 분산은 좋은 시스템이지만 매 시즌 같은 첫 퀘스트로 사용하지 않는다.
외곽거점이 강해진 만큼 `외곽에 가면 해결되는 재난`을 반복하지 않는다.

해결책은 거점 무효화가 아니라 **거점이 답하지 못하는 새 압력축**이다.

### 4.3 실제 비용 부족
플레이어가 잘하는 것은 문제가 아니다.
NORMAL에서 좋은 플레이는 가족 생존 가능성을 높여야 한다.

그러나 다음은 매번 모두 지켜지지 않아도 된다.
- 가족 시간
- 직장/소득
- 현금
- 차량
- 거점
- 자원
- 외부 책임
- 관계
- 기회

핵심:
**강제 실패가 아니라 강제 비용.**

### 4.4 Phase 변화가 장면 변화로 이어지지 않음
Phase가 바뀌면 플레이 동사도 바뀌어야 한다.

예:
- 초기: 확인 / 이동 / 확보
- 중기: 배분 / 협상 / 역할전환
- 장기: 생활·소득·거점 재편
- 최고조: 둘 이상의 가치가 동시에 충돌하며 일부 포기

### 4.5 가족 자율성 부족
가족은 플레이어 명령을 잘 수행하는 부하가 아니다.
필요하면:
- 플레이어가 못 본 문제를 발견
- 스스로 처리
- 역할 변경 제안
- 중요한 순간 다른 우선순위 제시

를 할 수 있어야 한다.
갈등 빈도 자체를 높이지 않는다.

### 4.6 시즌 종료가 늦음
메인 압력이 새로운 안정상태에 도달하면 시즌 종료를 먼저 검토한다.
결이 다른 후속 사건은 에필로그, 미니 에피소드, 다음 시즌 후보로 분리한다.

## 5. 현재 프로젝트 성숙도

### 강한 영역
- 작품 정체성
- MUD 조작 UX
- 두 거점 장기 성장
- 이해관계 기반 협업
- 정상사회 현실성
- 장기 Canon 누적
- TURN STATE 정합성
- AUTO와 경량 MUD UI

### 아직 약한 영역
- 선택 기회비용의 실제 집행
- 가족 자율 시작 행동
- 시즌별 행동군 다양성
- 결정 최고조의 강도
- 외부 플레이어 블라인드 재현성

### 제품화 판단
대형 앱/게임엔진 개발은 아직 보류한다.
현재 핵심 병목은 코드가 아니라 게임 박동과 선택비용이다.

다만 ChatGPT GM을 그대로 두고:
- Scene Header
- 가족/관련 자원 상태
- 선택 버튼
- AUTO/Phase 표시
정도만 가진 **얇은 MUD UI 프로토타입**은 향후 검토 가능하다.

## 6. S06 이후 우선순위

### P0 — 시스템 다이어트
새 규칙을 추가하지 말고 Runtime Kernel을 압축한다.
실제 플레이에서 반드시 필요한 하드 규칙만 상시 유지하고 상세 규칙은 on-demand 모듈로 둔다.

### P1 — Decision Collision
중요 장면은 `무엇을 할까?`보다 `무엇을 우선하고 무엇을 포기할까?`가 되도록 한다.
복수선택의 뒤 행동이 실제로 지연·부분성공·기회상실될 수 있어야 한다.

### P2 — 콘텐츠 다양성
다음 시즌은 전력·통신·단수 중심 기반시설 장애를 주축으로 삼지 않는다.
가족 분산 → 합류 → 물자확보 → 외곽 이동을 기본 오프닝으로 반복하지 않는다.

### P3 — 가족 자율성 테스트
한 시즌에서 가족 2명 이상이 플레이어의 명령 이전에 의미 있는 문제를 발견하거나 행동/역할 변경을 제안하는 사례를 자연스럽게 만든다.

### P4 — Phase별 플레이 동사 변경
각 Phase가 다른 종류의 선택을 요구하도록 한다.

### P5 — 시즌 종료 절제
메인 압력이 끝났다면 새 문제를 억지로 붙이지 않는다.

### P6 — 외부 블라인드 플레이
S06 또는 S07 이후 규칙을 모르는 외부 플레이어 1회 이상으로:
- 설명 없이 조작 가능한가
- 선택이 실제로 고민되는가
- 가족/거점/세계가 이해되는가
- 공동설계자 아닌 사람에게도 재미있는가
를 검증한다.

## 7. 현재 목표형
5개 시즌의 가장 좋은 요소를 결합한다.

> S01의 재난 박동
> + S02의 거점 성장
> + S03의 외생압력·협업 확장
> + S04의 정상사회 현실성
> + S05의 Runtime·AUTO·MUD UI

새로운 시스템을 더 만드는 것이 아니라 **이 다섯 요소를 한 시즌 안에서 더 비싼 선택과 빠른 장면밀도로 함께 작동시키는 것**이 다음 목표다.

## 8. 장기 질문의 변화
초기 질문:
`어떻게 안전해질까?`

현재 질문:
`안전할 능력은 생겼다. 동시에 모든 것을 지킬 수 없다면 무엇을 지킬 것인가?`

이 변화가 프로젝트를 단순 재난대응 시뮬레이션에서 장기 가족 생존게임으로 발전시키는 핵심이다.
