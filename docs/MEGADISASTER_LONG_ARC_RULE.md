# Mega-Disaster Long Arc Rule — 초재난 장기 아크 규칙

## 목적
S02 이후에는 단일 재난을 한 번 넘기고 완전히 정상화되는 구조만 반복하지 않는다.

새 방향은 `초재난 장기 아크`다.
하나의 거대한 위기 또는 연쇄적 시스템 충격이 여러 주·여러 달에 걸쳐 가족의 생활 기반을 계속 바꾸는 장기 생존 드라마를 만든다.

단, 시작부터 무법·완전붕괴 상태로 점프하지 않는다.

핵심:
`정상사회 → 부분 마비 → 장기 압박 → 생활체계 재편 → 새로운 안정상태`

## 절대 원칙
- 초재난은 곧바로 국가 소멸이나 무법상태를 뜻하지 않는다.
- 전력·수도·통신·물류·행정·의료·치안·금융은 서로 다른 속도로 약화·복구·재악화할 수 있다.
- 지역별 상태가 다를 수 있다.
- 일부 사회 기능은 오래 유지될 수 있다.
- 회복 가능성을 항상 열어둔다. 아포칼립스 결말을 강제하지 않는다.
- 플레이어 선택 때문에 세계가 소급해서 더 나빠지거나 좋아지지 않는다.

## 장기 단계 모델
정확한 기간은 시즌마다 달라질 수 있다.

### Phase 0 — 평범한 생활
재난 전 일상.
직장·학교·가족 일정·돈·차량·주거가 정상적으로 작동한다.

### Phase 1 — 급성 충격
대략 수시간~72시간 범위.
주요 목표는 즉시 안전, 가족 위치 확인, 정보 확인, 단기 거점과 이동 판단이다.

### Phase 2 — 부분 마비
대략 며칠~2주 범위.
일부 인프라는 복구되고 일부는 악화될 수 있다.
직장·학교·행정·물류·연료·통신 문제가 동시에 게임에 영향을 준다.

### Phase 3 — 장기 압박
대략 수주 범위.
단순 대피보다 다음 문제가 중요해진다.
- 물자 재보충
- 소득과 실제 지출
- 차량과 연료
- 약과 의료 접근성
- 거점 유지비용
- 가족 피로·불만·역할 충돌
- 정보 신뢰도
- 지역 이동 가능성

### Phase 4 — 생활체계 재편
대략 수개월 범위까지 확장 가능.
가족은 이전 생활을 그대로 유지할지, 거점을 바꿀지, 일을 조정할지, 가족 역할을 재편할지 결정하게 된다.

### Phase 5 — 새로운 안정상태
완전한 원상복구일 수도 있고, 부분적으로 바뀐 새로운 일상일 수도 있다.
이 단계 도달이 장기 아크의 가능한 종료조건 중 하나다.

## 시즌과 장기 아크의 관계
한 시즌이 초재난 전체를 모두 해결할 필요는 없다.

예:
- S02: 초재난의 시작과 첫 생활 변화
- S03: 장기 압박이 본격화된 이후의 새로운 문제
- S04: 거점·가족·경제 구조가 바뀐 뒤의 다음 국면

단, S03·S04 줄거리를 미리 쓰지 않는다.
각 시즌 종료 상태가 다음 시즌의 실제 시작 세계를 만든다.

즉:
`시즌 종료 = 세계 리셋`이 아니다.

## 지속 상태
장기 아크에서는 다음이 시즌을 넘어 누적될 수 있다.
- 가족의 건강·피로·신뢰·갈등
- 거점 상태
- 차량 상태
- 비축품과 소모품
- 경제적 손실과 지출
- 직장·학교 상태
- 지역별 인프라
- 신뢰할 수 있는 사람/NPC 관계
- 이전 선택에서 생긴 장기 결과

## 정상사회 지속 규칙과의 관계
`Normal Society Continuity Rule`은 초재난 초중반에도 유지된다.

사회 기능이 약해질수록 해당 의무가 사라지는 것이 아니라 형태가 변할 수 있다.
예:
- 정상 출근 → 재택/휴업/임시근무 → 소득 불확실성
- 정상 등교 → 휴교/원격/임시교육
- 정상 소비 → 재고 부족/가격 상승/구입 제한
- 정상 거주 → 임시거주/거점 이동/복구 비용

## 게임 난이도
초재난 장기전의 난이도는 사건 숫자가 아니라 `누적되는 선택 비용`에서 나온다.

강화 요소:
- 지금 살리면 나중 자원이 줄어드는 선택
- 가족 구성원별 우선순위 충돌
- 단기 안전과 장기 기반 사이의 충돌
- 현금/연료/시간/체력의 기회비용
- 불완전한 정보로 내리는 장기 결정
- 되돌리기 어려운 거점·직장·이동 선택
- 며칠 또는 몇 주 뒤 돌아오는 결과

## 플레이 템포
장기전이라고 하루를 매시간 플레이하지 않는다.

- 중요한 위기와 결정: 장면 단위로 플레이
- 의미 없는 안정기간: 몇 시간~며칠 압축
- 생활 변화가 누적될 때: 짧은 몽타주/요약 후 다음 중요한 장면

장기 아크의 목적은 느린 시뮬레이션이 아니라 `시간이 흐를수록 선택의 무게가 커지는 드라마`다.

## 숨은 월드 시드
S02 플레이 직전 GM은 초재난의 실제 원인/범위/회복 가능성/지역별 상태/시간 흐름을 비공개로 시드한다.

플레이어에게는 관찰 가능한 정보만 공개한다.

GM은 미리 다음을 정할 수 있다.
- 어떤 시스템이 얼마나 버틸 수 있는지
- 어느 지역이 먼저 영향을 받는지
- 어떤 문제가 복구되고 어떤 문제가 오래 남는지
- 일부 장기 전환 조건

하지만 다음은 미리 고정하지 않는다.
- 플레이어의 거점 선택
- 가족의 최종 이동
- 확정 시즌 결말
- 장기 아크 최종 결말

## 설계 목표
S01의 질문이 `어디가 더 안전한가?`였다면,
초재난 장기 아크의 질문은 점차 다음으로 이동한다.

`무엇을 지키고, 무엇을 포기하고, 어떤 삶을 계속 유지할 것인가?`
