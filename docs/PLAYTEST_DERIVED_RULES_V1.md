# Playtest-Derived Rules v1

실제 플레이테스트에서 발견되어 전 시즌 공통 규칙으로 승격된 항목을 관리한다.

## 1. Player Known Information Rule
플레이어가 현실적으로 이미 알고 있을 정보는 첫 의미 있는 선택 전에 공개한다.

예:
- 가족 구성원의 현재 위치 또는 마지막 확인 위치
- 가족의 평소 거주 형태
- 자기 집·차량·평소 비축품의 기본 상태
- 다른 가족 거점의 위치와 기본 특성

플레이어가 당연히 알고 있었을 사실을 선택 후에 공개해 이전 선택의 의미를 바꾸는 것을 금지한다.
상세 기준은 `core/FAMILY_RESIDENCE_AND_START_INFO.md`를 따른다.

## 2. Multi-Base Rule
거점은 재난 종류와 시간에 따라 가치가 달라져야 한다.

- 절대적인 최강 거점을 만들지 않는다.
- 도심 거점, 외곽 거점, 친척집, 대피소, 숙박시설 등은 서로 다른 장단점을 가진다.
- 산불에서 유리한 거점이 홍수·폭설·의료응급 상황에서는 불리할 수 있다.
- 같은 거점도 시간 경과, 도로, 전력, 물, 의료 접근성, 행정 통제에 따라 가치가 바뀐다.

## 3. Normal Society Continuity Rule
국가기능 붕괴 수준이 아니라면 직장·학교·행정·경제·주거·생활복구는 계속 작동한다.

재난이 발생했다고 플레이어의 평범한 인생이 사라지는 것은 아니다.
Standard 계열 난이도에서는 `가족 안전 + 정상생활 유지`가 동시에 압박으로 작동한다.
상세 기준은 `docs/NORMAL_SOCIETY_CONTINUITY_RULE.md`를 따른다.

## 4. Risk Exposure Rule
위험한 선택은 실패를 확정하지 않는다.

잘못된 구조:
`위험한 선택 → 반드시 사고`

권장 구조:
`위험한 선택 → 위험 노출 증가 → 환경 + 준비 + 이전 선택 + 숨은 상태 + 불확실성에 따라 결과 결정`

따라서 같은 위험 선택에서도 다음처럼 여러 결과가 가능하다.
- 문제 없이 통과
- 경미한 지연
- 작은 장애물
- 자원·차량 손실
- 경로 폐쇄
- 심각한 위험

GM은 플레이어가 위험을 감수했다는 이유만으로 서사적 처벌을 만들어서는 안 된다.

## 5. Player Intentional Stress-Test Tag
플레이어가 게임 시스템의 위험도·공정성·결과 범위를 검증하기 위해 의도적으로 위험한 행동을 선택할 수 있다.

이 경우 해당 선택은 일반적인 판단 실수와 구분해 기록한다.

권장 태그:
`[STRESS_TEST]`

복기 시:
- 생존 관점에서는 실제 위험성을 평가할 수 있다.
- 게임 시스템 관점에서는 `의도적 위험도 검증`으로 별도 해석한다.
- 이를 단순한 플레이어 판단 실패로 기록하지 않는다.

## 6. Post-Disaster Secondary Hazard Rule
주요 재난이 약화되거나 종료되어도 2차 위험이 발생할 수 있다.

예:
- 산불 후 호우 → 토사 유출·산사태
- 지진 후 여진·화재·단수
- 홍수 후 오염·도로 붕괴
- 폭설 후 결빙·고립

2차 위험은 억지로 시즌을 늘리기 위한 장치가 아니라 실제 세계 상태와 재난 특성에서 자연스럽게 파생되어야 한다.

시즌 종료 조건은 `주요 재난이 끝남`이 아니라 가족과 세계가 새로운 안정 상태에 도달했는지로 판단한다.

## 7. Season Dual Review Rule
시즌 종료 후 복기는 반드시 두 층으로 분리한다.

### A. 플레이어 생존 복기
현실 생존 관점에서:
- 좋은 판단
- 위험했던 판단
- 놓친 요소
- 실제 상황에서 개선할 점

### B. 게임 시스템 복기
게임 제작 관점에서:
- 재미
- 몰입
- 난이도
- 선택 다양성
- 선택 비용
- 위험도 작동 방식
- 가족 AI
- 정보 불확실성
- 장기 인과관계
- 반복성
- 개선사항

`[STRESS_TEST]` 선택은 반드시 B에서 별도 해석한다.

## 8. Decision Cost over Event Count
난이도 상승은 단순한 사건 수 증가로 만들지 않는다.

우선 강화할 것:
- 한 선택으로 다른 가치나 기회를 포기해야 함
- 결정 시간이 짧음
- 가족 요구가 충돌함
- 정보가 불완전함
- 자원이 제한됨
- 이전 결정이 몇 시간·며칠 뒤 돌아옴
- 일부 선택은 되돌릴 수 없음

핵심 목표:
`안전한 선택지를 찾는 게임`에서 `무엇을 지키고 무엇을 포기할지 결정하는 생존게임`으로 발전한다.

## 9. Exogenous World Pressure Rule
대규모 장기재난에서는 플레이어의 행동과 독립적인 세계 압력이 반드시 존재한다.

Hidden World Seed에 플레이어가 직접 제거할 수 없는 외생 압력 3~5개를 사전 설정한다.

예:
- 인프라 복구 실패/재악화
- 물류·연료 공급 제한
- 금융·결제 문제
- 의료 접근성 악화
- 행정 정책 변화
- 기상 2차 충격
- 직장·학교·가족 외부 의무

플레이어의 좋은 대응 때문에 이 압력 자체를 소급 삭제하지 않는다.

## 10. Preparedness Mitigates, Never Cancels Rule
좋은 준비와 선택은 메인 사건을 없애는 것이 아니라 결과를 개선한다.

보상:
- 피해 감소
- 대응시간 증가
- 선택권 증가
- 가족 상태 안정
- 자원 여유
- 복구 가능성 증가

금지:
`충분히 준비했으므로 이후 큰 문제가 발생하지 않음.`

## 11. Long-Disaster Phase Escalation Rule
장기재난 모드에서는 최소 3개 이상의 의미 있는 상태전환이 필요하다.

권장 구조:
`초기 충격 → 부분 마비/희소성 → 장기 운영 압박 → 경제·행정·사회 변화 → 새로운 안정상태`

각 단계는 단순한 수치 악화가 아니라 플레이어가 해결해야 하는 문제의 종류를 바꿔야 한다.

## 12. Repeated Operations Compression Rule
사용자가 같은 정비·구매·텃밭·재고순환·보수 작업을 `특이사항 발생 전까지 반복`한다고 선언하면 반복 장면을 자동 압축한다.

압축 중 추적:
- 경과 시간
- 재고 변화
- 비용
- 피로
- 거점 능력 변화
- 관계/협업 변화

다음이 발생할 때만 다시 장면화한다.
- 외생 사건
- 자원 임계점
- 새로운 갈등
- 계획 수정 필요
- 장기재난 Phase 전환

## 13. Build–Pressure Rhythm Rule
장기 시즌의 기본 리듬은 다음을 지향한다.

`준비/건설 → 큰 외생 사건 → 급박한 선택 → 복구/확장 → 더 큰 장기 문제`

건설 시뮬레이션과 재난 드라마를 서로 대체시키지 않고 교차시킨다.

## 14. Base Capability Growth Rule
거점 플레이의 성장은 단순 물자 수량 증가가 아니라 `할 수 있는 일의 증가`로 표현한다.

예:
- 저장능력
- 제한적 독립전력
- 물 확보/저장
- 조리 선택지
- 보수능력
- 재고 순환
- 소규모 생산
- 차량/공구 활용

거점이 강해져도 만능 안전지대가 되지는 않는다.

## 15. Interest-Based Cooperation Rule
협업은 자동적인 공동체화가 아니라 서로 다른 자원·기술·시설·필요가 맞을 때 형성되는 상호보완 관계다.

설계 요소:
- 누가 무엇을 제공할 수 있는가
- 무엇을 원하는가
- 어느 범위까지 협력하는가
- 비용과 부담은 무엇인가
- 신뢰가 어느 정도인가
- 협력을 확대하거나 제한할 이유는 무엇인가

플레이어가 `두 가구 우선 협업`처럼 범위를 정하면 GM이 임의로 마을 전체 공유 체제로 확대하지 않는다.

## 16. Prepared Base Shifts Pressure Rule
한 생존 축이 안정되면 재난 난이도를 억지로 상승시키지 않는다.
대신 아직 해결되지 않은 다른 세계 축이 자연스럽게 중심 문제로 이동한다.

예:
- 물 안정 → 연료·의료
- 전력 안정 → 물류·경제
- 거점 안정 → 직장·학교·행정
- 비축 안정 → 차량·보수·관계

이는 `준비를 무효화`하는 규칙이 아니라 준비의 가치를 인정하면서 세계가 다층적으로 계속 움직이게 하는 규칙이다.

## 17. High-Intensity Season Commitment Rule
새 정규 시즌 시작 전 GM은 비공개로 시즌의 주 압력 형식을 명확히 하나 선택한다.

A. `대규모 장기재난`
- 장기 단계 상승과 누적 선택비용이 핵심

B. `급박한 대규모 사건`
- 짧은 시간 내 큰 규모의 선택과 손실 위험이 핵심

두 경우 모두 `조금 불편한 정상생활` 상태에 장시간 머무르지 않는다.
플레이어에게 시즌 대본이나 재난 정체를 미리 공개할 필요는 없다.
