# 생존기록 IP Asset Pipeline v0.1

상태: ACTIVE / LIGHTWEIGHT

## 목적
《생존기록》의 1순위는 **사용자가 재미있게 계속 플레이하는 것**이다.
IP 자산화는 플레이를 방해하지 않고, 이미 발생한 시즌 기록을 나중에 웹소설·게임·웹툰·오디오드라마·시나리오 제작에 재사용할 수 있게 정리하는 보조 단계다.

핵심 원칙:
> 먼저 논다 → 시즌을 끝낸다 → 이미 생긴 좋은 재료만 짧게 구조화한다.

IP 자산화를 위해 플레이 중 장면을 멈추거나, 대형 문서작업을 선행하거나, 미래 작품을 미리 제작하지 않는다.

---

## 1. 한 시즌이 남기는 3층 자산

### A. Canon — 실제로 일어난 것
다음 시즌의 사실 기준이 되는 기록.
- 실제 발생 사건
- 가족·관계·거점 변화
- 주요 선택과 결과
- 엔딩/새 안정상태

기존 `PLAYTHROUGH_CANON.md`, `CHECKPOINT.md`, `PERSISTENT_CANON.md`가 담당한다.

### B. IP Package — 재사용 가능한 이야기 자산
재미나 재사용 가치가 있는 시즌에 선택적으로 생성한다.
권장 경로:
- `seasons/Sxx/IP_PACKAGE.md`

내용:
- 시즌 한줄 로그라인
- 핵심 갈등
- 캐릭터 아크
- 주요 결정과 결과
- 강한 장면
- 재사용 가능한 사건 원형
- 실제 플레이 중 드러난 미발생 가능성
- 미디어 전환 태그

### C. Library — 여러 시즌에서 반복 검증된 자산
한 시즌의 요소를 즉시 공통 세계관으로 승격하지 않는다.
여러 시즌에서 가치가 확인된 뒤에만:
- 사건 원형 라이브러리
- 관계/갈등 패턴
- World Director 규칙
- 장면 문법
- 설정/세계관 공통 요소

로 승격한다.

---

## 2. IP_PACKAGE 작성 규칙

### 사실과 창작 후보를 분리한다
- `CANON`: 실제 플레이에서 발생한 사실만.
- `UNUSED / POSSIBLE`: 실제 플레이 도중 제시되었거나 시스템상 존재했던 미발생 가능성만.
- 플레이 후 새로 상상한 아이디어는 `NEW ADAPTATION IDEA`로 별도 표시한다.

실제 플레이와 사후 창작을 섞지 않는다.

### 첫 플레이를 정답 루트로 만들지 않는다
첫 플레이는 하나의 Canon 기록이지, 이후 게임·소설의 유일한 정답 루트가 아니다.

### 좋은 장면만 남긴다
모든 턴을 IP Package에 복사하지 않는다.
다시 보고 싶은 장면, 갈등, 결정, 반전만 추출한다.

### 사용자 스포일러를 만들지 않는다
미래 시즌 Hidden Seed나 미발생 예정 사건을 IP 자산화를 이유로 사용자에게 공개하지 않는다.

---

## 3. 최소 메타데이터

각 IP Package에는 검색과 재활용을 위해 아래 태그를 권장한다.

- `season`
- `disaster_type`
- `time_scale`
- `locations`
- `characters`
- `relationship_conflicts`
- `resource_pressures`
- `society_state`
- `tone`
- `adaptation_fit`

예:
`전력망 / 가족분산 / 도심-외곽 / 부자관계 / 연료 / 부분사회기능 / 장기압박 / 웹소설·게임`

향후 시즌 수가 충분히 쌓일 때 이 태그를 기반으로 검색/Scenario Forge를 검토한다.
지금은 별도 DB나 검색 플랫폼을 만들지 않는다.

---

## 4. 미디어 전환 가능성 기록

IP Package는 완성 원고가 아니다.
각 시즌의 재사용 가능성을 짧게만 평가한다.

- `NOVEL`: 웹소설/장편소설에 쓸 갈등·장면
- `GAME`: 선택지·시스템·사건 원형
- `WEBTOON`: 시각적으로 강한 장면
- `AUDIO`: 통신·가족대화·라디오 등 음향 중심 장면
- `VIDEO`: 시즌 단위 영상/드라마 가능성
- `EDU`: 현실 생존 복기에서 교육적 가치가 있는 요소

평가는 `높음 / 중간 / 낮음` 정도면 충분하다.

---

## 5. 시즌 종료 기본 흐름

정식 시즌 종료 후:

1. SAVE / CHECKPOINT / GM_STATE 정리
2. PLAYTHROUGH_CANON 정리
3. 필요한 Persistent Canon 승격
4. 플레이어·GM 복기
5. **IP 가치가 있으면 `IP_PACKAGE.md` 자동 초안 생성**
6. 바로 다음 시즌으로 이동 가능

5번은 선택 단계다.
사용자가 문서를 직접 작성할 필요는 없고, AI가 기존 로그와 Canon에서 짧게 추출한다.

권장 작업시간:
- 사용자 입력: 거의 0
- AI 정리: 짧은 후처리

---

## 6. 장기 확장 — 지금은 만들지 않음

시즌이 충분히 누적된 뒤 검토:
- Scenario Library
- 사건/갈등 검색
- 캐릭터 교체형 시뮬레이션
- 웹소설/웹툰 각색 파이프라인
- Scenario Forge
- 다른 게임/매체용 시나리오 팩

진입 조건:
- 충분한 시즌 데이터가 실제로 존재함
- 반복적으로 재사용되는 자산이 확인됨
- 확장이 플레이보다 더 큰 관리 프로젝트가 되지 않음

## 최종 원칙
> 《생존기록》은 IP를 만들기 위해 플레이하는 프로젝트가 아니다.
> 재미있게 오래 플레이한 결과가 자연스럽게 IP 자산으로 축적되게 만든다.
