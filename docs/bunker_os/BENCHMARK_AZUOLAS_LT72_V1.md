# CASE STUDY — Ąžuolas 72시간 대피가방 서비스

확인: 2026-10-11 KST · 참고 URL: https://azuolas.mainline.inc/krepsys/ · 시장 규모/트래픽/가격/저장소 라이선스: 미확인

## 0. 사이트 정체성·신뢰 계층

- 화면 제목: 72 valandų krepšys (72시간 대피용 가방), Ąžuolas. 리투아니아어.
- 제3자 웹서비스이며 사이트 스스로 공식 LT72 원문을 출처로 적음: https://lt72.lt/isvykimo-krepsys-5/
- 정부 공식 본문은 별도 확인: https://essc.lrv.lt/lt/naujienos/ka-svarbu-tureti-72-valandu-isvykimo-krepsyje-rekomendacijos-gyventojams/ (2025-07 발표, 대피가방 기본 범주 9개) 및 LT72 원문.
- 스크랩된 화면 텍스트·메타데이터 기준 확인: 필수 항목 진행률 0/39 표기, 가족 인원 +/- 조절, 개별 물품의 설명·일부 수량, '추가' 물품 구분, 정기 점검 메시지, 가족계획 작성 CTA 링크.
- 원문 메타데이터는 기한 추적을 표방하지만 **데이터 저장/복원/계정/푸시/장기 미사용 알림은 시험하지 못함**. DOM 시각·실사용 클릭·모바일 접근성/성능도 실험 전.
- 이 사이트만으로 수요/유료 구매의사/검색 성과를 추론할 수 없음.

## 1. 지식 사이트에 벤치마킹할 사용자 동선

1. 문제: '72시간 대피 때 무엇을 챙겨야 하지?'
2. 개인화: 가족 인원에 맞추고 개인별 가방 필요를 알림.
3. 실행: 물품별 필수/추가 분류와 왜 필요한지 설명을 보면서 '갖고 있음' 처리.
4. 진행 상태: 39개 필수 항목 대비 실제로 확인한 개수/비율을 사용자에게 보여줌. 체크리스트의 진행률이지 생존율/안전 보장이 아님.
5. 유지: 최소 연 2회 전체 확인, 계절 의류·기한 식품/약품·전자장비 점검.
6. 다음 행동: 가방 준비 페이지 아래에서 가족 비상계획 작성 페이지로 이동.

핵심 원리: **공식 지식→개인별 판단→실제 행동→진행률→정기 점검→다음 지식·행동**. 이 연결은 생존가방 앱보다도 K-002·K-003 및 생존지식 전체의 검색 유입 후 실제 행동과 더 직접 연결된다.

## 3. 안전성·현지화 주의

- LT72 문서는 리투아니아 시민 보호 제도와 지역 위험을 전제로 하는 공식 자료이다. 한국의 법적 의무, 모든 재난의 충분한 준비량, 일률적인 72시간 보장으로 번역하지 않는다.
- 사이트의 6L 물, 신체중량 1/5 가방 무게, 의약품 7일분, 무기/도구, 일반 방호 마스크, 요오드제 100km 기준, 응급 지혈대 및 위험거리 등은 **제품 기본값/의학적 권고로 채택하지 않는다**. 국가·개인·상황별 지침 확인 필요.
- 특히 의약품의 복용, 지혈대 사용 및 방사선/화학물질 대응은 한국 질병관리청·원자력안전위원회·소방청 등 전문기관 최신 안내와 추가 검증 필요.
- 개인정보: 가족 수만으로도 개인 상황이 노출될 수 있으며, 연락처·문서사진·민감한 보관위치는 기본 수집하지 않음.
- 저작권: 민간 사이트의 HTML, 디자인 이미지, 구조화된 물품 데이터 전체를 그대로 복제·번역·출판할 권리는 확인되지 않음. **추상적인 UI 패턴만 벤치마킹**하고 독립 작성·권리확인 후 사용.
- 정부 출처와 제3자 서비스의 주장도 구분한다. 이미 K-002에 국내 근거가 있으므로 해외 사이트 하나로 최신 국내 공공 기준을 대체하지 않음.

## 4. 설계 관점의 교훈

- 장점: 개인화가 어렵지 않음(가족 수 증감) + 체크리스트 진행률 + '왜 챙기는지' 짧은 설명 + 필수/선택 구분 + 후속 행동 연결.
- 위험: 필수물품 39개를 그대로 제시하면 실제 한국 이용자에게는 부담/잘못된 권장으로 인식될 수 있음. 사용자 체력/이동거리/이미 보유한 가정 비축 등 현실 조건 고려 필요.
- 구별해야 할 개념: '체크한 항목', '실제 가방에 넣은 품목', '사용 가능한 상태', '다음 점검이 완료된 상태', '실제로 대피 시 들 수 있는 무게'.
- 벤치마킹 목적은 **가독성이 좋은 체크리스트를 또 만드는 것**이 아니라, 생존일기 검색 방문자가 작은 준비 행동을 실제로 완료하게 만드는 구조를 학습하는 것이다.

## 5. 이어서 할 일 (기존 로드맵 변경 금지)

2. Day 6 E-002 선정 전 K-002/가족연락/정전 대비 가운데 행동전환이 가장 짧은 항목을 비교.
3. 지식 글 업데이트·앱 개발은 여기서 자동 시작하지 않는다. 외부 자료 사용권과 국내 공공 근거를 따로 검증해 기존 C 인간승인 체계를 통과한 경우에만 반영.
4. BAG-SIDE-01 앱 개발은 별도 채팅과 PR을 통해서만 진행한다. 이 문서는 링크만 공유해 재활용한다.
