# 작은 수리 테이프는 왜 생존가방에 필요할까?

**작은 수리 테이프는 이동 중 가방이나 생활용품이 찢어지거나 헐거워졌을 때 빠르게 임시 고정해 계속 사용할 수 있도록 돕습니다.**

대피 장소로 이동하다가 가방 바깥쪽의 가벼운 덮개가 벌어졌다고 생각해 보세요. 수선도구를 꺼내기 어려운 상황에서도 작은 테이프 한 묶음이면 벌어진 곳을 잠시 붙이거나 흔들리는 물건을 묶어 정리할 수 있습니다. 짐이 흩어지는 일을 줄이는 데 도움이 됩니다.

테이프 제조사 3M도 다목적 덕트테이프의 용도로 **물품 묶기·보강·임시 보수**를 안내합니다. 생존가방에는 평소 직접 사용해 본 제품을 작게 나누어 챙기는 편이 실용적입니다.

## 언제, 어떻게 사용할까?

**가벼운 물품이 벌어졌을 때.** 가방 안의 비닐 포장이나 종이 상자처럼 테이프가 잘 붙는 표면을 임시로 고정합니다. 붙일 곳의 물기와 먼지를 가능한 한 닦고, 테이프를 적당한 길이로 잘라 가장자리가 들뜨지 않도록 눌러 줍니다.

**물품을 한데 묶을 때.** 사용하지 않는 케이블이나 작은 도구를 느슨하게 정리하면 가방 속에서 서로 얽히는 일을 줄일 수 있습니다. 필요한 순간 바로 풀 수 있게 끝부분을 조금 접어 손잡이를 만들어 두면 편리합니다. **전원선의 피복 손상을 보수한다는 뜻은 아닙니다.**

**덮개나 포장의 작은 틈을 임시로 막을 때.** 바람에 날리는 가벼운 포장이나 외부 수납물의 벌어진 부분을 잠깐 붙일 수 있습니다. 비가 오는 환경에서는 제품이 해당 표면과 습기에 적합한지 확인하고, 물이 직접 닿는 곳의 완전한 방수 성능을 기대하지 마세요.

## 어떤 제품을 준비하면 좋을까?

작은 크기여도 **어디에 붙일지와 실제 접착 상태**가 더 중요합니다.

- **용도:** 천·비닐·플라스틱·종이 등 주로 손볼 물품을 생각하고, 제조사가 해당 재질에 사용할 수 있다고 안내하는 제품을 고릅니다.
- **휴대성:** 큰 롤을 그대로 넣기보다 작은 휴대용 롤이나 평평하게 감긴 제품이 가방에서 자리를 덜 차지합니다. 3M도 별도 휴대형 덕트테이프를 소개합니다.
- **손으로 끊는 편의:** 가위 없이 자를 수 있는 제품인지 확인합니다. 손으로 잘 끊어지지 않는 제품이라면 안전한 절단 도구와 함께 보관합니다.
- **환경 적합성:** 물에 강한 뒷면이 있는 제품이라도 모든 재질·온도·습도에서 같은 접착력을 내는 것은 아닙니다. 실제 가방 소재에 작은 조각으로 시험해 보세요.

이 품목의 카탈로그 예시 수량 '1개'는 완비 기준이 아닙니다. 필요한 길이와 무게는 가방 크기와 사용 목적에 맞춰 정합니다.

## 가방에는 어떻게 넣고 관리할까?

테이프의 바깥면에 먼지가 많이 묻지 않도록 작은 지퍼백이나 별도 수납칸에 넣습니다. 비상약·식품을 꺼낼 때 접착면이 직접 닿지 않도록 분리하고, 급할 때 찾을 수 있는 도구 칸에 둡니다.

처음 넣을 때 종이나 실제 가방 소재의 눈에 띄지 않는 부분에 짧게 붙여 보세요. 잘 달라붙고 손으로 떼거나 끊을 수 있는지 확인하는 편이 제품명만 보고 선택하는 것보다 정확합니다.

정기 점검 때 접착제가 굳거나 흘러나오지 않았는지, 테이프 끝이 들뜨거나 서로 달라붙어 사용할 수 없게 되지 않았는지 봅니다. 한 번 사용해 길이가 줄었다면 다음 점검 때 보충합니다.

## 놓치기 쉬운 점

**전선 피복 손상을 일반 수리 테이프로 가린 뒤 계속 사용하지 마세요.** 미국 OSHA의 전기안전 기준은 손상으로 다칠 위험이 있는 전기기기를 사용하지 말고, 안전한 수리·검사를 거친 뒤 사용하도록 요구합니다. 테이프를 겉에 감는 것만으로 전기적 안전성이 회복되는 것은 아닙니다.

또한 무게를 지탱하는 가방 끈·안전장비·신발 밑창의 심한 파손, 가스·연료 누출, 뜨거운 난방기구의 손상은 임시 테이프로 해결할 일이 아닙니다. 그런 용도로 사용하지 말고 안전한 대체품이나 적절한 수리를 선택하세요.

일반 생활용 수리 테이프는 피부 상처에 붙이는 의료용 테이프가 아닙니다. 상처를 보호하려면 구급함의 알맞은 소독·드레싱 용품을 사용합니다.
