## 1. 가장 중요한 발견 3개

1. **첫 준비 과업은 기존 자산으로 시험할 수 있다.** 공개 K-002와 자체 XLSX가 존재하고, 이번에 PC Excel에서 실제 파일 열기·가상 한 행 입력·자동 계산·저장·재열기를 확인했다. 새 가방 앱이나 새 생산/측정 시스템이 선행조건은 아니다.
2. **검색/공유/자료 존재가 준비 행동·성장 엔진을 증명하지 않는다.** Day 1~3의 생산 자산/무료 경쟁 대안, Day 4의 작은 과업 가설, Day 5 유통 정책, Day 6 설계까지는 연결됐다. 실제 방문자가 준비를 했는지, 반복 사용·수요·수익이 있는지는 아직 미관측이다. 검색 인증 작업이나 파일 HTTP 200을 검색 성과로 세지 않는다.
3. **지금 확인한 실행 경로는 PC Excel에 한정된다.** XLSX를 편집할 환경과 시간을 가진 성인 편의표본은 모바일 전용 방문자·일반 가정 전체를 대표하지 않는다. 과업을 제시받은 사람의 자기보고는 자연 방문자 전환율·독립 관찰·행동 증가 효과와 다르다.

## 3. Week 2 추천 실행안과 하지 않을 것

**추천 주 실험 1개:** K-002 읽기 → 안전하게 확인 가능한 실제 비상용품 1종 확인 → 기존 XLSX의 점검 기록 한 행 작성·저장. 선정 이유는 기존 무료 자산, 낮은 위험, 명확한 과업 경계다. 가족 연락처 수집이나 실제 정전/전기설비 조작을 요구하지 않는다.

- 동의한 성인 첫 시작자 **8명**, 과업 **10분 내 도움 없이 완료 자기보고**. 유효 N=8에서 C≥6 PASS, C≤2 FAIL, 그 외/표본 부족/무효 조건은 INCONCLUSIVE. 기준을 바꾸지 않는다.
- 첫 환경은 **이번에 검증한 PC Excel 16.0 계열로 한정하는 안**을 추천한다. 이미 해당 로컬 편집 환경을 가진 사람만 대상이며 구매·설치를 요구하지 않는다. 이 환경 제한과 표본 편향은 감독자가 승인해야 한다. 다른 버전/앱도 자동 통과로 간주하지 않는다.
- **7일 / 운영 4시간 / 추가 0원**, 동의·철회·비식별 기록·삭제 규칙 유지. 보조 실험 0개. 참여 철회 데이터 삭제와 대체 모집 금지, 중도 중단·열기 실패 분모 유지도 그대로다.
- 지금 하지 않을 것: 참가자 모집·메시지 발송·실험 실행·외부 게시, 새 CTA/분석 서비스/DB/cron, 앱·유료 상품·광고·재고, Production 배포, 사람 승인 없는 Freeze/DB 완료 기록.
- 모바일 Excel·LibreOffice 등으로 참가 범위를 넓히려면 해당 환경에서 원본 사본의 입력/계산/저장/재열기를 먼저 확인한다. 모바일 지원을 위해 새 앱을 만드는 방향으로 확대하지 않는다.
