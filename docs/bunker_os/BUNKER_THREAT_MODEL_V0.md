## 1. 목적과 현재 판정

실제 벙커의 설계 전에 **어떤 위협에서 누구의 어떤 생존 기능을 유지할 것인가**를 구조화한다. V0의 산출물은 위협 분류, 기능 요구 후보, 미확인 조건, 정보공개 경계, 전문가 검증 질문이다. 도면·시공 지시·장비 선정·안전 인증은 이번 산출물이 아니다.

**현재 판정: 요구사항 초안 작성 가능 / 실제 설계 착수 조건 미충족.** 대상 인원, 체류기간, 부지 적합성, 법적 용도, 방호 범위와 유지관리 능력이 아직 확정되지 않았다. 위험 발생 확률·우선순위 점수·면적·깊이·구조 두께·환기량·저수량·전력 용량·허용 오염 농도·보호계수를 확정하지 않는다. 공공 행동요령에 있는 준비기간을 벙커의 자립기간으로 전용하지 않는다.

검토 맥락은 한국 생활환경이다. 특정 부지나 관할은 전제하지 않는다. 해외 공식 자료는 위험 메커니즘과 질문을 보완하며 한국의 법적 기준을 대신하지 않는다. 아래의 기능 요구는 **공식 자료에서 도출한 프로젝트 제안**이며, 자료 자체가 이 벙커의 안전성을 검증한 것은 아니다.

**체류가 항상 답은 아니다.** 국민안전24 침수 안내는 지하 바닥에 물이 차오르거나 하수 역류 시 즉시 대피하도록 한다(R3). 비상대비 안내도 재래식·핵·화학·생물학 공격의 대피 장소를 구분하고 침수 취약 지하시설을 피하도록 한다(R1). 이 모델은 실시간 공식 대피 지시를 대체하지 않는다. 화학 위협의 대피 장소를 다른 위협의 지하 대피 규칙으로 덮어쓰지 않는다.

### 복합 실패 검토

다음은 발생 예측이 아니라 전문가에게 확인할 **검토 조합**이다.

- 호우 + 정전 → 배수·경보·조명 동시 상실: 물 유입 시 설비가 남아 있는가, 안전한 이탈이 먼저 가능한가?
- 폭염/한파 + 정전 + 보급 차단 → 온도·공기·물·식품 유지 능력을 함께 검증할 수 있는가?
- 지진 + 배관 파손 + 출구 막힘 → 화재·누수와 피난 기능의 동시 상실을 어떻게 평가할 것인가?
- 전쟁/낙진 + 통신 두절 + 내부 화재 → 외부 대피 위험과 내부 체류 위험이 충돌할 때 적용할 검증된 판단 절차가 있는가?

설비를 여러 개 설치하더라도 같은 전원·관통부·제어·접근 경로에 의존하면 함께 실패할 수 있다. 도면 단계에서 공통 실패 원인을 검토하고, 운영 단계에서는 안전한 모의 시험으로 확인한다. V0에서는 실제 차단·침수·밀폐·연소 시험을 수행하지 않는다.

|---|---|---|
| 목적 | 준비 행동 교육, 기능 설명, 콘텐츠·체험·사업 가설 검토 | 정해진 위협 범위의 실제 비상 체류와 피난 |
| 성능 표현 | 전시/모형과 검증된 설비를 구분. 실제 생존·방호 보증처럼 홍보하지 않음 | 부지·설비·운영 조건에 맞춘 전문가 검증이 있어야 성능을 주장할 수 있음 |
| 사람과 운영 | 방문객·직원·대피약자 접근성, 공개 영업 용도·소방·보험 등을 별도 검토 | 이용자·운영 담당·정비/비상 대응·재진입 조건을 비공개 확정 |
| 관계 | 일반 원리·익명화된 배운 점을 공유할 후보 | 공개 공간과 같은 위치·평면·설비 배치·접근 경로를 전제하지 않음 |

두 공간 모두 안전·법률 검토가 필요하다. 공개 공간의 체험 성공은 비공개 벙커의 방호 성능 증거가 아니다. 공개 공간을 실제 대피시설로 겸용하려면 별도 요구·허가·성능·운영 검증을 먼저 거친다.

**공개 GitHub에 허용할 후보:** 위협 분류, 일반 기능 요구, 공식 자료 링크, 민감정보를 제거한 검토 질문과 상태, 개별 공개 승인을 받은 학습 요약.

**공개 GitHub에 기록 금지:** 실제/후보 부지 주소·좌표·지번·지도·위치 추정 사진, 개인 토지 규모·자산·예산·재무·견적, 실제 도면·출입/피난 경로·관통부·급수/전원 위치, 보안 장비·접근 권한·취약점·운영 일정, 실제 재고 위치/규모, 이용자 명단·건강정보·가족 연락처. 문서뿐 아니라 이슈·댓글·PR·커밋 메시지·첨부·로그·사진 EXIF에도 같은 경계를 적용한다. 이미 공개된 정보라도 재결합해 위치나 취약점을 드러내지 않는다.

세부값은 기존 **비공개 Project Source / 운영 Snapshot**에서만 다루고, 공개본에는 ‘미확인’ 또는 ‘비공개 검토 완료(범위·일자만)’처럼 필요한 상태만 적는다. 비공개 문서의 경로·공유 링크도 공개하지 않는다. 모호한 정보는 비공개 유지. 일반 대피 원칙은 설명할 수 있으나 실제 공간의 피난 도면은 공개본에 옮기지 않는다.

## 6. 실제 설계 전에 필요한 전문가 검증

아래 항목은 업무 의뢰용 질문이다. 적용 법령·수치·성능의 확정은 적격 전문가와 관할 기관의 검토가 필요하며 **모든 항목은 현재 미검증**이다. 이번 작업에서 전문가 계약·유료 상담·현장 조사·인허가 신청을 시작하지 않는다.

| 분야 / 검토 주체 후보 | 확인할 질문 | 실제 설계로 넘길 때 필요한 증거(비공개 보관) |
|---|---|---|
| 건축·구조·지반 / 건축사, 구조·토질/기초 전문가 | 선택 위협에 해당 부지가 적합한가? 굴착·지하수·부력·누수·사면·내진·인접 시설 영향은? 피난과 대피약자 접근이 가능한가? | 지반/재해 조건 조사, 용도·배치 검토, 구조 설계 기준 및 계산 범위, 피난 검토. 폭발 방호는 별도 적격 전문 검토 |

| 배수·오수 / 토목·배수·위생설비 전문가 | 집중호우·지하수·역류·정전이 겹치면 어떻게 되는가? 오수·폐기물의 적법한 처리가 가능한가? | 유입/배수 조건과 실패 분석, 전원 상실 검토, 하수/오수 처리 협의, 점검·이탈 계획 |
| 전기·비상전원 / 전기설계·전기안전 전문가 | 필수 부하와 전원 전환, 침수 감전, 배터리/연료 저장·환기·CO·화재 위험을 어떻게 관리하는가? | 부하 목록/계산, 보호·접지·전환 검토, 기기별 안전 자료, 정전/복구 시험과 정비 계획 |
| 화재안전·피난 / 소방설계·소방안전 전문가, 관할 소방기관 | 용도·수용 조건에 맞는 감지·경보·구획·소화·연기 제어·비상조명·피난 요구는? 출입 보안이 피난을 방해하지 않는가? | 적용 대상/기준 목록, 피난·연기 검토, 설비 성능/점검·훈련 계획. 전시공간도 독립 검토 |
| 법률·인허가 / 건축사, 관할 건축·도시계획·환경/소방 기관, 필요시 법률 전문가 | 토지 이용·건축 용도·허가/신고·굴착 및 지하안전 평가 적용은? 지하수/급수·하수/오수·위험물·공개 체험/영업·접근성·책임/보험·민방위 시설 관련 요건은? | 당시 현행 법령·시행령/규칙·조례의 적용/비적용 사유와 관할 확인. ‘개인 벙커’라는 이름만으로 면제·허가 가능 판정 금지 |

R10/R11은 법률 검토의 출발점이다. 법령 페이지의 존재나 일반 행동요령 확인은 해당 시설의 허가·적합성 확인이 아니다. 의료 의존이나 장기 체류를 포함하면 보건·의료 전문가의 별도 지원/이탈 계획도 필요하다.

**실제 설계 착수 검토로 넘어가는 최소 조건:** Q1/Q2의 요구 범위가 사용자 검토를 거쳐 정의되고, Q3의 부지·법 검토에서 중대한 미해결 제약이 식별·처리되며, Q4의 성능 요구/검증 계획과 Q5의 운영 가능성, Q6의 두 공간·공개 경계가 정리되어야 한다. 전문 검토가 필요한 항목의 담당과 증거를 연결한 뒤 별도 설계 착수 결정을 받는다. 한 영역의 PASS로 나머지를 승인하지 않는다.

지금의 다음 행동은 이 문서의 질문을 **민감값 없이 검토하고**, 실제값이 필요한 Q2/Q3/Q5는 기존 비공개 컨텍스트에서 해결할 순서를 정하는 것이다. 새 코드·DB·자동화·예약·Production 변경·구매 없이 진행한다. 전문가 검증은 후속 단계이며 현재 완료로 표시하지 않는다.

## 9. V0 검수 기준

- 범위: 최초 문서 한 개. 상위 전략·기존 실험 상태·원자료는 보존한다.
- 근거: 공식 자료와 프로젝트 도출 요구를 구분한다. 미확인 조건은 빈칸 대신 미확인으로 표시한다.
- 안전: 침수/화재/화학 위협과 지하 체류의 충돌, 복합 실패, 낙진 대피와 폭발 방호의 차이를 명시한다.
- 개인정보: 실제/후보 부지·위치·보안·개인 자산·이용자 정보와 민감한 첨부/링크를 포함하지 않는다.
- 실행: 설계 수치/발생 확률 확정, 현장 조작, 코드·DB·자동화·Production 변경, 새 비용 집행 없음.
- 상태: 문서 검수와 전문가 검증을 구분한다. Draft PR 제출은 설계·시공 착수 또는 사이트 게시 승인으로 취급하지 않는다.
