# 《생존일기》 경량 그래픽·로그라이크 UI 계획

## Status
- Canon v2 기반 웹게임 / AI GM 기획에 통합하는 UI·시각화 보조 규칙.
- 게임의 본체는 **텍스트 + AI GM + Engine authoritative state**다.
- 그래픽은 선택과 결과, 누적 성장, 현재 상태를 더 빨리 이해하게 하는 보조 계층이다.
- 현재 Web MVP를 중단하거나 대형 그래픽 프로젝트로 전환하지 않는다.

관련 기존 규칙:
- `docs/ILLUSTRATION_PIPELINE.md` — 모든 턴/선택마다 이미지를 만들지 않고 재사용 가능한 상황·장소·핵심 이벤트 자산을 우선한다.
- `docs/BASE_GROWTH_RULE.md` — 거점의 성장은 실제 플레이 결과로 누적되며, 유지보수 반복노동이 아니라 능력/전문화의 성장으로 표현한다.
- Issue `#57` — 현재 Web Game MVP v1의 구현 Source of Truth.

---

## 1. 핵심 원칙

> 그래픽이 게임의 본체가 되지 않는다. 그래픽은 플레이어가 내린 선택과 그 결과를 더 잘 느끼게 하는 보조 수단이다.

반드시 유지한다.
1. AI GM이 매 턴 이야기를 자연스럽게 진행한다.
2. 선택 후 충분한 이야기 전개가 발생한다.
3. 자유행동이 가능하다.
4. 가족은 플레이어의 말판이 아니며 독자적인 판단을 할 수 있다.
5. 선택 결과가 이후 세계에 누적된다.
6. 거점 성장도 실제 플레이 결과로 발생한다.
7. 그래픽 때문에 턴 진행 속도가 느려지지 않는다.
8. 게임이 단순 카드 선택 게임으로 변하지 않는다.

---

## 2. 선택지 카드 UI

기존 숫자 선택지를 3~4개의 경량 카드로 표시한다.

카드 기본 구성:
- 작은 아이콘
- 행동 제목
- 짧은 행동 설명

카드에 넣지 않는다:
- 위험 감소/증가 예상치
- 신뢰 상승/하락 예상치
- 자원 증감 예상치
- 성공률
- 희귀/특별/등급 표시
- 정답처럼 보이는 강조

핵심 경험은 `카드 평가`가 아니라:

`무엇을 선택했는가 → 실제 결과가 무엇이었는가 → 그 결과가 이후 세계에 어떻게 남는가`

이다.

### 2.1 순서 있는 복수 선택 큐

기존 시즌 플레이에서 사용하던 `3 → 1 → 4` 같은 복수 행동 지시 감각을 웹에서도 유지한다.

권장 조작:
- 카드 한 번 터치: 선택 큐에 추가
- 선택된 카드에는 `1순위`, `2순위`, `3순위` 배지 표시
- 다시 터치: 선택 취소
- `전체 취소` 제공
- `선택 종료 · N개 행동 실행` 버튼으로 확정
- 하나만 선택해도 같은 확정 버튼으로 실행 가능

AI GM에는 선택된 카드들을 **순서가 있는 하나의 플레이어 의도**로 전달한다.

동시에 성립할 수 없는 행동은 AI가 임의로 모두 실행하지 않는다. 기존 Action Queue / Validator가 충돌을 검증하고, 필요하면 플레이어에게 순서 변경 또는 선택 제거를 요구한다.

---

## 3. 자유행동 유지

카드는 기본 행동 제안일 뿐이다. 자유행동은 항상 유지한다.

예:
> 민석에게 통신 상태를 확인시키고 나는 외곽 상황을 살핀다.

AI GM은 의도를 해석하고, Engine은 실제 가능한 상태변화만 검증·커밋한다.

---

## 4. 서사 가독성 / 타이포그래피

현재 Web MVP 플레이테스트에서 다음 문제가 확인되었다.
- 선택 후 서사가 짧다.
- 줄글로 이어져 가독성이 낮다.
- 기본 글자 크기가 작다.
- 불필요한 환경 묘사가 행동·결과보다 많다.

### MVP 기본 규칙
- 장면 서술 기본 글자 크기를 현재보다 키운다.
- 모바일 기준 본문은 대략 17~18px 수준을 우선 검토한다.
- 줄간격은 약 1.7~1.8 수준을 우선 검토한다.
- AI narrative의 줄바꿈/문단을 실제 `<p>` 단위로 렌더링한다.
- 2~4개의 짧은 문단을 기본으로 한다.
- 설정에서 `작게 / 기본 / 크게` 정도의 간단한 글자 크기 조절을 제공한다.

### AI GM 서술 우선순위
길이를 늘릴 때 환경 묘사를 늘리지 않는다.

우선순위:
1. 플레이어 행동의 실제 결과
2. 가족/주변 사람의 반응과 판단
3. 세계 또는 자원의 의미 있는 변화
4. 새로 생긴 압력·기회·정보
5. 다음 선택으로 이어지는 장면
6. 필요한 만큼의 최소 환경 묘사

환경·날씨·빛·소리 묘사는 판단이나 긴장에 영향을 줄 때만 상세하게 쓴다.

---

## 5. 상황판 경량 그래픽화

가족·자원·거점 상태는 아이콘 + 짧은 상태 태그 중심으로 표현한다.

예:
- 가족: 아내 — 긴장 / 민석 — 안정 / 아버지 — 피로
- 자원: 물 / 식량 / 전력 / 통신
- 거점: 외곽주택 / 차량 / 도심 아파트

복잡한 게이지를 다수 만들지 않는다. 한눈에 판단 가능한 상태만 우선한다.

기본 아이콘 체계는 **Lucide Icons 우선 검토**. Tabler / Material Symbols는 대안이다. 여러 아이콘 체계를 섞지 않는다.

---

## 6. 현재 위기 단계

상단에 세계 전체의 위기 정도를 단순 텍스트 단계로 표현할 수 있다.

`안정 → 주의 → 위험 → 심각`

이는 선택의 예상 정답이나 성공률이 아니라 **현재 세계 상태 요약**이다. 테스트 후 가치가 낮으면 제거한다.

---

## 7. 선택 후 주요 변화

선택 전에 결과를 예고하지 않는다.

선택 후에는 플레이어가 알아야 할 변화 1~4개만 짧게 강조한다.

예:
- 물 12L 사용
- 발전기 점검 완료
- 아버지 피로 증가
- 통신 장애 확인

모든 내부 수치를 노출하지 않는다. Engine이 실제로 커밋한 delta만 표시한다.

---

## 8. 거점·차량의 시각적 성장

### 외곽주택
장기적으로 다음과 같은 시설이 실제 플레이 결과에 따라 시각적으로 누적될 수 있다.
- 태양광
- 물탱크
- 저장창고
- 창문 보강
- 울타리
- 텃밭
- 작업공간
- 경계등
- 발전기
- 빗물 저장시설

`Lv.1 → Lv.2 → Lv.3`만으로 단순화하지 않는다.

플레이어 선택에 따라:
- 전력 자립형
- 식량 비축형
- 방어 강화형
- 생활 안정형

등 서로 다른 전문화가 눈에 보이게 한다.

초기 MVP에서는 시설 슬롯/대표 이미지 단계로 증명하고, 장기적으로 레이어 합성 방식을 검토한다.

### 차량
차량도 누적 자산으로 표현한다.
- 비상가방
- 공구함
- 응급키트
- 물자함
- 루프랙
- 보조배터리
- 차량용 무전기
- 추가 적재 공간

---

## 9. 시설 슬롯

대형 이미지 이전에도 작은 아이콘으로 성장 체감을 제공한다.

예:
- 외곽주택: 태양광 / 물탱크 / 저장창고 / 창문 보강 / 미설치 시설
- 차량: 공구함 / 응급키트 / 물자함 / 무전기

이 슬롯은 `BASE_GROWTH_RULE.md`의 capability model과 연결한다. 존재하지 않는 시설을 단순 수집용으로 만들지 않는다.

---

## 10. 플레이 흔적 / 주요 갈림길

전체 분기 트리는 만들지 않는다.

시즌/위기에서 의미가 큰 결정만 기록한다.

예:
- 가족 전원 외곽 이동
- 제한적 협력 선택
- 차량 연료 비축 우선
- 도심 거점 유지
- 야간 조명 최소화

목적은 플레이어가 `이번 플레이가 어떤 방향으로 흘러왔는가`를 한눈에 확인하게 하는 것이다.

---

## 11. AI 이미지 사용 원칙

런타임에서 매 턴 AI 이미지를 생성하지 않는다.

우선순위:
A. 거점 성장 이미지
B. 반복 장소 대표 이미지
C. 정말 중요한 이벤트 이미지

### 상황별 이미지 원칙
선택지마다 이미지를 따로 만들지 않는다.

예: `외곽주택 야간 상황` 이미지 하나를 경계/발전기 확인/물자 확인/가족 대화 등 여러 행동에서 재사용할 수 있다.

기존 `ILLUSTRATION_PIPELINE.md`의 Visual Bible / 후보 태그 / 시즌 종료 후 asset 제작 규칙을 유지한다.

---

## 12. 로그라이크 감각 정의

《생존일기》에서 원하는 로그라이크 감각은 희귀카드·카드등급·랜덤 강화가 아니다.

핵심은:

`선택 → 결과 → 누적 → 세계 변화 → 성장한 상태로 다음 위기`

한 번의 플레이에서 내린 결정이 거점·관계·자원·세계의 형태를 바꾸고, 그 흔적이 다음 위기에 이어지는 것이 핵심이다.

---

## 13. 단계적 적용 순서

### Phase A — 현재 MVP에 바로 적용
AI GM / Engine 안정화를 막지 않는 작은 UI 개선만 진행한다.

1. 장면 본문 기본 글자 확대
2. 글자 크기 `작게 / 기본 / 크게`
3. AI narrative 문단 렌더링
4. 불필요한 환경묘사 억제 + 행동/결과/가족반응 중심 프롬프트
5. 숫자 선택지를 카드 형태로 변경
6. **순서 있는 복수 선택 큐 + 선택 종료 버튼**
7. 간단한 아이콘 적용
8. Engine commit 기반 `이번 턴 변화` 1~4개

### Phase B — 코어 플레이가 안정된 뒤
- 가족/자원/거점 아이콘 상황판
- 현재 위기 단계
- 시설 슬롯
- 외곽주택/차량 대표 성장 이미지

### Phase C — 시즌/세계 자산이 안정된 뒤
- 반복 장소 대표 이미지
- 핵심 이벤트 이미지
- 주요 갈림길/플레이 흔적 UI
- 시설 레이어형 거점 성장 검토

---

## 14. MVP 중단 금지 규칙

그래픽 작업 때문에 다음을 지연시키지 않는다.
- AI GM의 매 턴 서사 진행 품질
- 자유행동 해석
- Engine commit 안정성
- 가족 자율 반응
- 10~20턴 연속 플레이 안정성
- pressure / compression / growth fun loop

새 그래픽 기능이 이 항목을 막으면 그래픽 기능을 후순위로 내린다.

---

## 핵심 한 문장

> 《생존일기》는 텍스트와 AI GM이 본체이고, 카드·아이콘·거점 성장 이미지는 플레이어가 자신의 선택이 세계에 남긴 흔적을 눈으로 확인하게 만드는 경량 그래픽 시스템으로 사용한다.
