## Implemented

`accepted-image-handoff.mjs` requires a validated Step 6 request, the exact observer-bound receipt, the original PNG bytes, and an identified visual review. The reviewer must attest decoded pixels, one intended subject, no embedded text, and a match to the intended brief. The review is bound to the file SHA-256. Rejected, unreviewed, mismatched, changed or tampered results cannot become a candidate. The candidate retains point id, generation key, source revision, request id, receipt id and tool result id.
