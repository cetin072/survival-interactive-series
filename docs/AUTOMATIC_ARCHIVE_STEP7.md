# Automatic Archive Publication — Step 7 / 10: accepted image handoff

Status: CODE COMPLETE FOR LOCAL CONTRACT / REAL INGEST BLOCKED

## Implemented

`accepted-image-handoff.mjs` requires a validated Step 6 request, the exact observer-bound receipt, the original PNG bytes, and an identified visual review. The reviewer must attest decoded pixels, one intended subject, no embedded text, and a match to the intended brief. The review is bound to the file SHA-256. Rejected, unreviewed, mismatched, changed or tampered results cannot become a candidate. The candidate retains point id, generation key, source revision, request id, receipt id and tool result id.

An accepted **local candidate** is still `NOT_STORED` and `NOT_PUBLISHED`. The receiver generates a deterministic, disabled ingest plan only after rechecking the candidate against the bytes, receipt, request and current validated Visual Catalog. A changed generation key is rejected. For ordinary characters `registry_asset_id` remains null; the receiver does not guess a Supabase id. No file copy, Storage operation, database call, site publication, or provider call occurs.

## Tested
