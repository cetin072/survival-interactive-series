# Text Visual Grammar — Lightweight MUD Presentation Rules

## Goal
텍스트 기반 MUD/인터랙티브 생존게임의 정체성을 유지하면서, 세계 생성·상태 관리·GM 계산 부담을 늘리지 않고 화면 가독성과 게임 감각을 강화한다.

핵심 원칙:
`새로운 세계 상태를 만들지 않고, 이미 존재하는 정보를 더 잘 보이게 한다.`

## 기본 적용 요소
다음 5개를 우선 사용한다.

### 1. Scene Header
장소·시간·국면이 크게 바뀔 때만 표시한다.

예:
```text
━━━━━━━━━━━━━━━━━━
DAY 03 · 21:40
정호 외곽주택
광역정전 57시간째
━━━━━━━━━━━━━━━━━━
```

### 2. Information Source Tag
플레이어가 얻은 정보의 출처를 표시한다.

예:
```text
[라디오]
복구 예상시간은 아직 발표되지 않았다.

[이장]
읍내 주유소 두 곳이 문을 열었다고 한다.

[직접 확인]
도로 신호등은 여전히 꺼져 있다.
```

출처 표시는 정보 신뢰도와 불확실성을 체감하게 하되, 별도 숫자 신뢰도 시스템은 만들지 않는다.

### 3. Family Location
가족이 분산되거나 위치가 중요한 장면에서만 표시한다.

예:
```text
[가족 위치]
당신   : 외곽집
아내   : 외곽집
아이   : 외곽집
아버지 : 최씨 밭
```

목적은 가족 4인 파티의 존재감을 유지하는 것이며 매 턴 고정 출력하지 않는다.

### 4. AUTO Operation Marker
이미 정책이 확정되고 안정적으로 반복되는 시스템은 AUTO로 표시한다.

예:
```text
[AUTO]
우물 물물교환 — 정상
마을 연락망 — 정상
최씨 농사협업 — 진행 중
```

반복 실무는 자동 처리하고, 예외·고장·갈등·규모 변화·자원고갈이 생길 때만 AUTO를 해제하고 다시 플레이어 선택으로 복귀한다.

예:
```text
[AUTO 해제]
우물 운영에 이상 발생
```

### 5. Time Compression Line
반복 작업·대기·복구 구간을 압축할 때 사용한다.

예:
```text
──── 3시간 후 ────
```

또는:
```text
━━ DAY 4 → DAY 6 ━━
```

## 선택적으로 사용할 수 있는 가벼운 요소

### State Warning
문제가 있을 때만 표시한다.

```text
⚠ 연료 — 위험선 접근
⚠ 통신 — 간헐적
```

### Major Change Log
큰 선택 결과 뒤에만 짧게 표시한다.

```text
변화
+ 식량 비축
+ 최씨 신뢰
- 현금 여유
```

### Unlock / Relationship Change
새로운 선택권이나 관계 변화가 실제로 생겼을 때만 사용한다.

```text
[새 선택 가능]
최씨와 공동 물자조달
```

### Typography as Direction
중요 장면은 그래픽 대신 여백·구분선·단독문장을 사용한다.

```text
문제는 이제 정전이 아니었다.

연료였다.
```

## 사용 제한
- 매 턴 모든 요소를 출력하지 않는다.
- 복잡한 RPG HUD로 발전시키지 않는다.
- HP/갈증/피로 등을 과도한 숫자로 상시 표시하지 않는다.
- 미니맵, 수십 개 아이콘, 대형 인벤토리 UI를 현 단계에서 추가하지 않는다.
- 매 장면 AI 이미지를 생성하지 않는다.
- 시각문법 때문에 GM이 새로운 자원값·위치값·상태값을 별도로 계산해야 하는 구조를 만들지 않는다.

## Development Timing
### Phase A — 지금
ChatGPT 플레이 단계에서 본 문법을 가볍게 적용해 체감 테스트.

### Phase B — 게임 시스템 안정 이후
상태창·간단한 지도·가족/거점 화면을 실제 UI로 프로토타입.

### Phase C — Scenario/Visual Bible 안정 이후
핵심 삽화·제한적 애니메이션·효과음 등을 추가.

## Evaluation
다음 시즌 종료 후 확인:
- 게임처럼 느껴지는가
- 정보 파악이 쉬워졌는가
- 몰입을 방해하지 않는가
- 출력이 장황해지지 않았는가
- GM/세계 생성 부담이 늘지 않았는가
