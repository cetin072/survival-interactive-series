## Architecture at the current boundary

`approved public RAW and publication snapshot -> Reader candidate -> public graph -> visual points and briefs -> image request/observed result -> human-reviewed local candidate -> durable asset -> site-ready projection -> public website`

The first three transforms have local compilers. The image tail now has one visually reviewed built-in Codex foreground PNG from a real Step 5 public brief, preserved as an unpublished experiment in Draft PR #144. PR #144 validates that PNG against the current READY public Visual Point and computes a disabled local observation entry. A pure approval-gated function can compute a local candidate and disabled ingest plan, but its positive test uses a synthetic approval; there is no real owner decision, accepted asset or active production path. The Step 9 read-only command carries a validated, uncommitted Reader candidate through graph links and visual briefs in memory, with batch/revision/content checks. It still requires a Git-pinned committed BOOK before image attempt selection; a locally updated BOOK does not qualify. Its catalog-bound S02 attempt journal is empty. An opt-in local append function was tested on a temporary file, but the orchestrator does not invoke it. Step 8 consumes a pinned public Visual Catalog and an empty site-asset manifest; it can display a validated local static image if one is later accepted, but currently shows pending states only. A read-only reconciliation function can carry forward only verified site assets whose point and generation key remain current, and identifies stale public paths for removal before a later release. A build-time inventory check rejects static visual files missing from the manifest. Neither check updates files or deploys. No hidden world seed, private GM record, or PLAYER_ARCHIVE-only map is an authorized input to this chain.

A separate Draft stack #149, #151–#156 and #157–#167 now has a **local Git-ref proposal chain**: reviewed public segment files, a Git-pinned public-season snapshot, Reader BOOK, Reader-derived graph links, Visual Catalog, disabled image request envelopes, and a local catalog-bound attempt journal. #162 removes checkout-season scanning from ref Reader compilation; #163–#164 inspect and resume the local proposal stages; #165 keeps request IDs stable when the ref advances; #166–#167 validate and locally persist attempt reservations. Commit-capable steps require caller-supplied authorizers and advance only an existing dedicated local ref with compare-and-swap. Isolated S99 fixtures prove the chain without checkout edits; Linux archive CI passed at #167 ([run 153](https://github.com/cetin072/survival-interactive-series/actions/runs/36294815232)). The stack supplies no real S03 public segment, owner authorization, remote push, website deployment, image execution, authenticated cross-batch attempt history, or repeated unattended run. It is not the production publisher.

```sh
node --experimental-strip-types archive/scripts/check-archive-pipeline.mjs --demo-s02 --check
node --experimental-strip-types archive/scripts/check-archive-pipeline.mjs --demo-s02 \
  --ledger archive/content/visuals/C03-AFTERFALL/ATTEMPTS_S02.json --check
```

For a later approved public batch, supply its frozen snapshot and pinned public facts, plus dated appearance/map projections when applicable:

```sh

  --snapshot /path/to/approved-snapshot.json \
  --facts archive/content/public-facts/C03-AFTERFALL/Sxx/FACTS.json \
  --appearances archive/content/public-facts/C03-AFTERFALL/Sxx/APPEARANCES.json \
  --check
```

Their hashes are previews, not published artifacts; image attempt selection stays empty. A locally updated BOOK does not clear this gate.
