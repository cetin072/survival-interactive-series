# NPC Design v2

## Goal
NPC를 단순 기능 담당자나 플레이어 갈등 장치로 쓰지 않는다. 핵심 인물은 자기 욕구·판단기준·장점·약점·자율행동을 가진다. 다만 모든 NPC를 장기 캐릭터화해 GM 부담을 늘리지 않는다.

## Family v2
- 한준호: 장기판단·자원·외부환경. 모든 문제를 직접 해결하려는 경향이 약점.
- 서윤: 공동 의사결정자·생활 지속성. 항상 보수적이지 않으며 필요하면 먼저 결단 가능.
- 민석: 15세 중3. 정보·기술 적응·독립성 성장. 보호·갈등 장치로만 사용하지 않고 실제 문제해결과 정보발견에 기여.
- 정호: 68세 유지. 지역 경험·생활기술·독립성. 자기 역할과 존엄성을 지키려 하며 일부 분야에서는 플레이어보다 더 정확한 판단 가능.

## External NPCs
### 최씨 — Anchor NPC
- 장기 주요 NPC로 유지.
- 자기 가구 우선 + 상호주의.
- 플레이어의 부하가 아니라 독립 자산과 이해관계를 가진 동급 파트너.

### 이장 — Recurring Supporting NPC
- 마을 전체 질서·공정성을 대표하는 역할.
- 마을 규모 사건에서만 비중 상승.
- 최씨급 장기 주연으로 확대하지 않는다.

### 회사 인물 — Anchor 후보
- 회사라는 기관 대신 반복 등장 가능한 직속상사/운영책임자 1명 도입 검토.
- 직원 필요와 재난 현실을 동시에 고려하는 인간적 압력축.
- 회사 NPC를 여러 명 늘리지 않는다.

## NPC Tier
1. Core: 아내·아들·아버지 — 장기 성격·관계·성장
2. Anchor: 최씨, 필요 시 회사 인물 — 시즌 간 관계 누적
3. Recurring Support: 이장 등 — 필요 시즌에 재등장
4. Season NPC: 시즌 핵심 인물 2~4명 — 욕구·성격 1~2개만 부여
5. Extra: 직원·주민·공무원 등 — 기능 중심, 이름 불필요

## Characterization Rule
캐릭터성이란 플레이어와 자주 갈등하는 것이 아니다. 좋은 NPC는 다음 중 하나 이상을 한다.
1. 플레이어가 못 본 것을 발견한다.
2. 플레이어 대신 문제를 해결한다.
3. 자기 판단으로 새로운 행동을 시작한다.
4. 정말 중요할 때 다른 의견을 낸다.

가족은 1~3이 자주, 4는 드물게 작동한다.

## Minimal Character Spec
장기/주요 NPC는 다음 5개만 정의하면 충분하다.
1. 원하는 것
2. 잘하는 것
3. 싫어하는 것
4. 스스로 판단하는 기준
5. 플레이어와 의견이 달라질 수 있는 지점

각 시즌에서는 이 중 1~2개만 전면에 사용한다.

## Child Character Rule
민석은 보호대상이라는 이유만으로 갈등·질병·피로 발생장치가 되지 않는다.
의미 있는 등장에서는 도움/발견, 독립 의견, 보호·문제 요소가 균형을 이루어야 한다.
정확한 비율을 강제하지 않지만 `아이 때문에 문제 발생`만 반복하지 않는다.

## Delegation and Autonomy
가족에게 맡긴 일은 가족이 자기 성격·능력·정보에 따라 합리적으로 진행한다.
플레이어에게 다시 올라오는 경우는:
- 정상 완료: 짧은 AUTO 보고
- 의미 있는 변화: 새 정보/결과 제공
- 가족 판단만으로 결정하기 어려움: 플레이어 선택

핵심: `Delegation ≠ Control`.

## Human Drama Limit
이 작품의 중심은 인간관계 드라마가 아니라 재난 속 판단·생존·가족운영·현실적 학습이다.
- NPC 갈등은 재난 대응의 판단을 선명하게 만들 때만 사용한다.
- 가족갈등, 배신, 질투, 복수, 장기 숙적을 시즌 긴장도의 기본 엔진으로 사용하지 않는다.
- 인간관계 서사가 재난 자체, 생존 판단, 자원 선택, 정보 불확실성, 정상사회 의무보다 앞서지 않게 한다.
- 향후 시즌별 현실 생존 교육요소를 붙일 수 있도록, 주요 사건의 중심 원인은 가능한 한 재난·환경·인프라·제도·자원 제약에 둔다.

## Villain Is Optional Rule
- 재난·환경·사회 시스템의 제약이 기본 적대축이다.
- 인간 빌런은 시즌 필수 요소가 아니다.
- 실제 악의적 인물은 드물게만 등장시키며, 단순히 긴장도를 올리기 위해 투입하지 않는다.
- 빌런이 등장하더라도 재난 속 이해관계, 기회주의, 권한 남용, 자원 우선권 문제 등 현실적인 맥락에서 발생해야 한다.
- 장기 숙적은 기본적으로 만들지 않는다. 플레이 중 자연스럽게 반복될 이유가 생긴 경우에만 별도 검토한다.

## Conflict Before Evil Rule
사람과 문제가 생기면 먼저 `악인인가`가 아니라 `이해관계가 다른가`를 판단한다.
- 최씨, 이장, 회사 관계자, 주민, 공공기관이 플레이어와 다른 판단을 해도 자동으로 빌런이 되지 않는다.
- 보통의 인간 갈등은 기여도, 책임, 우선순위, 정보범위, 가족보호, 자원배분 차이에서 나온다.
- 합리적인 협상과 좋은 시스템으로 갈등을 예방·완화할 수 있으며, 그것 자체가 플레이 보상이다.

## Antagonistic Pressure Priority
시즌 설계 시 적대 압력 우선순위는 기본적으로 다음을 따른다.
1. 재난·환경
2. 인프라·제도·물류·시간 압박
3. 평범한 사람들의 이해관계 충돌
4. 실제 악의적 인간 빌런

4번은 희소하게 사용한다. 인간 빌런이 없는 시즌도 정상이며 오히려 권장될 수 있다.
