# Autosave & Memory Policy

사용자가 저장 위치나 파일 구조를 기억하지 않아도 되도록 GM이 플레이 중 상태 변화를 자동 기록하는 운영 규칙.

## 자동 저장 시점
아래 상황에서는 사용자가 `저장`이라고 말하지 않아도 GM이 가능한 한 GitHub 상태를 갱신한다.
- 중요한 선택의 결과가 확정된 직후
- 장면/에피소드/날짜가 크게 전환될 때
- 파티가 분리되거나 다시 합류할 때
- 가족의 부상·상태·관계가 크게 바뀔 때
- 거점, 차량, 핵심 장비, 주요 자원이 크게 변할 때
- 새 중요 장소/정보/NPC가 Canon으로 확인될 때
- 장기 지속되는 비용·소유·접근권·협업의 인과관계가 확정될 때
- 사용자가 과거 설정의 오류·누락을 바로잡아 Canon Correction이 발생할 때
- 세션을 마치거나 사용자가 다른 채팅으로 이동한다고 명시할 때
- 시즌 종료 시

## 자동 기록 항목
필요에 따라 다음 파일을 갱신한다.
- `core/PERSISTENT_CANON.md` — 시즌을 넘어 유지되는 누적 장기 Canon
- `players/main/SAVE_STATE.json`
- `players/main/CHECKPOINT.md`
- `players/main/SESSION_LOG.md`
- 현재 시즌 `GM_STATE.json`
- 현재 시즌 `EVENTS.json`
- 해당 시즌 `PERSISTENT_WORLD_STATE.md`
- `idea_vault/INBOX.md`
- `playtests/PLAYTEST_NOTES.md`

## Canon Correction 자동 감지
사용자가 플레이 중 다음과 같이 과거 사실을 바로잡는 경우 단순 대화 수정이 아니라 `Canon Correction`으로 취급한다.

예:
- `원래 이 사람은 이 동네에 살았잖아.`
- `지난 시즌에는 이렇게 정리됐었어.`
- `그 시설은 직접 연결된 게 아니었어.`
- `그 비용은 두 집이 같이 부담했었어.`

처리 순서:
1. 현재 장면의 충돌 설정을 즉시 바로잡는다.
2. 사용자의 정정이 기존 기록과 충돌하는지 확인한다.
3. 장기 지속 사실이면 `core/PERSISTENT_CANON.md`에 반영한다.
4. 해당 사실이 시작된 시즌의 `PERSISTENT_WORLD_STATE.md`에도 필요한 범위에서 보강한다.
5. 현재 SAVE/CHECKPOINT/GM 상태가 영향을 받으면 함께 갱신한다.
6. 이후 시즌에서 같은 오류를 반복하지 않는다.

사용자가 `설정확정:`이라는 명령어를 사용하지 않았더라도, 문맥상 명백한 과거 사실 복원·설정 정정이면 이 규칙을 적용한다.

단, 사용자가 아이디어나 가정을 제시하는 것뿐이면 자동으로 Canon으로 확정하지 않는다.

## 장기 Canon에 남길 정보 기준
`core/PERSISTENT_CANON.md`에는 시즌이 여러 번 지나도 의사결정에 영향을 줄 사실만 남긴다.

포함 예:
- 가족 구조와 지속적인 거주 방식
- 거점별 핵심 능력과 약점
- 중요 시설의 소유·접근·연결 구조
- 중요 NPC와 지속되는 관계
- 공동 투자·비용 부담·협업의 역사
- 후속 시즌에서 오해하면 선택 의미가 달라지는 인과관계

제외 예:
- 일회성 소모품 수량
- 임시 위치
- 한 장면에서만 필요한 대화
- 장기 영향이 없는 작은 행동

이런 정보는 SAVE/CHECKPOINT/SESSION_LOG에서 관리한다.

## 아이디어 감지
플레이 중 사용자가 게임 밖 관점에서 새 기능, 재난, 갈림길, NPC, 연출, 삽화, 시스템 아이디어를 말하면:
1. 현재 플레이를 불필요하게 중단하지 않는다.
2. 아이디어를 `idea_vault/INBOX.md`에 우선 기록한다.
3. 명백한 공식 설정 확정이 아니라면 Canon으로 바로 승격하지 않는다.
4. 적절한 시점에 DISASTERS / DILEMMAS / SURVIVAL_KNOWLEDGE 등으로 분류한다.

## 시즌 종료 자동 정리
시즌이 끝나면 `docs/SEASON_COMPLETION_PIPELINE.md`를 실행 대상으로 본다.
즉, 실제 플레이 로그를 보존하고, 시나리오 자산화·Branch Map·삽화 계획·플레이테스트 정리 항목을 생성 또는 갱신한다.

추가로 시즌 종료 시 반드시:
1. 해당 시즌 `PERSISTENT_WORLD_STATE.md`를 정리하고
2. 그중 다음 시즌 이후에도 장기 유지되는 사실을 `core/PERSISTENT_CANON.md`에 승격 또는 갱신한다.

즉 시즌 간 승계는 `직전 시즌 요약 → 다음 시즌`만으로 처리하지 않는다.
`core/PERSISTENT_CANON.md`가 누적 장기 기억의 기준점이다.

## 한계
이 자동화는 백그라운드에서 독립적으로 실행되는 작업이 아니다. ChatGPT와 사용자가 대화하고 있고 GitHub 연결/쓰기 권한을 사용할 수 있는 동안 GM이 규칙에 따라 저장 작업을 수행하는 방식이다.
새 채팅에서는 먼저 `START_HERE.md`, `core/PERSISTENT_CANON.md`, 최신 저장 상태를 읽어 연속성을 복구한다.
