# Season Completion Pipeline — Tiered v2

목적: 시즌 종료 때 **필수 저장**과 **선택적 제작/자산화**를 분리한다.
모든 시즌 종료가 대형 문서작업으로 이어지지 않게 한다.

## TIER 1 — 반드시 하는 종료 처리
시즌이 새로운 안정상태 또는 명확한 종료점에 도달하면 먼저 이것만 한다.

### 1. 현재 상태 저장
- `players/main/SAVE_STATE.json`
- `players/main/CHECKPOINT.md`
- 해당 시즌 `GM_STATE.json`

### 2. 실제 플레이 보존
재사용 가치가 있는 정식 시즌이면:
- `seasons/Sxx/PLAYTHROUGH_CANON.md`

내용은 실제 일어난 것만 짧고 명확하게:
- 시작 사건
- 큰 선택
- 중요한 결과
- 가족/거점/관계 변화
- 엔딩

### 3. 지속 Canon 승격
다음 시즌에도 필요한 사실만:
- `core/PERSISTENT_CANON.md`

일회성 사건·임시 수량·짧은 일정은 승격하지 않는다.

### 4. 복기
사용자가 원할 때 분리 제공:
- A. 플레이어 생존 복기
- B. 게임/GM 시스템 복기

게임 시스템 문제 중 여러 시즌에서 재발할 가능성이 큰 것만 공통규칙 승격을 검토한다.

**여기까지 하면 시즌은 완전히 종료된 것으로 본다.**

---

# TIER 1.5 — 선택적 IP PACKAGE
해당 시즌에 강한 장면·결정·갈등·재사용 가능한 사건이 있었다면 짧게 생성한다.

권장:
- `seasons/Sxx/IP_PACKAGE.md`
- 템플릿: `templates/IP_PACKAGE_TEMPLATE.md`
- 운영 기준: `docs/IP_ASSET_PIPELINE.md`

원칙:
- 사용자에게 추가 문서노동을 요구하지 않는다.
- AI가 기존 플레이 로그와 Canon에서 초안을 추출한다.
- 실제 플레이 사실과 사후 각색 아이디어를 분리한다.
- 모든 턴을 복사하지 않고 재사용 가치가 높은 요소만 남긴다.
- IP Package를 만들지 않아도 시즌 종료에는 아무 문제가 없다.

목적은 당장 작품을 제작하는 것이 아니라, 장기적으로 웹소설·게임·웹툰·오디오·영상 등에서 다시 꺼내 쓸 수 있는 원천 재료를 축적하는 것이다.

---

# TIER 2 — 필요할 때만 하는 시나리오 정제
다음 중 하나일 때 실행한다.
- 해당 시즌을 다시 플레이하고 싶다.
- 다른 사람에게 플레이시키고 싶다.
- 첫 플레이의 구조가 특히 좋았다.
- 시나리오 자산으로 보존할 가치가 크다.

선택 작업:
- 느린 구간 압축
- 선택비용 재설계
- 가족/NPC 변수 보강
- 정보 불확실성 수정
- Fail-Forward 보강
- 주요 전환점 정리
- Branch Map 작성
- `SCENARIO_V1.md` 후보 작성
- `EVENTS.json` 재사용 구조 정리

첫 플레이 Canon을 정답 루트로 고정하지 않는다.

## Scenario v1.0 의미
완성 대본이 아니라:
- 세계 구조
- 주요 압력
- 갈림길
- 종료상태
- 재사용 가능한 사건/GM 데이터
가 충분히 정리된 상태를 뜻한다.

---

# TIER 3 — 미디어 제작이 실제로 필요할 때만
Scenario가 충분히 안정됐고 시각 제작을 하기로 결정했을 때:
1. Visual Bible
2. 핵심 장면 후보
3. 삽화 계획
4. 극소수 영상 후보
5. 적합한 생성도구 선택

플레이 중에는 미디어 제작 때문에 게임을 중단하지 않는다.

---

# 새 시즌으로 바로 넘어가도 되는 조건
아래가 충족되면 TIER 1.5/2/3 없이 다음 시즌으로 가도 된다.
- SAVE/GM_STATE 종료상태 정합
- CHECKPOINT 작성
- 지속 Canon 반영
- 필요한 회고 완료 또는 보류 결정

즉:
`시즌 종료 ≠ IP PACKAGE 제작 ≠ Scenario v1.0 제작 ≠ Visual Bible 제작`

네 작업은 독립 단계다.

## 장기 원칙
사용자의 취미 플레이와 재미 검증이 우선이다.
문서 자산화는 재미를 증명한 시즌에 선택적으로 투자한다.
IP 자산화가 플레이보다 더 큰 관리 프로젝트가 되면 즉시 축소한다.
