# Season → Game Production Pipeline v1

## Status
**APPROVED — 2026-09-04**

이 문서는 실제 ChatGPT 시즌 플레이 중 특히 재미있었던 시즌을 나중에 웹게임/단편게임으로 제작할 때 사용하는 변환 절차다.

## 1. 시작점
게임을 먼저 만들고 이야기를 끼워 넣지 않는다.

출발점은 반드시:
- 실제 플레이 완료 시즌
- 플레이어 체감상 재미가 검증된 시즌
- RAW Transcript와 Canon 결과가 보존된 시즌

중 하나다.

## 2. Golden Route
선정된 시즌의 실제 플레이 경로 중 대표 경로를 `Golden Route`로 지정한다.

Golden Route는:
- 정답 경로가 아님
- 다른 플레이어에게 강제하지 않음
- 가장 좋은 리듬/갈등/보상 구조를 보여주는 제작 기준선

이다.

## 3. Golden Route에서 추출할 것
대본 자체보다 아래를 우선 추출한다.

### Story Anchors
- 반드시 존재해야 하는 큰 세계 사건
- 가족/거점/사회 상태의 주요 전환

### Pressure Tracks
- 시간
- 재난 강도
- 도로/통신/전력/사회기능 악화
- 가족 피로/분산

### Character Motives
- 각 가족이 그 시점에 원하는 것
- 플레이어 명령과 충돌할 수 있는 이유

### Choice Gates
- 되돌릴 수 없는 결정
- 가치 충돌
- 큰 자원/관계/경로 변화

### Growth/Reward
- 거점 기능
- 장비/퇴로
- 정보망
- 가족 역할 성장
- 관계/신뢰
- 다음 시즌 선택권

## 4. 대체 분기 생성
Golden Route의 모든 문장을 무한 분기시키지 않는다.

대신 중요한 Choice Gate마다 2~4개의 전략 계열을 만든다.

예:
- 구조 우선
- 정보 우선
- 자원 우선
- 거점 우선

AI를 제작 도구로 사용해 각 계열의 결과를 다수 시뮬레이션한 뒤 사람이 검수한다.

## 5. Scenario Graph
최종 구조는 거대한 나무가 아니라 **분기 후 다시 합류 가능한 그래프**다.

원칙:
- 큰 사건은 여러 경로에서 만날 수 있음
- 그러나 도착 당시 상태는 다름
- 상태 차이가 대사/선택 가능성/자원/관계에 영향을 줌
- 플레이어가 이전 선택의 결과를 체감해야 함

이 구조로 분기 폭발을 통제한다.

## 6. 사전 제작 우선
출시 후보는 먼저 런타임 AI 없이 가능한 범위까지 완성한다.

사전 제작 대상:
- 주요 사건
- 대표 대사/장면
- 상태 전이
- Choice Gate
- 실패 결과
- 가족 반응 변형
- 엔딩/후일담

목표는 첫 플레이의 품질을 높이는 것이다.

## 7. 런타임 AI 추가 판단
사전 제작 버전 테스트 후 아래 질문을 한다.

1. 자유행동 부재가 실제로 답답한가?
2. 캐릭터 자유대화가 핵심 재미를 크게 높이는가?
3. 사전 제작 분기만으로 플레이어 행동 대부분을 수용할 수 있는가?
4. AI의 불안정성과 비용을 감수할 만큼 가치가 있는가?

필요할 때만 Runtime AI를 추가한다.

### 추천 Hybrid 역할
Runtime AI가 필요하다면 우선:
- 예상 밖 자유행동 해석
- 사전 제작 그래프의 가장 가까운 상태로 연결
- 선택적 가족 자유대화
- 일부 비핵심 표현 변주

에 사용한다.

AI가 세계의 최종 사실을 마음대로 Commit하지 않는다.

## 8. 웹 엔진 책임
제품화 시 엔진이 확정하는 것:
- 시간/날짜
- 위치
- 가족 동행/분산
- 차량
- 자원
- 도로/기관 상태
- 거점
- 진행 중 행동
- 관계/기억의 구조화 상태
- 분기 플래그
- save/load/log

## 9. QA
각 주요 Choice Gate는 최소 다음을 검증한다.
- Golden Route
- 반대 전략
- 위험 전략
- 자유행동 또는 예외 행동
- 실패 후 진행 가능 여부
- 분기 합류 후 과거 선택의 흔적 유지

## 10. 출시 판단
단편 게임 후보는 아래를 만족해야 한다.
- 그래픽 없이 텍스트만으로도 계속 읽고 싶음
- 가족 중 최소 2명 이상에게 애착/반감/관심이 생김
- 중요한 판단이 실제 결과 차이를 만듦
- 최소 한 번 "지난 선택이 지금 나를 살렸다/곤란하게 했다"가 발생
- 엔딩 후 플레이어가 자기 가족의 역사를 기억함

이 기준을 통과하지 못하면 UI/그래픽으로 덮지 않고 시나리오를 다시 수정한다.
