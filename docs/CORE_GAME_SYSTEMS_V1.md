# Core Game Systems v1

이 문서는 정식 본편의 기본 시스템 기준이다. 튜토리얼보다 높은 긴장도와 장기 인과관계를 목표로 한다.

## 1. 난이도 체계
### Tutorial
- 초보자·어린이·첫 플레이어용.
- 기본 재난행동과 가족 협업을 자연스럽게 체험.
- 정보는 비교적 명확하고 큰 실패는 적다.
- 선택의 대가는 낮고, 안전한 복구 루트가 비교적 잘 보인다.

### Standard
- 성인 본편 기본값.
- 불확실한 정보, 자원 압박, 가족 변수, 장기 분기, 이동 제약을 포함.
- 좋은 선택끼리 충돌할 수 있다.
- 일부 자원·기회·관계를 포기해야 할 수 있다.
- 실수는 후반에 다시 돌아올 수 있다.

### Hard
- Standard 시스템을 유지하되 안전 여유가 적다.
- 모든 사람·자원·거점을 동시에 지키는 것이 불가능할 수 있다.
- 더 강한 시간압박, 복합재난, 이동경로 상실, 정보오염, 가족 상태 악화를 허용한다.
- 불공정한 즉사/게임오버는 금지한다.

정식 본편의 기본 목표 난이도는 `Standard와 Hard 사이`다.

## 2. 정식 시즌 최소 품질 기준
정식 시즌은 다음을 모두 충족해야 한다.
1. 하나의 주요 사건/재난이 일상을 실제로 붕괴시킬 것.
2. 최소 3회 이상의 의미 있는 상황 전환이 있을 것.
3. 안전한 선택 하나만 존재하지 않고, 좋은 가치끼리 충돌할 것.
4. 초반 선택 최소 2개 이상이 후반에 다시 영향으로 돌아올 것.
5. 가족 4명 중 최소 2명 이상이 독립적 의견·상태·행동으로 플레이에 영향을 줄 것.
6. 최소 1회의 정보 충돌 또는 정보 부족 판단이 있을 것.
7. 최소 1회의 실질적 손실 가능성이 있을 것: 자원, 시간, 거점, 이동수단, 관계, 체력 등.
8. 단순 `재난 발생 → 대피 → 안전 확보 → 종료`만으로 끝나지 않을 것.
9. 시즌 종료 시 가족과 세계가 시작점과 다른 새로운 안정상태에 도달할 것.
10. 현실 생존지식이 플레이 중 강의가 아니라 세계 내부 행동과 결과로 작동할 것.

## 3. 번호 체계
### 작품명
`생존기록`은 현재 가칭이며 번호를 붙이지 않는다.

### 정식 시즌
- `S01`, `S02`, `S03` ...
- 표기: `생존기록 — S01: 시즌 제목`
- 공식 S01은 아직 설계 전이다.

### 튜토리얼
- `T01`, `T02` ...
- 표기: `생존기록 — Tutorial T01: 지진`
- 이번 지진 플레이는 `T01 v0.1`.

### 초기 프로토타입
기존 폭우/정전 테스트는 번호를 소급 부여하지 않고 `Pre-Alpha Prototype`으로 보존한다.

### 플레이테스트 빌드
필요하면 `v0.1`, `v0.2`처럼 버전을 붙인다.

## 4. 시즌 서사 구조와 길이
화수는 고정하지 않는다. 기본 리듬은 다음과 같다.
1. 평범한 일상과 초기 이상징후
2. 첫 번째 충격과 즉각 대응
3. 정보 부족과 첫 전략 선택
4. 초기 안전전략의 한계 또는 예상 밖 변화
5. 가족·자원·이동·관계의 충돌
6. 더 큰 전환점 또는 복합재난
7. 누적 선택의 회수
8. 클라이맥스
9. 새로운 안정상태와 후일담

모든 시즌이 9단계를 모두 독립 에피소드로 만들 필요는 없다. 짧으면 압축하고, 복합재난이면 늘린다.

## 5. 가족 4인 파티 시스템
각 캐릭터는 플레이어에게 보이는 상태와 GM만 아는 숨은 상태를 가진다.

### 공개 또는 관찰 가능한 상태
- 위치
- 대략적 피로
- 눈에 띄는 부상/불편
- 현재 감정과 의견
- 들고 있는 주요 역할/짐

### 숨은 상태
- 누적 피로
- 스트레스/공포
- 수면 부족
- 갈증/영양 상태
- 숨은 통증 또는 질환 위험
- 플레이어 판단에 대한 신뢰
- 위험 민감도
- 가족별 우선순위

가족은 명령대기 NPC가 아니다. 상황에 따라 제안, 반대, 거부, 독자 행동, 실수를 할 수 있다.

## 6. 자원 시스템
모든 물건을 아이템화하지 않는다. 플레이에 영향을 주는 자원만 추적한다.

### 핵심 자원군
- 물
- 식량
- 약/의료
- 전력/배터리
- 통신수단
- 현금/결제수단
- 연료
- 의복/보온
- 위생
- 이동수단
- 휴식 가능한 거점
- 정보
- 시간

자원은 단순 수량뿐 아니라 `접근 가능성`, `운반 부담`, `보관 위치`, `누가 들고 있는지`가 중요하다.

## 7. 동시 역할분담 시스템
플레이어는 가족에게 서로 다른 임무를 맡길 수 있다.
예:
- 플레이어+아들: 외부 확인
- 아내: 연락/숙박 거점 탐색
- 아버지: 차량 물자 정리

동시행동의 장점은 시간 절약, 단점은 정보 비대칭·통신 두절·독립 사건 가능성이다.

가족 분리 시 GM은 각 팀의 경과시간과 사건을 별도로 진행한다. 재합류할 때까지 상대 팀의 모든 정보를 자동 공개하지 않는다.

## 8. 정보 불확실성 시스템
정보는 출처에 따라 완전성·정확도·시간차가 다를 수 있다.
- 직접 목격
- 가족/NPC 진술
- 주민 말
- 단톡방/SNS
- 뉴스
- 재난문자
- 관리사무소
- 경찰·소방·행정

본편에서는 서로 충돌하는 정보가 존재할 수 있다. 단, GM이 정답을 숨기기 위해 무작위 거짓말을 남발하지 않는다. 각 출처가 왜 틀리거나 늦을 수 있는지 세계 내부 이유가 있어야 한다.

## 9. 선택의 대가와 장기 분기 회수
좋은 선택은 무료가 아니다.
예:
- 더 안전한 우회로 = 시간 손실
- 물자 확보 = 이동 지연
- 가족 분리 = 병렬행동 가능 + 통신/재합류 위험
- 차량 유지 = 연료·도로 의존
- 이웃 지원 = 자원/시간 소모 + 후반 관계 보상 가능

초반 선택은 후반에 다시 회수한다.
- 차량 포기 → 후반 장거리 이동 제약
- 약 미확보 → 다음날 선택 압박
- 특정 NPC 도움 → 후반 도움/정보로 복귀
- 잘못된 정보 신뢰 → 경로 상실/시간 손실

모든 분기를 회수할 필요는 없지만, 시즌당 최소 2개의 장기 인과관계를 의도적으로 설계한다.

## 10. Fail-Forward
실패는 이야기 종료가 아니라 새로운 상태로의 전환이다.
가능한 결과:
- 자원 일부 손실
- 차량 또는 거점 상실
- 가족 분리
- 이동경로 폐쇄
- 피로/부상 증가
- 관계 악화
- 선택 가능한 경로 축소
- 원래 목표 포기와 새로운 목표 설정

중대한 결과는 전조·합리적 원인이 있어야 한다. 플레이어가 알 수 없었던 단일 함정 때문에 즉시 종료시키지 않는다.

## 11. 플레이 중 해설 정책
정식 본편에서는 다음을 최소화/금지한다.
- `좋은 선택이다`
- `이제 장기전으로 넘어간다`
- `이 선택은 위험하다`
- 선택의 의미를 미리 해설

플레이 화면은 기본적으로 `상황 → 행동 → 결과`로 유지한다.
현실 생존지식, 잘한 점, 실수 평가는 시즌 종료 후 사용자가 요청할 때 AAR로 제공한다.

## 12. 시각 후보 태그
시나리오 초안과 플레이 중 장면 메모에는 다음 태그를 허용한다.
- `[삽화 후보] 장면 설명`
- `[영상 후보] 장면 설명`

태그는 제작 지시가 아니라 후보 표시다. 시즌 확정 전에는 실제 이미지/영상을 제작하지 않는다.

## 13. Visual Bible 및 미디어 제작
정식 시즌이 플레이테스트와 수정까지 끝난 뒤 진행한다.
Visual Bible 최소 항목:
- 가족 4명 외모/연령감/체형
- 기본 복장과 계절별 변형
- 표정 범위
- 세계관 건축/도시 분위기
- 화풍
- 색감
- 화면비
- 카메라 거리와 렌즈 느낌
- 재난 표현 강도

이후 시즌 전체를 다시 검토해 핵심 삽화와 영상만 제작한다. 모든 선택지마다 이미지를 만들지 않는다.

2. 기획 승인/동결

4. 플레이어 체감 평가
5. 플레이테스트 기록
6. 기획방: 원인 분석 및 규칙/시즌 수정
7. 필요 시 재플레이

9. Visual Bible/삽화/영상 제작
10. 외부 플레이어용 버전 준비

핵심 원칙: `기획방에서 세계와 압력을 설계하고, 플레이방에서 이야기를 발견한다.`
