# Base Growth Rule

## Purpose
장기 시리즈에서 외곽거점의 성장 보상은 유지하되, 플레이가 반복 정비·구매·재고관리 중심의 건설 시뮬레이션으로 변하는 것을 방지한다.

## Base Growth Is Permanent Rule
- 실제 플레이와 장기계획을 통해 획득·검증된 거점 개선은 장기 Canon에 누적한다.
- 시즌 종료 시 거점 능력을 원상복구하거나 난이도 조정을 위해 임의로 약화하지 않는다.
- 여러 시즌을 거치면 외곽거점은 평범한 외곽주택에서 재난에 강한 두 번째 거점, 더 나아가 상당 기간 독립생활이 가능한 가족 거점으로 발전할 수 있다.
- 강한 거점은 장기 플레이의 정당한 성과이며, 모든 재난에서 항상 정답인 만능기지가 되는 것은 아니다.

## Upgrade by Need Rule
- 새 거점 능력은 실제 재난에서 드러난 취약점 또는 플레이어가 명시한 장기계획을 근거로 발전시킨다.
- 업그레이드 메뉴를 채우기 위해 의미 없는 설비·부품·단계를 추가하지 않는다.
- 플레이어는 가능하면 `전력 자립도 강화`, `수자원 안정성 강화`, `식량 저장능력 강화`, `장기체류성 강화`처럼 큰 프로젝트 방향을 결정한다.
- 세부 구매·설치·정리·부품선택은 전략적 차이가 없으면 AUTO 처리한다.
- 의미 있는 사양 차이, 비용 차이, 장기 트레이드오프가 있을 때만 직접 선택으로 올린다.

## No Maintenance Gameplay Rule
- 이미 구축된 능력의 정상적인 정비, 재고순환, 창고정리, 충전, 텃밭관리, 기본 점검은 배경 운영으로 처리한다.
- 정상 상태는 필요 시 `[AUTO] 외곽거점 정기관리 — 정상` 정도로만 표시한다.
- 이상, 고장, 자원 임계점, 전략적 변경, 의미 있는 비용 또는 외생 압력과 충돌할 때만 직접 플레이로 복귀한다.
- 거점을 키우는 재미는 유지하고, 거점을 유지하는 반복노동은 최소화한다.

## Capability-Based Base Model
거점은 장기적으로 세부 아이템 목록보다 실질 능력 중심으로 관리한다.

권장 능력축:
- 물
- 전력
- 식량
- 주거·보수
- 이동
- 통신·정보
- 생활 지속성
- 사회적 협력 능력은 별도 관계 Canon으로 관리

플레이어 화면에는 필요할 때만 `강함 / 부분 자립 / 복수 수단 확보 / 취약` 같은 판단 가능한 질적 상태를 보여준다.
세부 수량과 내부 상태는 실제 선택에 필요할 때만 높은 해상도로 공개한다.

## Two-Base Identity
- 도심 아파트는 일상·직장·학교·의료·행정·상업 접근 중심의 정상사회 거점이다.
- 외곽주택은 비상·장기체류·비축·보수·회복탄력성 중심의 두 번째 거점이다.
- 외곽거점이 강해져도 가족이 자동으로 상시 농촌 생존생활로 전환하지 않는다.
- 어느 거점이 유리한지는 재난 종류, 위치, 시간, 가족 배치, 외부 의무에 따라 달라진다.
- 핵심은 `강한 거점 ≠ 항상 정답 거점`이다.

## Design Test
새 거점 관련 장면을 직접 플레이하기 전 다음을 확인한다.
1. 새로운 전략적 결정이 있는가?
2. 이전 재난에서 발견된 취약점 또는 플레이어 장기계획과 연결되는가?
3. 시간·비용·능력·위치 중 의미 있는 트레이드오프가 있는가?

세 항목이 모두 아니면 AUTO 또는 시간 압축을 우선한다.
