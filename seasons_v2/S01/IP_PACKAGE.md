# 《생존일기》 Canon v2 — 정식 S01 IP Package

Status: lightweight season-end capture

## 1. 한 줄 로그라인

평범한 한국 가족이 산불로 흩어진 뒤 약 1년의 대피·복귀·전력·물류·소득 위기를 통과하며, `한 사람이 모두 지키는 가족`에서 `각자가 판단하고 다시 합류할 수 있는 가족`으로 변한다.

## 2. 핵심 장면 후보

1. 산불 초기 — 가족이 흩어진 상태에서 서로의 위치와 안전을 확인하는 장면
2. 대피소 — 기존 일상이 더 이상 당연하지 않다는 첫 체감
3. 호텔 — 임시생활이 단기 대피를 넘어 생활문제로 바뀌는 구간
4. 남쪽 임시거점 — 거주지 선택 자체가 생존 판단이 되는 구간
5. 아파트 복귀 — 돌아가는 것이 곧 `원상복귀`는 아니라는 확인
6. 외곽주택 복구 — 정호의 집이 실제 2차 거점으로 변하는 과정
7. 전력위기·물류 차질 — 재난 뒤의 사회기반 압력이 가족 생활을 다시 흔드는 구간
8. 생활서비스·지역 협업 — 재난 대응이 새로운 소득/관계 방식으로 이어지는 구간
9. 1년 후 가족회의 — 무엇을 평시에도 남길지 스스로 줄이고 선택하는 장면
10. 마지막 저장 — 민석이 기록 파일 이름을 묻고 준호가 `시즌 1`이라고 답하는 장면

## 3. 가족 Character Arc

### 한준호
`모든 것을 직접 확인·통제하려는 사람` → `가족의 독립 판단과 위임을 받아들이기 시작한 사람`

### 서윤
`가족 생활을 지키는 사람` → `위기에서도 자기 기준으로 판단하는 공동 의사결정자`

### 민석
`보호받는 자녀` → `정보·기록·상황판을 맡는 실제 가족 운영 참여자`

### 정호
`나이 때문에 보호받을 수 있는 아버지` → `자기 거점을 스스로 운영하면서 가족과 협력하는 독립 인물`

## 4. 주요 선택과 지속 결과

- 가족 합류를 `무조건 한곳`이 아니라 조건부 분산·합류 규칙으로 정착
- 도심 아파트 + 외곽주택의 유연한 이중거점 생활 정착
- B-2를 고정 자산이 아닌 제3 퇴로 정보로 유지
- 차량 비축을 과잉적재에서 핵심 비상품목만 남기는 방식으로 축소
- 가정 비축을 중간 수준 순환형으로 전환
- 비상현금 유지
- 상황판은 비상시에만 재가동
- 생활서비스는 2인 소규모로 유지하고 무리한 사업확장 중단
- 외곽주택은 적극 확장보다 유지·수리 중심으로 전환

## 5. 재사용 가능한 사건 원형

- 가족이 서로 다른 위치에 있을 때의 동시 판단
- `대피 성공` 이후 시작되는 장기 생활비용
- 임시거점 → 복귀 → 2차 거점 재정의
- 인프라 위기가 소득·물류 문제로 이어지는 연쇄
- 재난 중 생긴 임시 협업이 평시 관계로 남는 과정
- 재난 종료 후 `무엇을 버리고 무엇을 남길지` 결정하는 후일담형 시즌 엔딩

## 6. 이번 시즌에서 확인된 IP 강점

- 가족 4명의 역할 차이가 장기 서사로 이어질 수 있음
- 생존장비 자체보다 가족관계와 생활운영 변화가 엔딩의 감정축이 될 수 있음
- 시즌 종료 생존복기가 본편과 자연스럽게 연결됨
- 웹게임, 웹소설, 오디오드라마 모두에서 `1년 뒤 가족회의` 같은 정리 장면의 각색 가치가 높음

## 7. 다음 각색 시 주의

- 산불 소재 자체보다 `가족 분산 → 장기 후속위기 → 생활에 남은 변화`가 시즌의 고유 핵심이다.
- 거점 건설/비축 과정만 길게 나열하면 드라마성이 떨어질 수 있다.
- 가족의 독립성이 약해지면 Canon v2의 가장 큰 성과가 사라진다.
- 실제 발생하지 않은 분기 아이디어는 Playthrough Canon과 섞지 않는다.

## 8. 매체별 한 줄 평가

- 웹게임: 매우 높음 — 선택·자유행동·장기상태 누적과 직접 연결
- 웹소설: 높음 — 가족 4인의 시점과 장기 위기 전환 활용 가능
- 웹툰: 높음 — 산불/대피/임시거점/가족회의 등 시각적 장면이 명확함
- 오디오드라마: 높음 — 가족 대사와 재난정보/통신 장면 활용도가 높음
