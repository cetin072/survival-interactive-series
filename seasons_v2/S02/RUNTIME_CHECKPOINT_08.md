# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 08

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 16
- 회사·직장 제한 운영 재개 가능성이 생기기 시작한 단계

## 플레이어 결정
- 준호·서윤이 제한근무로 외부에 나가더라도 외곽 거점이 유지되도록 가족 역할을 재편한다.
- 정호·민석이 단순 보호대상이 아니라 실제 거점 유지 인력으로 기능하도록 한다.

## 현재 가족 역할
- 준호: 외부자원·행정·운송·전력/물 인프라 연결, 장거리/긴급 판단.
- 서윤: 생활·의약·위생·가족상태 판단, 외부근무 가능성 대비.
- 정호: 외곽거점 현장 운영, 텃밭, B/D집 및 지역 신뢰망 연결, 현장 판단.
- 민석: 기준시각·공식정보 검증, 기록, 연락망 정리, 거점 이상 징후 보고. 독립 판단 역할 확대.

## 현재 거점 핵심 자산
- 전력 LV.3: 태양광 패널 추가 4장, 저장배터리 추가 2세트 누적, 제어장치 보강, 예비부품.
- 물 저장 LV.2: 500L 탱크 2기, 최근 약 650L 저장 + 기존 소형 비축.
- 식량생산 LV.2: 텃밭 1.6배, 농사 조언가구와 상호 노동관계, 2차 확장은 성과 검증 후.
- 이동 LV.2+: 유류차 1, 가족 EV 1, 협력 EV-C 1. 가족 EV는 공공운송망 예비차량.
- 도심 아파트: 장기 비상 예비거점 LV.1+, 같은 층 상주 연락가구 1곳.
- 신뢰망: B집, D집, 농사 조언가구, EV-C 가구, 기존 협력가구 일부. 공유재산화 없이 상호지원.

## 운영 방향
- 성인 2명이 상시 거점에 있어야만 굴러가는 구조를 벗어난다.
- 정호와 민석의 판단이 실제 결과에 영향을 미친다.
- 직장 복귀는 곧바로 정상사회 복귀를 뜻하지 않으며, 외곽 거점 유지와 병행되는 새로운 압력으로 취급한다.
- 향후 선택지는 비슷한 답안을 묶고, 3지선다 1개 선택 / 4~5지선다 최대 2개 선택 / 자유행동 유지 규칙을 따른다.
