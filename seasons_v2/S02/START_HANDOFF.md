## S02 시작 공개 Canon

### 가족
- 준호·서윤·민석·정호 네 사람 모두 S01을 생존했다.
- 가족은 준호 한 사람의 직접 통제보다 역할분담·독립판단이 강화된 상태다.
- 서윤은 공동 의사결정자다.
- 민석은 정보·기록 역할 경험이 있다.
- 정호는 외곽주택을 스스로 운영하는 독립성이 확립됐다.
- 가족 합류 규칙은 간단한 핵심 규칙으로 영구 유지한다.

### 거점
- 도심 아파트 = 주 거점
- 정호 외곽주택 = 정호 생활공간 + 가족 실제 2차 거점
- B-2 = 고정 부동산/설비가 아닌 제3 퇴로 정보
- 외곽주택은 공격적 시설확장보다 유지·수리 중심

### 대비
- 차량 비상창고 = 축소 유지
- 가정 비축 = 중간 수준 순환형
- 비상현금 = 제한된 수준 유지
- 민석 상황판 = 평시 중단 / 비상시 재가동
- 이중거점 생활 = 의무가 아니라 유연한 생활 선택지

### 관계·소득
- 지역 정보·거래 관계가 일부 형성돼 있다.
- 생활서비스는 2인 소규모 구조로 남아 있다.
- 본업 우선, 무리한 요청 거절, 공동사업체 확대 없음.

### 세계
- S01의 산불은 종료됐다.
- 전력위기는 안정화 단계다.
- 사회는 기능하고 있으나 가족의 생활과 대비체계는 재난 이전으로 돌아가지 않았다.
- S02 시작에서 이 상태를 `모든 것이 원래대로 복구된 완전 평시`로 리셋하지 않는다.

- 가능한 새로운 안정상태

## S02 Creative Gate

### 1. S01 자산을 인정한다

가족이 S01에서 얻은:
- 2차 거점
- 순환비축
- 비상현금
- 합류 규칙
- 가족 독립성
- 지역 관계

을 억지로 삭제하거나 무효화하지 않는다.

### 2. 그러나 준비가 정답이 되지 않게 한다

기존 준비는 선택권을 늘릴 수 있지만 모든 압력을 자동 해결하지 않는다.

### 3. 행동군 다양성

S01의 다음 흐름을 단순 반복하지 않는다.

`산불 → 가족 회수 → 대피소/호텔 → 외곽 복구 → 비축/시설확충`

새 사건은 플레이어가 다른 종류의 판단을 하게 만들어야 한다.

### 4. 가족 성장 이후의 새 충돌

가족이 성장했다고 의견충돌이 사라지는 것은 아니다.

- 서윤의 독립 판단
- 민석의 역할 확대 욕구
- 정호의 외곽 독립성
- 준호의 위임과 통제 사이의 긴장

이 새 균형이 실제 선택 비용을 만들 수 있다.

### 5. 세계 변화

S01은 가족·생활 변화가 강했고 세계 차원 비가역 변화는 상대적으로 약했다.
S02는 장기 아포칼립스 IP 방향에 맞게 세계 규칙이 변할 가능성을 충분히 가진다.

단, 강제 붕괴나 정해진 손실을 대본으로 만들지는 않는다.

### 6. 운영 압축

반복적인:
- 외곽주택 보수
- 재고 순환
- 생활서비스
- 평시 왕래

는 특별한 변화가 없으면 AUTO/시간점프로 압축한다.
