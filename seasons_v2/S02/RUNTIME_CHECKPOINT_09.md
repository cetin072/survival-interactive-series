# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 09

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 17 오전
- 준호 회사와 서윤 직장이 제한근무 재개 가능성을 타진하는 단계

## 플레이어 결정
- 준호는 제한근무 요청을 즉시 수락하지 않는다.
- 근무 의사는 명확히 밝힌다.
- 다만 현재 연료·충전·교통 여건에서 출퇴근 에너지 비용을 개인이 계속 부담하는 것은 물리적으로 지속 불가능하다고 회사에 알린다.
- 회사가 출퇴근 유류/충전 또는 이에 준하는 이동수단 지원을 제공하지 못하면 출근은 불가능하다는 조건을 제시한다.
- 이는 근무 거부가 아니라 이동수단 제약으로 인한 조건부 불가이다.

## 현재 가족 운영
- 외곽주택은 준호·서윤이 없어도 정호와 민석 중심으로 단기 운영 가능함이 확인됨.
- 정호는 현장 판단과 텃밭·B/D집·설비 문제 대응 권한을 가짐.
- 민석은 기준시각, 전력·물, EV 충전, 신뢰망 연락과 이상징후 검증을 담당.
- 준호·서윤 외부근무 재개 시 출근일을 엇갈리게 하는 방식은 여전히 후보이나, 우선 이동에너지 조건 해결이 선행되어야 함.

## 이동 원칙 확장
- 공공 운송과 동일하게 직장 출퇴근도 실제 이동에너지 비용을 발생시키는 행위로 취급한다.
- 가족 유류차의 비축연료는 무제한 통근에 소모하지 않는다.
- 가족 EV도 장거리 통근 시 외곽 거점 전력과 경쟁하므로 무상·무제한 통근수단으로 취급하지 않는다.
- '안 간다'가 아니라 '이동 에너지가 공급되지 않으면 못 간다'는 원칙을 유지한다.
