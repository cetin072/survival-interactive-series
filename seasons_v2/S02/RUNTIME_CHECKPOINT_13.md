# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 13

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 205 이후
- 외곽이 공식 주 생활권으로 굳어졌고, 지역분산 사회체계가 장기화된 단계

## 플레이어 결정
- 지역 소규모 전력망에는 참여하지 않는다.
- 외곽주택 전력 LV.3의 독립 운용을 유지한다.
- 가족 필수전력과 비상저장량을 외부 배분체계에 연결하지 않는다.
- 정비·부품 문제는 기존 전력업자, 신뢰망, 거래선으로 해결한다.

## 현재 전력 상태
- 태양광 패널 4장 추가 설치 완료.
- 저장배터리 추가 2세트 누적.
- 제어장치 보강.
- 예비 전력부품 1세트.
- 가족 EV 1대와 연계.
- 지역망과 미연결 상태로 독립 운용.

## 효과와 비용
### 장점
- 가족 전력 자산과 운용권 완전 유지.
- 지역 전력난에 따른 잉여전력 제공 의무·압력 없음.
- 비상저장량 기준을 가족이 독자적으로 결정 가능.

### 비용
- 공식 전력망 정비지원과 부품 우선배정 혜택을 받지 못함.
- 배터리/인버터 고장 시 자체 거래선과 기존 기술자 관계에 더 의존.
- 지역망에서 남는 외부 전력을 받을 수 있는 기회 없음.

## 운영 원칙
- 큰 변화가 없으면 AUTO 진행.
- 자잘한 사건·거점 유지·일상 갈등은 자동 처리.
- 구조적 사회변화, 가족관계 변화, 자산의 큰 손실/획득, 장기정책 선택에서만 멈춘다.
