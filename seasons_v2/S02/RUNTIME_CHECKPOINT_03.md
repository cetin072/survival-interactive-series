## B집 수원
- 주 펌프 1대 정상
- 예비 펌프 후보 1대 확보, 작동 확인 전
- 펌프·배관 유지부품 확보
- B집·준호 가족·전력업자 간 상호 거래관계 형성
- 민간 우물/지하수는 사유재산 원칙 유지, 현 단계 행정 비상수원 등록 안 함

## 운영 원칙 업데이트
- 마을/공공 목적 차량 운송은 개인 가족 연료를 무상 소모하지 않음
- 운송 요청 시 필요한 왕복 연료를 행정/마을이 부담해야 수행 가능
- 협력망 운영·민원·기여도 관리는 이장 중심으로 이관
- 준호 가족은 영향력은 유지하되 직접 배분권·민원창구 역할은 최소화

## 플레이어 피드백 반영
- 거점 성장 효과를 실제 설치 자산과 기능 변화로 명확히 표시
- 태양광, 저장전력, 펌프 예비화, 텃밭 확장 등은 구체적 자산/효과 단위로 표현
- 세계관에 전기차가 존재함을 자연스럽게 반영
- 전기차는 유류 독립 장점이 있으나 전력망/충전 인프라 제약을 가짐
