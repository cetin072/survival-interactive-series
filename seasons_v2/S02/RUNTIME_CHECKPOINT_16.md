# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 16

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 520 이후
- 외곽주택이 가족의 장기 본거지로 정착한 뒤, 노후 저장배터리 성능저하가 발생한 단계

## 플레이어 결정
- 성능이 떨어진 저장배터리 1세트를 교체한다.
- 지역 소규모 전력망에는 연결하지 않는다.
- 비용을 감수하고 가족 독립전력 체계의 완전성을 유지한다.

## 실제 자산 변화
- 노후 저장배터리 1세트: 성능저하 상태에서 교체 완료.
- 교체품: 같은 급의 사용 가능한 저장배터리 세트로 설치 및 작동 확인.
- 기존 태양광 추가 패널 4장, 다른 저장배터리 세트, 전력 제어설비, 예비부품 체계는 유지.

## 현재 전력 상태
- 전력 LV.3 완전 회복.
- 맑은 날 생활전력 안정.
- 흐린 날·야간 저장 여유가 성능저하 이전 수준으로 회복.
- 가족 EV 충전과 필수 생활전력 병행 가능성이 다시 높아짐.
- 지역망과 연결되지 않아 외부 전력 의존·잉여전력 제공 의무 없음.
- 대신 교체 비용과 향후 독립 정비·부품 확보 부담은 가족이 계속 부담.

## 장기 구조
- 외곽주택: 가족 4인의 공동 생활거점이자 공식 주 생활권.
- 도심 아파트: 장기 예비거점 및 직장 접근 자산.
- 큰 변화가 없으면 자잘한 유지·거래·출퇴근·소규모 사건은 AUTO 처리.
