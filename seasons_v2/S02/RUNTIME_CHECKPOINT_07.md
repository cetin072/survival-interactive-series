# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 07

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 14 이후
- 외곽주택이 가족의 실질적 주거·생존 거점으로 굳어지는 단계

## 플레이어 결정
- 도심 아파트를 포기하지 않는다.
- 한 번 정리하러 가서 핵심물품을 회수하고, 장기간 비워도 되는 상태로 만든다.
- 도심 아파트의 역할은 평시 생활거점에서 장기 비상 예비거점으로 낮춘다.

## 현재 외곽주택 핵심 자산
- 전력 LV.3: 기존 보조전력 + 태양광 패널 4장 추가 + 저장배터리 추가 2세트(누적) + 제어장치 보강 + 예비 전력부품.
- 물 저장 LV.2: 500L급 탱크 2기, 최근 대형탱크 저장수 약 650L 수준 + 기존 소형 비축.
- 식량생산 LV.2: 텃밭 기존 대비 약 1.6배, 농사 조언가구와 상호 노동관계, 2차 확장은 실제 성과 검증 후.
- 이동 LV.2+: 준호 유류차 1대, 가족 소유 EV 1대, 협력 EV-C 전기화물차 1대. 가족 EV는 필수 단거리 공공운송망의 예비차량으로만 참여.
- 신뢰망: B집, D집, 농사 조언가구, EV-C 가구, 기존 협력가구 일부. 공유재산화하지 않고 최소 상호지원 기록만 유지.

## 도심 아파트의 기존 상태
- 가족 소유 자산으로 유지 중.
- 전력·상수도·엘리베이터 등 생활기능이 불안정해 장기 상시거주 적합성은 떨어지고 있다.
- 일부 장기보관 물품, 의류·생활용품, 개인 중요물품이 남아 있다.
- 도시 생활 정상화 시 복귀 기반으로서의 가치는 남아 있다.

## 운영 원칙
- 도심 아파트를 버리거나 매각한 것으로 처리하지 않는다.
- 회수한 물품은 실제 필요한 핵심품 위주로 제한하고, 모든 것을 외곽으로 옮겨 만능화하지 않는다.
- 도시 방문은 이동에너지와 시간 비용을 실제로 발생시킨다.
- 외곽 거점의 성장 효과는 실제 설치·확보된 자산과 기능 변화로 명확하게 표현한다.
