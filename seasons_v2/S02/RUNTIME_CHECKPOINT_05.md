# 《생존일기》 Canon v2 — S02 Runtime Checkpoint 05

Status: LIVE RUNTIME CHECKPOINT

## 시점
- DAY 10 오전 이후
- 외곽주택이 실질적 가족 거점으로 기능 중

## 플레이어 결정
- 기존 신뢰가구들과의 신뢰망을 더 강화한다.
- 상호지원은 유지하되 공유재산화·공식 조직화는 피한다.
- 누가 무엇을 얼마나 제공했는지 최소 기록을 남겨 반복적 일방부담을 막는다.
- 텃밭은 기존 대비 약 1.6배로 확장된 1차 상태를 유지하고 실제 성과를 본 뒤 2차 확장 여부를 결정한다.
- 중고 저장배터리 거래를 받아들여 전력 LV.3 업그레이드를 진행한다.

## 현재 핵심 신뢰망
- B집: 전동 지하수, 주 펌프 1대, 작동 확인된 예비 펌프 1대, 펌프/배관 예비부품 1세트. 준호 가족과 상호투자 관계.
- D집: 무전력 수동우물. 생활·운송 상호지원 관계. 급할 때 먼저 연락 가능한 신뢰관계.
- 농사 조언가구: 20년 이상 소규모 밭농사 경험. 텃밭 조언 및 상호 노동교환 관계.
- EV-C 가구: 소형 전기화물차 소유. 준호 가족 잉여전력과 지역 운송을 교환하는 개인 협력관계.
- 기존 협력가구 일부: 정보, 인력, 운송, 물자 교환 관계.

## 거점 자산 상태
### 전력
- 기존 보조전력 설비 운용 중.
- 태양광 패널 4장 추가 설치 완료.
- 저장배터리 1세트 추가 설치 완료(LV.2 시점).
- 전력 제어장치 1대 보강.
- 예비 전력부품 1세트 보유.
- 가족 소유 EV 1대 확보.
- 추가 중고 저장배터리 1세트 거래 결정, 설치 진행 예정(LV.3 후보).

### 물
- 외곽주택 자체 우물 없음.
- 500L급 저장탱크 2기 추가 설치, 저장능력 약 +1,000L.
- B집 전동 지하수 및 D집 무전력 수원과 신뢰 기반 거래관계.
- 수질 미확인 물은 용도 구분 원칙 유지.

### 식량생산
- 텃밭 1차 확장 완료: 기존 대비 약 1.6배 재배면적.
- 2차 확장은 보류. 실제 수확성과, 노동부담, 물 부담 확인 후 결정.

### 이동
- 준호 유류차 1대: 장거리/긴급용, 연료 희소.
- 가족 EV 1대: 단거리/일상 이동 우선, 외곽 태양광과 연계.
- EV-C 전기화물차: 타 가구 소유, 운송 협력관계.
- 공공 운송은 이동 에너지 비용 보전이 있어야 수행한다는 원칙 확립.

## 운영 원칙
- 가족/신뢰망 자원은 자동 공공재가 아니다.
- 마을 공공업무·민원·배분 판단은 이장 중심 체계에 둔다.
- 개인 우물은 사유재산이며 소유가구 필요량 우선, 남는 범위에서만 자발 거래/지원.
- 핵심 생존자원은 봉사·기여도 순 우선배분하지 않는다.
- 기여도는 거래조건 우대나 다른 자원/노동 보상에 반영 가능.
- 신뢰망은 공동창고/공동소유가 아니라 상호연락·상호지원 구조로 유지.
- 최소 상호지원 기록은 반복적 일방부담 방지 목적이며 점수화·계급화하지 않는다.

## 표현/게임 시스템 피드백
- 향후 거점 성장 표현은 '강화됨' 같은 추상 표현 대신 실제 설치/확보된 자산, 상태, 효과를 명확히 제시한다.
- 전력, 물, 텃밭, 이동수단 등은 실제 자산 변화와 사용효과를 구체적으로 보여준다.
- 전기차는 세계관에 존재하며 유류차의 완전한 상위호환이 아니다. 충전전력·날씨·저장전력과 경쟁하는 별도 자원축으로 취급한다.
