# PROJECT DECISIONS — Long-term Canon

이 문서는 기획방에서 합의한 장기 운영 결정을 요약한다. 새 채팅이나 장기 공백 이후에도 이 문서를 기준으로 방향을 유지한다.

## 프로젝트 정체성
- 가칭: `생존기록` (정식명 미확정)
- 장르: 현대 가족 생존 인터랙티브 드라마 / MUD + 선택지 + 자유행동
- 주 타깃: 30~40대 남성
- 재미와 몰입이 최우선이며, 실제 생존지식은 플레이를 통해 자연스럽게 체득하게 한다.
- 플레이 중 메타 강의는 하지 않는다. 현실 피드백은 시즌 종료 후 선택형 AAR로만 제공한다.

## 가족 기본 구조
- 한준호(본인) 41세
- 서윤(아내) 39세
- 민석(아들) 13세, 중학교 1학년
- 정호(아버지) 68세
- 가족 4명은 수동 NPC가 아니라 각자 자율행동·의견·실수·갈등·피로·공포·경험 누적을 가진 독립 파티원이다.
- 자녀는 보호 대상이지만 완전 수동이 되지 않도록 중학생을 기본값으로 둔다.

## 시즌 설계
- `한 시즌 = 하나의 주요 사건/재난`을 기본으로 한다.
- 시즌 길이와 화수는 고정하지 않는다. 6화는 참고 감각일 뿐이며 완성도와 긴장 구조에 따라 유연하게 결정한다.
- 여러 시즌을 미리 완성해 두지 않는다. 먼저 한 시즌씩 실제 플레이하고 재미 공식을 발견한다.
- 기존 홍수/정전 플레이는 공식 Season 1이 아니라 튜토리얼/프로토타입으로 본다.
- 공식 Season 1은 완전히 새로운 사건으로 Day 0의 평범한 일상에서 시작한다.

## 시나리오 생성 방식
- 완성 대본을 미리 읽어주는 구조가 아니다.
- GM은 시즌 시작 시 비공개로 `세계 상태 / 재난의 본질 / 숨은 위험 / NPC 목적 / 시간 이벤트 / 조건부 이벤트 / 가능한 종료 상태`를 먼저 설정한다.
- 플레이어의 실제 행동과 선택에 따라 세부 이야기는 즉흥적으로 생성된다.
- 핵심 원칙: `GM은 세계와 위험을 먼저 만들고, 이야기는 플레이어가 만든다.`
- 선택 후 결과를 맞추기 위해 숨은 상태를 소급 변경하지 않는다.
- 플레이어가 보지 않은 사건·NPC·장소도 세계 안에서 독립적으로 진행될 수 있다.

## 시즌이 끝난 뒤 자산화
한 시즌의 첫 플레이는 동시에 프로토타입, 플레이테스트, 공동 창작이다.
시즌 종료 후 아래 두 자산을 분리한다.
1. 실제 플레이 스토리: 사용자가 실제 선택해서 경험한 서사
2. 정식 시나리오 구조: 미사용 사건·다른 갈림길·다른 결말 후보까지 포함한 재사용 가능한 시나리오

정리 후 해당 시즌을 `Scenario v1.0`으로 만들 수 있다. 이후 다른 플레이어는 같은 세계/시나리오 뼈대를 사용하되 AI가 세부 장면과 대화를 유연하게 생성한다.

## 다른 플레이어를 위한 장기 방향
- 시나리오 데이터와 플레이어 세이브를 분리한다.
- 같은 시즌을 여러 사람이 서로 다른 선택으로 플레이할 수 있게 한다.
- 장기적으로 웹 기반 인터랙티브 게임으로 확장할 수 있으나 최소 3개 이상의 시즌을 실제 플레이해 재미를 검증하기 전에는 웹앱/DB/회원가입/대형 게임엔진 개발을 하지 않는다.

## 이미지/삽화 방향
- 첫 플레이 도중에는 삽화를 미리 제작하지 않는다.
- 시즌 완성 후 재사용 가치가 높은 장면만 추출해 삽화 자산으로 만든다.
- 공용 자산: 가족 캐릭터, 집, 동네, 도시 랜드마크, 차량, 대피소, 주요 반복 장소 등.
- 시즌 전용 자산: 대표 재난 장면, 핵심 사건, 중요한 갈림길, 클라이맥스, 엔딩 장면 등.
- 목표 UX: 최초 공동창작 플레이는 텍스트 중심, 이후 다른 플레이어용 버전은 웹소설처럼 중요한 지점에 삽화를 배치한다.

## 정보 저장 원칙
- GitHub `cetin072/survival-interactive-series`가 Source of Truth다.
- ChatGPT 기억이나 이전 채팅보다 저장소의 최신 Canon / State / Log를 우선한다.
- 아이디어는 우선 INBOX에 잃지 않게 저장하고 이후 분류한다.
- 사용자는 저장 위치를 기억할 필요가 없다.

## 메타 명령
- `생존기록 시작` / `새 생존게임 시작` → 새 시즌 시작
- `생존기록 이어서` / `생존게임 이어서` → 최신 저장 상태에서 계속
- `메모: ...` → 아이디어 보존 및 분류
- `설정확정: ...` → 공식 설정으로 승격
- `버그: ...` → 플레이테스트 문제 기록
- `상태` → 플레이어 공개 상태 요약
- `저장` → 체크포인트 저장
- `종료` → 현재 상태 저장 후 세션 종료

## 공개 저장소 주의
- 현재 저장소는 Public이다.
- API 키, 토큰, 비밀번호, 실제 개인 주소·연락처·민감정보를 저장하지 않는다.
- 외부 플레이어가 실제로 생기면 GM 스포일러 데이터는 별도 Private 저장소나 서버측 저장소로 분리하는 것을 검토한다.
