# PROJECT DECISIONS — Design Reference v2

이 문서는 **프로젝트의 장기 제작 방향**만 기록한다.
실제 플레이 런타임에는 기본 로드하지 않는다.

> 캐릭터 최신값: `core/CHARACTERS.json`
> 지속 세계/거점/관계: `core/PERSISTENT_CANON.md`
> 플레이 운영 핵심: `runtime/GM_KERNEL.md`

## 프로젝트 정체성
- 가칭: `생존기록` — 정식명 미확정.
- 장르: 현대 가족 생존 인터랙티브 드라마 / MUD + 숫자 선택지 + 자유행동.
- 주 타깃: 30~40대 남성.
- **재미와 몰입이 0순위**다.
- 현실 생존 해설은 본편에 끼우지 않고 시즌 종료 후 선택형 AAR로 분리한다.

## 캐릭터 관리
가족의 나이·학년·성향·역할을 이 문서에 중복 저장하지 않는다.
`core/CHARACTERS.json`이 최신 캐릭터 Source of Truth다.

가족 4명은 독립 파티원이며 자율행동·의견·실수·갈등·경험 누적이 가능하다.

## 조작 원칙
복잡한 세계를 단순한 입력으로 다룬다.
- 숫자 선택
- `3 → 5 → 1` 순차 복수선택
- 필요 시 가족 역할분담
- 자유행동

복수선택의 세부 비용 규칙은 `runtime/GM_KERNEL.md`를 따른다.

## 정식 시즌 제작 철학
완성 대본을 먼저 만들지 않는다.
플레이 직전 Hidden World Seed만 잠근다.

핵심:
`세계는 먼저 존재하고, 이야기는 플레이로 생긴다.`

첫 플레이 전 미리 고정하지 않는 것:
- 정답 루트
- 의무 장면 순서
- 확정 클라이맥스
- 하나의 확정 엔딩

## 작품의 핵심 재미 축
1. **거점 성장** — 단순 재고가 아니라 할 수 있는 일의 증가.
2. **이해관계 기반 협업** — 가족·이웃·기관 사이의 제한과 비용이 있는 협력.
3. **독립적인 세계 압력** — 플레이어가 준비해도 세계는 계속 움직임.
4. **가족 운영** — 4인이 보호대상/기능NPC가 아니라 실제 파티로 작동.
5. **비싼 선택** — 무엇을 할지보다 무엇을 포기할지가 중요해짐.

## 본편 품질 기준
- 정보 불확실성 또는 충돌.
- 선택의 시간·자원·기회비용.
- 가족/NPC 독립행동.
- 실질적 손실 가능성.
- 이전 선택이 나중에 돌아오는 인과관계.
- Fail-Forward.
- 장기 시즌은 의미 있는 Phase 변화.
- 평온한 반복 운영은 과감히 압축.

## 난이도
정식 본편 기본은 NORMAL 계열.
난이도는 사건 수를 마구 늘리는 방식보다:
- 선택 비용
- 정보 부족
- 시간 압력
- 회복 여유
- 동시 요구 충돌
로 조정한다.

## 시각 자산
- 기본은 텍스트 + 선택 + 핵심 시각요소.
- 플레이 중에는 텍스트 Visual Grammar를 우선한다.
- 실제 삽화/영상은 시즌이 충분히 굳은 뒤 선별 제작한다.
- 핵심 순간의 제한적 비주얼 실험은 가능하다.

## 시즌 종료 후 자산화
필요할 때만:
1. 플레이 Canon 보존
2. 시스템 복기
3. 현실 생존 복기
4. 재사용 가능한 시나리오 구조 추출
5. Branch Map/Scenario 동결 검토
6. Visual Bible/미디어 제작

모든 시즌을 반드시 Scenario v1.0까지 즉시 완성할 필요는 없다.

## 개발 원칙
- GitHub `cetin072/survival-interactive-series`가 장기 Source of Truth다.
- 플레이와 저장 관리는 가볍게 유지한다.
- 충분한 시즌 플레이 검증 전 대형 게임엔진/복잡한 앱 개발을 서두르지 않는다.
- 새 문제가 생길 때마다 새 규칙을 추가하지 않는다. **기존 Kernel로 해결 가능한지 먼저 확인**한다.

## 공개 저장소 주의
저장소는 Public이다.
실제 주소·전화번호·계정정보·비밀번호·토큰·기타 민감정보를 저장하지 않는다.
