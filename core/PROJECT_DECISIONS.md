# PROJECT DECISIONS — Long-term Canon

이 문서는 기획방에서 합의한 장기 운영 결정을 요약한다. 새 채팅이나 장기 공백 이후에도 이 문서를 기준으로 방향을 유지한다.

## 프로젝트 정체성
- 가칭: `생존기록` (정식명 미확정)
- 장르: 현대 가족 생존 인터랙티브 드라마 / MUD + 숫자 선택지 + 자유행동
- 주 타깃: 30~40대 남성
- 재미와 몰입이 최우선이다.
- 실제 생존지식은 플레이 안에서 자연스럽게 체득하고, 메타 해설은 시즌 종료 후 선택형 AAR로만 제공한다.

## 가족 기본 구조
- 한준호(본인) 41세
- 서윤(아내) 39세
- 민석(아들) 13세, 중학교 1학년
- 정호(아버지) 68세
- 가족 4명은 수동 NPC가 아니라 자율행동·의견·실수·갈등·피로·공포·경험 누적을 가진 독립 파티원이다.

## 콘텐츠 번호 체계
- 작품명 `생존기록` 자체에는 번호를 붙이지 않는다.
- 정식 본편: `S01`, `S02`, `S03` ...
- 튜토리얼: `T01`, `T02` ...
- 지진 플레이테스트는 `Tutorial T01: 지진 v0.1`.
- 기존 폭우/정전 테스트는 번호 없는 `Pre-Alpha Prototype`.

## 난이도
- Tutorial: 초보자/어린이/첫 진입자용.
- Standard: 성인 본편 기본. 정보 불확실성, 자원 압박, 가족 변수, 장기 인과 포함.
- Hard: Standard보다 안전 여유와 복구 가능성이 적다.
- 정식 본편의 기본 감각은 Standard와 Hard 사이.
- 상세 기준은 `docs/CORE_GAME_SYSTEMS_V1.md`를 따른다.

## 정식 시즌의 핵심 제작 철학
정식 시즌은 완성 대본을 먼저 쓰고 플레이하는 구조가 아니다.

핵심 원칙:
`세계는 먼저 존재하고, 이야기는 플레이로 생긴다.`

첫 플레이 전에는 `docs/WORLD_SEED_PROTOCOL.md`에 따라 GM이 비공개로 최소한의 월드 골격만 고정한다.
- 재난/사건의 실제 성격
- 도시·인프라 상태
- 숨은 위험
- 주요 장소의 실제 상태
- 가족의 숨은 상태와 우선순위
- 일부 NPC와 목적
- 시간 기반 사건
- 조건부 사건
- 정보 출처별 진실/오해/지연 상태
- 초반 선택이 후반에 돌아올 잠재적 인과 고리
- 가능한 종료 상태 조건

반대로 다음은 첫 플레이 전에 확정하지 않는다.
- 완성된 에피소드 대본
- 반드시 지나야 하는 장면 순서
- 정답 루트
- 확정 클라이맥스
- 하나의 정해진 엔딩

플레이어는 재난 종류조차 반드시 미리 알 필요가 없다. 세부 이야기와 장면은 실제 선택과 자유행동을 통해 발견한다.

## 안티-레트콘
- 중요한 선택 전에 관련 숨은 상태가 필요하면 GM_STATE/EVENTS에 먼저 기록한다.
- 선택 후 결과를 맞추기 위해 세계의 진실을 소급 변경하지 않는다.
- 즉흥 생성은 기존 세계 상태의 자연스러운 결과 범위에서만 허용한다.

## 본편 품질 기준
정식 시즌은 최소한 다음을 포함한다.
- 좋은 선택끼리의 충돌과 실제 포기 비용
- 정보 부족 또는 정보 충돌
- 가족 독립행동/의견/갈등
- 자원·시간·거점·이동수단 등의 실질적 손실 가능성
- 초반 선택이 후반에 돌아오는 장기 인과관계
- 실패해도 다음 상태로 이어지는 Fail-Forward
- 최소 3회 이상의 의미 있는 상황 전환
- 단순 `재난 발생 → 대피 → 안전 확보 → 종료`보다 깊은 변화

## 선택지와 동시행동
- 선택지는 `1, 2, 3...` 숫자를 기본으로 한다.
- 한 개만 선택할 필요가 없고 `3 → 5 → 1`처럼 순서를 지정할 수 있다.
- 행동 순서, 시간, 거리, 동시행동 여부가 실제 결과에 영향을 준다.
- 가족별 역할분담과 동시 행동을 허용한다.
- 자유행동 입력은 항상 허용한다.

## 자원과 정보
- 모든 물건을 아이템화하지 않는다.
- 물, 식량, 약, 전력, 통신, 현금, 연료, 보온, 위생, 이동수단, 거점, 정보, 시간을 핵심 자원으로 본다.
- 자원은 수량뿐 아니라 접근성, 보관 위치, 운반 부담, 누가 들고 있는지를 추적할 수 있다.
- 정보는 직접 목격, 주민, SNS, 뉴스, 재난문자, 관리사무소, 경찰·소방·행정 등 출처마다 정확도와 시간차가 다를 수 있다.

## 플레이 중 해설
정식 본편에서는 `좋은 선택`, `위험한 선택`, `이제 장기전` 같은 GM 메타 평가를 최소화한다.
기본 화면은 `상황 → 행동 → 결과`다.
현실 대응 분석과 플레이 평가는 시즌 종료 후 원할 때 AAR로 제공한다.

## 시즌 종료 후 자산화
첫 플레이는 프로토타입, 플레이테스트, 공동 창작을 동시에 수행한다.
시즌이 끝난 뒤 처음으로:
1. 실제 플레이 스토리 보존
2. 미사용 사건/장소/NPC와 함께 재사용 가능한 시나리오 구조 추출
3. Branch Map 정리
4. 플레이테스트 피드백 반영
5. 현실 생존지식 검증
6. `Scenario v1.0` 동결
7. Visual Bible 제작
8. 삽화/영상 후보 선별 및 제작

## 시각 자산
- 플레이 중에는 `[삽화 후보]`, `[영상 후보]`만 기록한다.
- 시즌이 굳기 전 실제 제작하지 않는다.
- 시즌 확정 후 가족 4명, 주요 랜드마크, 반복 장소를 공용 자산으로 만들고 시즌 대표 사건·갈림길·클라이맥스는 시즌 전용 자산으로 만든다.
- 기본은 텍스트 + 선택 + 핵심 삽화이며, 정말 중요한 순간만 짧은 영상을 검토한다.

## 플레이방 ↔ 기획방 루프
1. 기획방: 시스템 원칙과 월드 시드 생성 규칙 관리
2. 플레이 직전: GM이 비공개 월드 시드 생성
3. 플레이방: 실제 플레이로 이야기 발견
4. 사용자 체감 평가
5. 기획방: 문제 원인 분석 및 시스템 수정
6. 필요 시 재플레이
7. Scenario v1.0 동결
8. Visual Bible/미디어 제작

## 장기 개발
- GitHub `cetin072/survival-interactive-series`가 Source of Truth다.
- 시나리오와 플레이어 세이브를 분리한다.
- 최소 3개 이상의 정식 시즌을 실제 플레이해 재미를 검증하기 전에는 웹앱/DB/대형 게임엔진 개발을 서두르지 않는다.

## 메타 명령
- `생존기록 시작` / `새 생존게임 시작` → 새 정식 시즌 또는 지정 튜토리얼 시작
- `생존기록 이어서` / `생존게임 이어서` → 최신 상태에서 계속
- `메모: ...` → 아이디어 저장
- `설정확정: ...` → 공식 설정 승격
- `버그: ...` → 플레이테스트 문제 기록
- `상태` → 공개 상태 요약
- `저장` → 체크포인트 저장
- `종료` → 현재 상태 저장 후 종료

## 공개 저장소 주의
현재 저장소는 Public이다. API 키, 토큰, 비밀번호, 실제 주소·연락처 등 민감정보를 저장하지 않는다.
