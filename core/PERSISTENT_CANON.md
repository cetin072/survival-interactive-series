# Persistent Canon — 시즌 간 누적 세계 상태

이 문서는 시즌별 요약을 넘어, 이후 모든 시즌에서 유지되어야 하는 누적 Canon의 단일 기준점이다.

## 목적
- 시즌이 바뀌어도 가족·거점·NPC·관계·시설의 핵심 사실과 인과관계를 잃지 않는다.
- 직전 시즌 요약만 연쇄적으로 읽다가 세부 설정이 압축·변형되는 문제를 방지한다.
- 새 시즌 시작 전 GM이 반드시 읽는 장기 상태 원본으로 사용한다.

## Source of Truth 우선순위
설정 충돌 시 다음 순서를 따른다.
1. 사용자가 명시적으로 바로잡거나 확정한 최신 Canon Correction
2. `core/PERSISTENT_CANON.md`
3. 직전 시즌 `PERSISTENT_WORLD_STATE.md`
4. 해당 시즌 실제 플레이 Canon / SAVE / CHECKPOINT
5. 과거 시즌 요약·회고 문서
6. GM의 즉흥 생성

상위 항목과 충돌하는 즉흥 설정은 폐기한다.

## 가족의 장기 운영 구조
- 가족은 도심 아파트와 정호 외곽주택을 병행하는 2거점 체계를 유지한다.
- 도심 아파트는 일상·직장·학교·병원·행정·상업 접근 중심이다.
- 정호 외곽주택은 비상·장기체류·비축·보수·텃밭 중심 거점이다.
- 정상사회가 복구되어도 외곽거점을 정기 방문해 재고 순환, 보수, 텃밭, 물·전력 상태를 관리한다.
- S03 BLACKOUT을 통해 실제 장기 정전 상황에서 이 구조가 작동한다는 점이 검증되었다.

## 정호 외곽주택의 지속 능력
S02 종료 시점까지 확인된 주요 능력:
- 외곽 창고 보수
- 체계적인 비축/재고 관리 기반
- 제한적 태양광·배터리 전력
- LPG 등 대체 조리수단
- 물 저장체계
- 소규모 텃밭
- 기본 공구와 보수재

S03 종료 후 추가로 확인·강화된 능력:
- 태양광·배터리는 장기정전 동안 가족 필수전력과 우물용 이동형 전원 충전에 실제 사용됨.
- 태양광 계통의 일부 호환 예비부품·보조 충전장비를 확보해 소규모 고장 대응력이 높아짐.
- 장기보관 식량·위생·생활소모품 비축이 초기보다 강화됨.
- 식량은 `현재소비 / 중기비축 / 비상보존`으로 나눠 관리하는 방식이 정착됨.
- 가족 텃밭은 최씨 측 주 생산축과 별개인 보조 생산축으로 유지됨.
- 비상차량 1대는 가족 의료·대피 우선 차량으로 보존하는 원칙이 실제 장기재난에서 유지됨.

이 거점은 완성형 생존기지가 아니며 재난 종류에 따라 취약점이 달라질 수 있다.
특히 S03에서 **연료와 외부 공급망**이 주요 약점으로 확인되었다.

## 최씨 가구와의 협업 Canon
최씨 가구는 정호 외곽주택과 같은 생활권에 거주하는 별도 가구다.

관계 원칙:
- 마을 전체 공동체가 아니라 **두 가구 우선의 제한적 협업관계**다.
- 각 가구는 자기 집, 설비, 자원, 비용 부담의 독립성을 유지한다.
- 공유 범위는 자동으로 확대하지 않는다.
- 협업은 신뢰만이 아니라 실제 이해관계, 비용, 노동, 자원 상호보완에 기반한다.
- **현재 지속적인 핵심 자원협력 파트너는 최씨 가구 한 곳**이다.
- 새로운 가구와 자원·시설·비용을 공유하는 장기 협업관계는 플레이어가 명시적으로 결정한 경우에만 형성한다.

### S02 우물 협업의 정확한 역사
- 최씨 가구에는 우물이 있었으나, S02 당시 펌프 구동과 설비 상태 문제 때문에 즉시 안정적인 백업 수원으로 사용할 수 있는 상태는 아니었다.
- 플레이어 가족의 태양광 전력을 최씨 집 우물에 직접 유선 연결한 구조가 아니다. 두 집은 떨어져 있고 각각 독립된 거점이다.
- 플레이어 가족과 최씨 가구는 최씨 측 우물 정비·개선에 필요한 비용을 함께 부담하기로 했고, 필요한 관리와 협력을 나누었다.
- 이 공동 부담과 실용적 협력이 두 가구 협업관계의 중요한 단초가 되었다.
- S02가 정리되는 동안 플레이어 가족은 자기 외곽 거점을, 최씨 가족은 자기 거점을 각각 보강했다.
- S02 종료 후에도 두 가구는 서로 다른 자산·시설·노동력을 필요할 때 상호보완하는 관계를 유지한다.

### S03 BLACKOUT에서 확정된 추가 Canon
- 두 집은 약 **300m**, 도보 약 4~5분 거리이며 직접 시야가 완전히 이어지지 않는다.
- 정전 중 우물 펌프 가동을 위해 두 가구가 **이동형 전원을 50:50 공동구매**했다.
- 운영 방식은 `플레이어 가족 태양광에서 이동형 전원 충전 → 최씨 집으로 이동 → 우물 펌프 필요 시 가동`이며 집 사이 장거리 임시 전선을 설치하지 않는다.
- 우물은 최씨 가구 소유지만, 이동형 전원과 이후 확보한 대체 가능한 **예비펌프 1대는 두 가구가 50:50 비용을 부담한 공동 협력자산**이다.
- S03 중 우물의 물은 두 가구 필요량 우선, 잉여분만 이장 관리 아래 제한적으로 마을 내부 물물교환에 사용됐다.
- S03 종료 시 상수도 복구로 물물교환은 자연스럽게 축소됐지만, 우물·이동형 전원·예비펌프 체계는 이후 재난에서도 사용할 수 있는 백업 능력으로 남는다.
- 농사는 최씨의 경험과 기존 경작지를 주 생산축으로 하고, 플레이어 가족의 노동·아버지의 참여·가족 텃밭을 보조축으로 연결하는 협력 경험이 생겼다.

### 금지되는 잘못된 해석
- `우리 집 태양광 = 최씨 우물에 바로 연결된 전원`으로 취급하지 않는다.
- `최씨 우물 = 아무 조건 없이 즉시 쓸 수 있는 공동 수원`으로 취급하지 않는다.
- `두 가구 협업 = 마을 전체 자원 공동화`로 확대하지 않는다.
- `마을의 필요 = 자동 공유 의무`로 취급하지 않는다.
- S03의 마을 비상협력망을 `8가구가 평시에도 모든 자원을 공동소유하는 조직`으로 해석하지 않는다.

## 정호 마을 비상협력 경험 — S03 이후
S03 BLACKOUT 동안 마을 단위 비상운영 경험이 생겼다.

지속 사실:
- 외부인·귀향가족 증가로 마을회관을 한시적으로 **임시 통합관리소**로 사용했다.
- 기능은 `의료·돌봄 / 생활안전 / 행정·통신`으로 나눠 교대 운영했다.
- 주민 거주인원·취약계층·외부정보·연락망을 관리했고, 공공 의료지원과 읍 행정망을 연결하는 경험이 생겼다.
- 시설경비 경험 주민, 돌봄 경험 주민, 이장 보조 등 비상시 역할을 맡을 수 있는 인적 네트워크가 확인되었다.
- 마을 전체 생활안전망은 관찰·조기경보·연락·가족보호·필요 시 대피를 목적으로 했으며 직접 대치를 전제로 하지 않았다.
- 정상화 이후 마을회관 비상체계는 평시 연락망 수준으로 축소되었지만, **누가 무엇을 할 수 있는지에 대한 경험과 연락관계는 남았다.**

중요한 한계:
- 이 네트워크는 평시 상설 공동체나 공동재산 조직이 아니다.
- 각 가구의 식량·연료·의약품·현금·차량·개인 비축은 독립 소유다.
- 최씨 가구 외 다른 가구는 자동으로 장기 핵심 자원협력 파트너가 되지 않는다.

## 시즌 간 승계 원칙
시즌 종료 시 다음 중 하나라도 해당하면 이 문서를 갱신한다.
- 가족 구조나 장기 거주 방식 변화
- 거점의 핵심 능력 추가·상실
- 차량·시설·핵심 장비의 장기 상태 변화
- 중요 NPC와의 관계가 지속적으로 바뀜
- 공동 투자·비용·소유·접근권처럼 후속 시즌 판단에 영향을 주는 인과관계 발생
- 사용자가 과거 설정을 바로잡아 Canon Correction이 확정됨

단순한 일회성 장면, 소모품 수량, 임시 위치는 이 문서가 아니라 SAVE/CHECKPOINT에 기록한다.

## Canon Correction 규칙
사용자가 플레이 중 과거 설정을 바로잡거나 누락된 사실을 복원하면:
1. 현재 장면의 잘못된 설정을 즉시 수정한다.
2. 장기 지속 사실이면 이 문서를 갱신한다.
3. 해당 사실이 시작된 과거 시즌의 `PERSISTENT_WORLD_STATE.md`에도 필요한 범위에서 보강한다.
4. 이후 시즌에서 같은 오류를 반복하지 않는다.

핵심 원칙:
`채팅은 플레이 공간이고, GitHub Canon은 장기 기억이다.`
