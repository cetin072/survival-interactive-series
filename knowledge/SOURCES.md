# SURVIVAL KNOWLEDGE SOURCES

게임에 반영하는 현실 생존·재난 지식의 근거를 기록한다. 플레이 중에는 출처나 강의를 노출하지 않고, 시즌 종료 후 AAR 또는 내부 검수 때 사용한다.

## 기본 원칙
- 한국 배경 재난 대응은 대한민국 공식 재난안전 지침을 우선한다.
- 의료·응급·감염 관련 정보는 공신력 있는 보건·응급기관 자료를 우선한다.
- 인터넷 커뮤니티의 팁은 공식 지침과 충돌하면 사용하지 않는다.
- 현실 지식은 시나리오 재미를 위해 왜곡하지 않는다.
- 사실이 불확실하면 게임 내에서도 확정 정보처럼 쓰지 않는다.
- 각 항목은 가능하면 검증 날짜를 기록한다.
