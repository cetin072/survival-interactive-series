# IDEA INBOX

플레이 또는 기획 중 떠오른 아이디어를 즉시 임시 저장하는 곳.

## 규칙
- 사용자가 `메모: ...`, `아이디어 저장: ...`, `이거 저장해`처럼 명시하면 우선 여기에 원문에 가깝게 저장한다.
- 저장 시 지나치게 다듬지 않는다. 의미 보존이 우선이다.
- 나중에 정리할 때 DISASTERS / DILEMMAS / LOCATIONS / NPC_IDEAS / SURVIVAL_KNOWLEDGE 등 적절한 문서로 이동한다.
- 이미 공식 설정으로 확정된 내용은 core/ 또는 해당 season 파일로 반영한다.
