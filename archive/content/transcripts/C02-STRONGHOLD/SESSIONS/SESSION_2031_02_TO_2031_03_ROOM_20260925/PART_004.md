## 문제는 ‘힐링’이 아니라 **장르 약속 위반**

예를 들어 GM이 내부적으로 이번 큰 장을:

> **정전으로 시작되는 생존 스릴러**

라고 잡았다면 최근 흐름은 문제가 있습니다.

초반은 좋았습니다.

**정전 → 외곽 이동 → 수도관 파손 → 낯선 차량 → 창고 절도 → 실제 침입 시도**

여기까지는 다음 화를 계속 보고 싶게 만드는 힘이 있었습니다.

그런데 이후:

**오정태 → 옛 창고 → 경찰 확인 → 야적장 → 참고인 → 수사**

로 가면서 도현이 생존하는 이야기가 아니라 **경찰 미스터리를 옆에서 따라다니는 이야기**로 바뀌었습니다.

그리고 사용자가 “더 관여하지 않는다”고 했을 때 사건을 잘 끊기는 했는데, 이후 곧바로:

**집 방비 → 지연과 저녁 → 숙박 → 관계 진전 → 평온한 일상**

으로 넘어갔습니다.

이 장면들 자체는 좋습니다. 특히 지연과 관계가 진전된 부분은 오히려 중요한 보상입니다.

하지만 **처음부터 이번 장을 ‘아포칼립스/생존 스릴러’라고 약속했다면 부족합니다.**

# 그래서 앞으로는 이렇게 구분해야 합니다

### **힐링·일상 장**
느려도 됩니다.

밭을 키우고, 집을 고치고, 지연과 여행하고, 새로운 사람이 들어오고, 밥 먹고, 땅을 사고, 몇 달 평온하게 살아도 됩니다.

대신 매 화의 보상은:

> **사람이 가까워진다 / 생활이 좋아진다 / 거점이 넓어진다 / 새로운 삶이 가능해진다**

여야 합니다.

그럼 충분히 재미있습니다.

### **거점 구축 장**
재난이 없어도 됩니다.

하지만:

> 2번 집 완성 → 새로운 공간 사용 → 사람 수용 → 생산 → 실제로 써먹음

처럼 **축적의 쾌감**이 계속 있어야 합니다.

### **생존·스릴러 장**
이건 다릅니다.

1~2화 동안 숨을 돌리는 건 가능하지만, 사건이 살아 있는 동안에는 계속:

- 새로운 정보
- 위험의 변화
- 이동
- 손실 가능성
- 선택
- 예상 밖의 결과

중 하나가 움직여야 합니다.

특히 대략 **3~5화 정도 같은 상태가 유지되면 안 됩니다.**

### **아포칼립스 장**
더 엄격해야 합니다.

뉴스에서 나라가 어렵다고 말하는 건 아무 의미가 없습니다.

도현이 실제로:

- 길을 못 쓰거나
- 사람과 떨어지거나
- 물건을 못 구하거나
- 돈의 의미가 달라지거나
- 거점 일부를 포기하거나
- 누군가를 선택하거나
- 이전 준비를 실제로 써야

아포칼립스입니다.
