## 보존 원칙

- 현재 대화에서 실제 문장 단위로 확인 가능한 원문만 기록한다.
- 기억·요약·체크포인트를 실제 대사처럼 재구성하지 않는다.
- 현재 원문을 직접 확인할 수 없는 구간은 `[원문 확인 불가 구간]`으로 명시한다.
- 내부 추론, 비공개 도구기록, GitHub 호출내용은 Raw 대화 원문에 포함하지 않는다.
- 공개 저장소에 게임과 무관한 실제 개인정보가 포함되면 필요한 부분만 `[REDACTED]` 처리한다.

## 현재 보존 범위

현재 작업 시점에서 S02 초반~중반의 실제 문장 전체는 직접 조회할 수 없고, 런타임 체크포인트와 압축 요약만 남아 있다. 따라서 그 내용을 Raw 대사로 재작성하지 않는다.

직접 확인 가능한 연속 원문은 **SEASON 02 · 54의 선택 직후 사용자 입력 `1`부터 시즌 종료 결정까지**이며 `PART_001.md`에 보존한다.

앞부분의 실제 채팅 원문을 향후 다시 직접 확인할 수 있게 되면 별도 PART로 추가하고 이 INDEX를 갱신할 수 있다.

## Canon과의 관계

Raw와 Canon이 충돌할 경우 현재 플레이의 지속 사실 기준은 승인된 Canon이다. Raw는 실제 당시 출력·선택을 복원하거나 소설·웹툰·게임·영상 각색을 위한 원재료로 사용한다.
