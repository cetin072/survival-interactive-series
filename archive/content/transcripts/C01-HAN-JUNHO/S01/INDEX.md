# Canon v2 S01 RAW TRANSCRIPT INDEX

Status: **COLD ARCHIVE / NOT BOOT INPUT / NOT CURRENT SOURCE OF TRUTH**

이 디렉터리는 정식 《생존일기》 Canon v2 S01의 실제 플레이 당시 사용자와 GM이 주고받은 원문을 장기 보존한다.

현재 게임 상태의 사실 기준은 승인된 Canon이며, 이 Raw Archive는 평상시 시즌 부팅이나 플레이 컨텍스트에 로드하지 않는다.

> **RAW → CANON → IP PACKAGE**

- RAW TRANSCRIPT: 당시 실제 플레이 원재료 / 역사자료 / 각색용 Cold Archive
- PLAYTHROUGH_CANON: 실제 일어난 사건의 압축 사실 기록
- PERSISTENT_CANON: 다음 시즌으로 승계되는 현재 지속 사실
- IP_PACKAGE: 각색·재사용용 장면·갈등·캐릭터 아크 추출물

Canon과 Raw가 충돌하면 현재 게임의 사실 기준은 승인된 Canon이다.

## 보존 범위

현재 채팅에서 실제로 확인 가능한 S01 대화만 사용했다.

시작은 사용자의 `정식 시즌 1 시작. GitHub main의 REBOOT_START_HERE.md를 기준으로 Canon v2로 부팅해.`이며, 종료는 GM의 `《생존일기》 정식 시즌 1 완료`다.

현재 확인 범위에서는 시작부터 종료까지 플레이 순서가 연속적으로 존재해 `[원문 확인 불가 구간]`이 필요한 곳을 발견하지 못했다. 향후 별도 원문 대조에서 누락이 발견되면 해당 위치를 명시하고 기억으로 보충하지 않는다.

## 역할 표기

- `USER`: 사용자가 실제 입력한 선택·자유행동·메타 지시
- `GM`: 실제 사용자에게 출력된 장면·대사·선택지·AUTO 진행
- `ASSISTANT — 운영 메타`: 첫 장면 전 실제 사용자에게 보인 짧은 부팅 확인 문구

비공개 내부정보와 도구 내부 기록은 Archive 대상이 아니다. 공개 저장소 안전 세부 규칙은 `docs/RAW_TRANSCRIPT_ARCHIVE_POLICY.md`를 따른다.

## 원문 무수정 원칙과 공개 저장소 예외

Raw는 당시 실제 출력의 오류도 역사자료로 보존하는 것이 원칙이다. 다만 공개 저장소에 게임과 무관한 실제 개인식별정보가 섞인 경우 개인정보 보호를 우선해 해당 부분만 `[REDACTED]` 처리한다.

이번 원문에서 `PART_009.md` 276일차에 GM이 플레이어 `한준호` 대신 게임 밖 실제 인물명으로 보이는 이름을 잘못 섞은 1건이 확인되어 이름 부분만 `[REDACTED]` 처리했다. 이 오류는 기존 Canon에 들어가 있지 않으며, 이 사실만으로 Canon을 수정하지 않는다.

## 정상 부팅 규칙

이 디렉터리는 소설·웹툰·게임·영상 각색, 특정 장면 복원, 실제 대사 검증, Canon 근거 재확인 때 필요한 PART만 선택적으로 읽는다.
