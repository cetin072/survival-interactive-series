비상장비 식별·이력

비상장비의 식별번호와 정비이력은 어떻게 연결할까

장비마다 바뀌지 않는 식별번호를 하나 정하고, 구매·배치·점검·수리 기록을 모두 그 번호에 연결합니다. 장비가 여러 장소와 담당자를 오갈수록 이름이나 외형만으로는 같은 물건인지 확인하기 어렵습니다. 제조사 일련번호가 있으면 원형 그대로 기록하고, 내부 관리번호를 따로 붙일 때는 두 번호를 함께 보존해야 이력이 끊기지 않습니다.

위험도 · 일반 준비 정보사람 편집 검토 · 필수 아님검토 상태 · 자동 게시 기준 충족공개 상태 · 공개 승인 완료범위 · 소규모 공동체와 비영리조직이 일반 비상장비의 식별번호를 구매·배치·점검·수리 기록과 연결하는 저위험 자산관리 절차를 다룬다. 진품 감정, 상표권·계약 분쟁, 리콜 판정, 법정 검사나 고위험 장비의 안전성 평가는 다루지 않는다.자료 확인 · 2026-10-22게시 · 2026-10-22

핵심 요약

비상장비마다 고정 식별번호를 두고 구매·배치·점검·수리 기록을 연결하며, 번호 중복이나 불일치는 미확인 상태로 분리해 검증하는 방법을 설명한다.

적용 범위
소규모 공동체와 비영리조직이 일반 비상장비의 식별번호를 구매·배치·점검·수리 기록과 연결하는 저위험 자산관리 절차를 다룬다. 진품 감정, 상표권·계약 분쟁, 리콜 판정, 법정 검사나 고위험 장비의 안전성 평가는 다루지 않는다.
근거
FEMA의 NIMS 자원관리 지침과 ICS 218 장비 재고 양식을 바탕으로 고유 식별자, 장비 속성, 배치·상태 변경 기록을 하나의 생애주기 장부로 재구성했다. 공개 Reader의 허구 서사는 질문이 시작된 출처일 뿐 현실 장비의 진품·안전·권리 판단 근거가 아니다.
목차
  1. 식별번호의 기준을 먼저 고정합니다
  2. 한 번호 아래 이력을 시간순으로 연결합니다
  3. 번호 충돌은 판정이 아니라 검증 신호로 다룹니다
  4. 사례는 저위험 수동 운반장비를 가정합니다
  5. 점검표와 변경기록을 함께 보관합니다
  6. 안전 경계와 출처의 확인 범위
  7. 《생존일기》에서 시작한 질문

01식별번호의 기준을 먼저 고정합니다

  1. 장비 몸체에 제조사 일련번호나 차량·장비 번호가 있으면 사진과 문자로 그대로 기록합니다.
  2. 내부 관리번호가 필요하면 별도로 발급하되 제조사 번호를 덮거나 지우지 않고 두 번호의 연결표를 남깁니다.
  3. 장비 종류·제조사·모델·규격·소유자·보관 위치를 같은 기본 기록에 묶습니다.
  4. 번호를 읽을 수 없거나 같은 번호가 이미 있으면 새 번호로 덮어쓰기 전에 상태를 '미확인'으로 표시합니다.
주의

식별번호는 기록을 연결하는 열쇠입니다. 번호 하나만으로 진품, 소유권, 안전성 또는 작동 가능 상태가 증명되지는 않습니다.

02한 번호 아래 이력을 시간순으로 연결합니다

단계남길 기록변경 때 확인할 것
구매·인수구매처, 인수일, 증빙 참조, 제조사 번호와 내부 번호증빙의 품목·모델·번호가 장비와 맞는가
배치·이동위치, 담당자, 용도, 이동 시각이전 위치의 출고와 새 위치의 인수가 모두 기록됐는가
점검점검일, 점검자, 결과, 다음 확인일점검 결과가 사용 가능 상태와 일치하는가
수리·부품고장 증상, 조치, 교체 부품, 작업자, 완료일원래 장비의 식별번호 아래 기록됐는가
상태 변경사용 가능·제한·미확인·사용 중지, 결정자와 근거현재 위치와 실제 표식이 장부와 맞는가

기록을 수정할 때 이전 값을 지우기보다 날짜, 변경자와 사유를 덧붙입니다. 그래야 위치가 바뀌거나 담당자가 교대해도 어느 장비에 어떤 조치가 있었는지 역순으로 확인할 수 있습니다.

03번호 충돌은 판정이 아니라 검증 신호로 다룹니다

  1. 중복·누락·훼손·장부 불일치를 발견한 시각과 발견자를 기록합니다.
  2. 해당 장비를 '미확인'으로 표시하고, 같은 번호의 다른 장비와 기록이 섞이지 않게 임시 참조번호를 붙입니다.
  3. 원래 표식 사진, 구매·인수 증빙, 과거 위치 기록과 정비 이력을 모아 서로 대조합니다.
  4. 제조사·공급처 확인이나 계약·법률 판단이 필요하면 담당 기관 또는 전문가에게 넘깁니다.
  5. 확인 결과, 새로 확정한 번호, 변경 사유와 승인자를 기록한 뒤에만 정상 이력으로 합칩니다.
주의

번호가 겹친다는 사실만으로 위조품이라고 공개 단정하지 않습니다. 확인되지 않은 주장은 별도 기록으로 남기고 운영 판단과 법적 판단을 분리합니다.

04사례는 저위험 수동 운반장비를 가정합니다

아래 사례는 사람을 구조하거나 전기·연료·압력·위험물을 다루지 않는 수동 접이식 운반카트 두 대를 관리하는 상황입니다. 인명 위험이 큰 장비의 안전 판정 절차를 설명하기 위한 사례가 아닙니다.

두 카트에 같은 내부번호 A-07이 적혀 있다면 한쪽 번호를 바로 바꾸기보다 두 대를 각각 임시 참조번호로 구분하고, 몸체 표식 사진·구매 영수증·이전 배치 기록·바퀴 수리 기록을 대조합니다. 어느 기록이 어느 카트에 속하는지 확인한 뒤 한 대에 새 내부번호를 발급하고, 기존 A-07 기록에서 분리한 이유와 승인자를 남깁니다.

05점검표와 변경기록을 함께 보관합니다

  • 제조사 번호, 내부 관리번호와 두 번호의 연결 상태
  • 장비 종류·제조사·모델·규격·소유자
  • 현재 위치·담당자·용도와 마지막 확인 시각
  • 구매·인수 증빙의 참조번호와 보관 위치
  • 점검·수리·부품 교체의 날짜·작업자·결과
  • 현재 상태와 사용 제한, 다음 점검일
  • 번호 충돌·훼손·누락의 발견 내용과 검증 상태
  • 변경자, 변경 시각, 사유와 승인자

정기 실물 점검 때는 장부의 번호와 장비 몸체의 표식을 직접 대조하고, 위치·상태 변경이 빠졌으면 발견 시점부터 보정 기록을 추가합니다. 원본 사진과 증빙은 접근 권한을 정해 보관합니다.

06안전 경계와 출처의 확인 범위

FEMA 자료는 고유 식별번호, 장비 속성, 배치 위치와 상태 변경을 연결하는 자원관리 원칙을 뒷받침합니다. 다만 이 글의 정비이력 표, 임시 참조번호와 충돌 해소 순서는 그 원칙을 소규모 조직에 맞게 재구성한 편집안이며 공식 표준 양식이 아닙니다.

주의

식별과 이력 기록은 제조사 정비지침, 리콜 확인, 법정 검사, 진품 감정 또는 전문가의 안전 판단을 대신하지 않습니다. 구조·의료·전기·연소·압력·중장비는 확인되지 않은 상태에서 투입하지 않습니다.

질문 출처《생존일기》에서 시작한 질문

공개된 《생존일기》의 허구·서사(narrative)에서는 겉표식이 비슷한 장비 두 대에 같은 관리번호가 적힌 사실을 발견하고 판매·수리 장부로 출처와 이력을 다시 확인합니다. 이 장면은 '장비의 식별번호와 정비이력을 어떻게 연결할까'라는 질문의 출처일 뿐, 작품 속 표식과 장부가 현실 제품의 진품 여부·안전성·권리관계 또는 특정 기록 방식의 효과를 입증하지 않습니다.
