소개·예약 상태 구분

재난 지원 연결에서 소개와 예약 확정은 어떻게 나눌까

재난 지원 연결에서는 제공처를 알려 주는 '소개'와 제공 기관이 인원·시간·수용 가능 여부를 확인한 '예약 확정'을 별도 상태로 기록해야 합니다. 담당자가 좋은 뜻으로 장소를 알려 줬더라도 제공 기관의 회신이 없다면 자리는 보장되지 않습니다. 이동하기 전 최신 상태와 조건을 다시 확인해야 헛걸음과 자원 낭비를 줄일 수 있습니다.

위험도 · 일반 준비 정보사람 편집 검토 · 필수 아님검토 상태 · 자동 게시 기준 충족공개 상태 · 공개 승인 완료범위 · 공동체·비영리조직이 숙박, 급수, 수리, 보관 등 일반 생활지원 서비스를 다른 제공처와 연결할 때 소개와 확정을 구분하고 상태를 갱신하는 저위험 운영 원칙을 다룹니다. 긴급 구조·의료·공식 대피 명령, 계약·결제 분쟁, 전문 시설의 안전 판정은 다루지 않습니다.자료 확인 · 2026-10-20게시 · 2026-10-22

적용 범위

01소개는 가능성을 알려 주는 단계입니다

재난 뒤에는 숙박, 물, 수리, 보관 같은 서비스의 남은 수용량이 자주 바뀝니다. 한 기관이 다른 제공처를 알고 있다는 사실과, 그 제공처가 특정 인원·시간·서비스를 실제로 받기로 했다는 사실은 다릅니다.

상태뜻이용자에게 말할 표현
소개제공처와 문의 방법을 알려 줌이용 가능 여부는 직접 확인해야 합니다
확인 요청인원·시간·필요 서비스를 보내 회신을 기다림아직 확정되지 않았습니다
예약 확정제공처가 수용 가능 조건과 확인번호를 회신함이 조건으로 자리가 확인됐습니다
변경·취소수용량이나 일정이 달라짐이전 확정 내용이 바뀌었습니다
도착·이용 완료실제 도착과 제공 결과를 기록함이번 연결 결과가 확인됐습니다

02확정 전에는 다섯 단계를 차례로 확인합니다

  1. 요청 정리: 인원 또는 수량, 필요한 서비스, 도착 예정 시각, 차량·접근 조건을 적습니다.
  2. 제공처 확인: 현재 수용 가능량, 운영시간, 비용, 제한조건과 담당자를 묻습니다.
  3. 회신 기록: 제공처가 가능한 범위와 불가능한 범위, 확인 시각을 명시적으로 회신하도록 합니다.
  4. 확정 전달: 확인번호나 담당자, 장소, 도착 시각, 제공 범위, 비용과 유효시간을 이용자와 양쪽 담당자에게 같은 내용으로 전달합니다.
  5. 도착·결과 갱신: 도착 여부와 실제 제공 결과, 남은 수용량 변화를 기록해 다음 안내에 반영합니다.
주의

회신이 없거나 수용 가능량이 불분명하면 상태는 '예약 확정'이 아니라 '확인 요청 중'입니다. 소개 기관이 대신 확정을 추정하지 않습니다.

03사례는 일반 생활지원 연결이라는 조건에서 봅니다

아래 사례는 공식 대피소 배정이나 의료·구조가 아니라, 두 공동체가 평소 합의한 일반 숙박·급수 서비스를 연결하고 통신이 제한적이지만 출발 전 한 번은 상태를 주고받을 수 있다는 조건입니다.

진행기록 예시판정
소개동쪽 시설에 숙박 문의 가능, 연락 담당자 제공자리 보장 아님
확인 요청성인 3명·차량 1대·오늘 18시 도착·1박 요청회신 대기
예약 확정방 1개 가능·식수 1인당 정해진 양·18시까지 유효·담당자 회신조건부 확정
도착 확인17시 50분 도착·3명 체크인·실제 제공량 기록이용 완료
상태 갱신남은 방 없음·다음 날 오전 재확인 필요후속 소개에 반영

이용자가 확정 시각보다 늦거나 인원·차량·필요 서비스가 달라지면 기존 확정을 그대로 적용하지 않고 제공처에 다시 확인합니다.

04양쪽이 같은 최소 기록을 사용합니다

  • 연결번호와 소개 기관·제공 기관 담당자
  • 인원 또는 수량, 차량, 필요한 서비스
  • 요청 시각·예상 도착 시각·제공 장소
  • 현재 상태: 소개·확인 요청·확정·변경·취소·도착·완료
  • 제공 범위, 비용, 제한조건과 확정 유효시간
  • 회신한 사람·확인 시각·마지막 갱신 시각
  • 실제 도착·이용 결과와 다음 수용 가능량

통신이 불안정하면 종이 한 장이나 단순한 표도 충분합니다. 핵심은 새 기록이 이전 기록을 지워 버리지 않도록 변경 시각과 변경자를 남기고, 다음 이동자에게는 마지막으로 확인된 상태만 전달하는 것입니다.

주의

이름·연락처·이동정보는 서비스 제공에 필요한 최소한만 기록하고, 공유 대상과 보관기간을 정합니다. 생명·의료·긴급대피 문제는 일반 예약표로 처리하지 않습니다.

05출처가 확인해 주는 범위

FEMA 자료는 자원 요청자가 종류·수량·도착 시각·장소·수령자를 명확히 하고, 제공 기관이 실제 가용량과 차이를 회신하며, 요청부터 도착 이후까지 상태를 추적해야 한다는 원칙을 뒷받침합니다. 이 글은 그 원칙을 소규모 생활지원 연결표로 단순화했습니다.

다만 공식 자료가 '소개'와 '예약 확정'이라는 생활서비스 용어를 표준화한 것은 아닙니다. 실제 예약의 법적 효력, 환불·취소, 개인정보 처리, 시설 안전과 허가는 서비스 제공 기관의 규정과 관할법을 따릅니다.

질문 출처《생존일기》에서 시작한 질문

공개된 《생존일기》의 허구·서사(narrative)에서는 길드와 동쪽 차고지가 이용자를 서로 소개하되, 출발 전 인원·차량·도착 예정일을 알리고 제공처가 실제 방과 물의 수용 가능량을 확인합니다. 연락 없이 찾아온 사람에게는 자리가 보장되지 않았고, 두 곳은 '소개 ≠ 예약'을 같은 양식에 적었습니다. 이 장면은 질문의 출처일 뿐, 작품 속 서비스·수용량·비용·이동 조건이 현실의 가용성이나 계약 성립을 입증하지 않습니다.
