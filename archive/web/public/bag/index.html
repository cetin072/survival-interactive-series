BEFORE YOU START

궁금한 것, 세 가지.

저장은 어디에 하나요?

실제 물품 기록은 지금 사용하는 기기·브라우저에 저장됩니다. 기기 간 자동 동기화는 제공하지 않습니다. 브라우저 데이터 삭제나 기기 교체 전에 앱의 더보기에서 JSON 백업을 내려받으세요. Preview와 정식 사이트의 저장 공간도 서로 다릅니다.

프리셋만 선택하면 준비가 완료되나요?

프리셋은 편집 가능한 준비 목록입니다. 기본 실제 수량은 0이며, 물품을 가방에 담고 직접 확인해야 합니다. 내 상황에 맞게 목표와 구성을 조정하세요. 목록을 채웠다는 사실이 안전이나 생존을 보장하지는 않습니다.

점검 알림을 받을 수 있나요?

웹 PWA는 설치·오프라인 기록과 앱 내 점검 안내를 지원합니다. 지원 브라우저에서는 권한을 허용한 뒤 즉시 테스트 알림을 보낼 수 있습니다. 웹을 닫은 뒤 날짜 알림을 예약하지 않습니다. Android OS 장기 알림은 실기 검증 전 시험 중입니다. 로그인·클라우드 동기화는 지원하지 않습니다.

저장 없이 둘러보고 싶다면 샘플 데이터 가상 시연을 이용하세요. 실제 물품 기록은 앱에서 시작합니다.
