# CURRENT CHECKPOINT

## 시즌 상태
- **SEASON 04 — 해협 첫 플레이 종료**
- 난이도: NORMAL
- 상태: 새로운 안정상태 도달 후 종료
- 세계 국면: **P4_PROLONGED_RESTRUCTURING_OR_DEESCALATION**

## 엔딩 요약
- 대만해협 대규모 충돌은 장기간의 긴장완화 단계로 들어갔고 주요 해상통로 제한이 단계적으로 완화되기 시작했다.
- 한국은 시즌 내내 직접 교전국이 되지 않았다.
- 전력·통신·상수도·일반 결제는 붕괴하지 않았으며, 사회는 공급망·물가·기업운영·근무형태를 바꾸며 적응했다.
- 문제의 중심은 `초기 물류충격 → 공급망 병목 → 기업 감산·소득압박 → 국내대체·새 안정상태`로 이동했다.

## 가족 최종 상태
- 한준호: 고용 유지. 주4일·순환휴업 경험으로 소득은 감소했으나 비근무일을 외곽 노동·가족운영에 활용.
- 서윤: 병원 정상운영 유지. 위기 중 비상대기와 추가근무가 늘어 가계소득 일부를 보완했고, 종료 시 비상근무 축소 예정.
- 민석: 학교 유지. 방과후를 줄이고 공식정보 판별, 외곽 생활, 재고기록 등 독립 역할 경험을 얻음.
- 정호: 외곽주택 상주. 외곽 운영과 민석 생활관리까지 맡으며 독립적인 가족 운영축으로 기능.

## 두 거점
- 도심 아파트: 주생활·직장·병원·학교 연결 거점 유지.
- 외곽주택: 기존 비축·태양광·배터리·LPG·물 저장·공구·텃밭에 더해 정비 예비부품과 고장대응력, 운영 효율이 강화됨.
- 가족 전체 조기이주는 하지 않았으며 상황에 따라 외곽 체류를 늘리는 유연한 이중거점 체계를 구축함.
- 최씨 가구와 두 가구 우선 협력 관계 유지.

## 가계
- 초기 연료·장기보관·의료위생품을 선제 보강.
- 외곽 대규모 확장 대신 병목 예비부품과 정비능력에 집중.
- 이후 신규투자를 중단하고 생활비를 단계적으로 낮춰 현금 방어.
- 준호 소득 감소분 상당 부분을 서윤의 추가근무 수입과 지출 감소가 완충.

## 회사
- 회사는 감산, 주4일제, 순환휴업으로 고용을 유지함.
- 공급충격 이후 주문감소·결제지연까지 겪었으나 국내 대체부품 공동개발과 공급망 재편으로 적응.
- 반복 회사 NPC로 **박재현 부장(47)**이 실제 플레이에서 등장함. 생산·구매·납기를 조율하며 기관 의사결정은 회사가 하고 플레이어는 자기 업무·시간·가족대응을 결정하는 구조가 확립됨.
