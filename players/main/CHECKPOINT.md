# CURRENT CHECKPOINT

새 채팅에서 빠르게 이어가기 위한 사람-readable 요약.

## 현재 상태
- 게임 상태: S03 첫 플레이 진행 중
- 시즌: **SEASON 03 — BLACKOUT**
- 난이도: NORMAL
- 시점: DAY 4 / 오후
- 위치: 정호 외곽주택·최씨 가구·마을회관 생활권
- 가족 4명 전원 무사
- 플레이어 가족과 최씨 가족의 두 가구 핵심동맹 유지

## 현재 운영 구조
- 핵심 의사결정은 **플레이어·최씨·이장 3인 운영체제**가 맡음.
- 플레이어 가족 + 최씨 가족 + 이장 가구 + 협조 5가구를 합쳐 사실상 **8가구 협력권**이 형성됨.
- 다만 8가구를 한 번에 완전 공동체·공동재산 체제로 격상하지 않음.
- 5가구는 행동·질서·기여·정보보안을 보며 단계적으로 역할을 확대함.

## 핵심 인프라
- 광역 정전·통신장애·상수도 중단 지속.
- 플레이어 가족 외곽거점의 태양광·배터리 정상 운용.
- 최씨 우물은 공동구매 이동형 전원으로 가동 가능.
- 우물은 두 가구 우선, 잉여분만 제한적 물물교환.
- 두 집 사이 장거리 임시 공동전선은 설치하지 않음.
- 비상용 차량 1대는 계속 보존.

## 공동화 범위
1. **물**: 두 가구 우선 + 잉여분 제한 거래, 이장이 질서·대상자 관리.
2. **농사**: 최씨 중심 기술·경작, 협조 가구 노동·운송을 필요에 따라 연계.
3. **외부 통제·정보**: 이장 중심 외부 차량·낯선 사람·거래 질서 관리.
4. **안전·경계**: DAY 4부터 8가구 협력권에 야간순찰·비상경계·연락체계를 단계적으로 추가 논의.

## 아직 공동화하지 않는 범위
- 각 가구 식량 비축
- 각 가구 연료
- 각 가구 의약품
- 현금·개인재산
- 차량 소유·개별 비축

## 차량·연료 협력 원칙
- 각 가구 연료와 차량은 계속 개인자산.
- 공동작업에 차량·연료를 제공한 가구에는 물·농산물·노동 등으로 보상하는 **교환 원칙**을 둠.
- 실제 공동운송이 필요할 때마다 자동 배정하지 않고 3인 운영체제에서 상황별로 결정함.

## 8가구 안전·경계 제안
정전·물 부족·통신 장애가 길어지면서 외부인 접근과 주민 간 긴장이 높아질 가능성을 고려해 다음을 제안함.

- **야간순찰조**: 협력 가구 성인이 교대로 마을 주요 생활권의 이상 상황을 관찰.
- **비상경계조**: 순찰 중 이상 상황이 확인되면 추가 인원이 가족 안전·이장 연락·상황 전달을 지원.
- 목적은 무장대치가 아니라 **관찰·조기경보·연락·가족 대피·이장 중심 대응**임.
- 외부인과 불필요하게 직접 충돌하지 않으며, 위험 상황에서는 거리 유지와 후퇴를 우선함.
- 각 집의 문단속과 가족 안전은 계속 각 가구 책임.
- 플레이어 가족과 최씨 가족의 기존 300m 두 거점 상호백업 체계는 유지.

## 통신망 논의
- 휴대전화가 불안정해져 8가구 내 단거리 연락수단 확보 필요성이 커짐.
- 각 가구가 이미 보유한 합법적 소비자용 무전기·라디오·예비배터리 여부를 먼저 조사.
- 확보 가능한 무전기는 순찰조·이장·핵심거점 연락용으로 우선 배치하는 방향을 검토.
- 플레이어 가족 태양광은 기존 원칙대로 필수기능 우선이며, 통신장비 충전은 남는 범위에서 지원 검토.
- 무전기가 부족하면 정해진 직접 연락시간·이장 전달망·라디오 청취를 병행.

## 외부 상황
- 전력 복구 장기화 가능성이 공식화됨.
- 연료·식품·의약품·농업 투입재 수송 지연 확대.
- 일반 주유 제한 가능성 증가.
- 외부 차량이 물 거래 소문을 듣고 마을에 접근한 사례 발생.
- 이동통신은 심각하게 불안정하며 라디오가 핵심 외부 정보원.
