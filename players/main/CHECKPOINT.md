# CURRENT CHECKPOINT

새 채팅에서 빠르게 이어가기 위한 사람-readable 요약.

## 현재 상태
- 게임 상태: S03 첫 플레이 진행 중
- 시즌: **SEASON 03 — BLACKOUT**
- 난이도: NORMAL
- 시점: DAY 3 / 출근 직전 아침
- 위치: 플레이어는 도심 출근 예정, 가족은 정호 외곽주택, 최씨는 자기 가구 거점
- 가족 4명 전원 무사
- 최씨 가구와 두 가구 제한적 협업 유지

## 핵심 인프라
- 광역 정전과 통신 장애 지속, 상수도 중단.
- 플레이어 가족 외곽거점의 태양광·배터리 정상 운용.
- 최씨 우물은 두 가구가 공동구매한 대용량 이동형 전원으로 시험가동 성공.
- 이동형 전원은 플레이어 가족 거점 태양광으로 충전한 뒤 최씨 집 우물에서 사용하는 순환 구조.
- 두 집 사이 장거리 임시 공동전선은 설치하지 않음.
- 우물은 두 가구 절약 운용에는 충분한 장기 백업수원 가능성이 높으나 마을 공동수원 규모는 검증하지 않음.

## 두 가구 협업
- 두 집은 각자 독립 거점을 유지함.
- 플레이어 가족의 강점: 태양광·배터리·비축·독립전력.
- 최씨 가구의 강점: 우물·농사 경험·기존 텃밭 관리.
- 최씨는 플레이어 가족 텃밭 보강에도 조언해온 관계.
- DAY 2 밤 회의 결과, 주 생산 확대는 최씨 집 쪽 기존 텃밭/경작지를 중심으로 하고 플레이어 가족이 노동력을 지원하기로 함.
- 플레이어 가족 자기 텃밭은 소규모 독립 생산축으로 유지함.
- 토지·수확물을 자동 공동소유로 만들지 않고 각 가구 독립성을 유지한 채 지식·노동을 교환함.

## 우물 외부 거래 원칙
- 우물은 개인자산이며 기본 운용 대상은 플레이어 가족과 최씨 가족 두 가구임.
- 무료 공동급수나 무제한 공급은 하지 않음.
- 두 가구 필요량을 먼저 확보하고 **남는 양만** 외부 거래 가능.
- 외부 공급은 제한적 물물교환 방식.
- 아무 가구나 상대하지 않고 협조적이고 갈등이 적은 가구 위주로 거래함.
- 거래 가능량은 제한적이며 상황 악화 시 언제든 중단 가능.

## 이장과의 관계 / 신규 위임 구조
- 우물 가동 사실이 결국 알려질 가능성이 높다고 보고 DAY 2에 이장에게 먼저 개인자산·공동정비 이력·두 가구 우선 원칙을 설명함.
- DAY 3부터 외부 거래가 시작될 경우 **거래대상자 선별과 인원관리·줄 통제를 이장에게 위임**함.
- 최씨와 플레이어 가족은 이장이 선별한 사람과만 거래함.
- 이장에게 제시할 선별 기준:
  - 두 가구 필요량 확보 후 남는 양 범위
  - 협조적이고 갈등을 만들지 않는 가구 우선
  - 무제한 공급 금지
  - 공급 가능 인원 수와 양은 두 가구가 정함
- 이장은 마을 질서·대기 인원·거래 순서를 관리하지만 우물의 소유권이나 공급 결정권을 갖지 않음.
- 플레이어와 최씨는 협조에 대한 보상·관계 유지 차원에서 이장에게는 별도로 소량의 물을 제공하기로 함. 이 지원은 일반 거래 물량과 분리해 조용히 처리함.

## 차량·연료 / 회사
- 가족 차량 중 1대는 가족 긴급 이동·병원·거점 이탈 등 **비상 전용**으로 보존.
- 일반 운용 차량으로 DAY 3 09:00 회사 현장 확인 출근 예정.
- 플레이어는 회사에 주유 지원을 조건으로 출근 가능하다고 통보했고 회사가 협력 주유소 제한 주유를 제공하기로 함.
- DAY 3 아침 기존 지정 주유소 재고가 소진되어 회사 인근 협력 주유소로 변경됨.

## DAY 3 역할분담
- 플레이어: 도심 출근, 회사·도로·전력·물류 정보 확인, 회사 지원 주유 이용.
- 아내·아버지: 외곽거점·비축·텃밭 관리 및 필요 시 최씨 쪽 농사 노동 지원.
- 최씨: 우물·이동형 전원·주 생산 텃밭 관리.
- 이장: 외부 물 거래 요청자 선별, 대기 인원·질서·순서 관리.
