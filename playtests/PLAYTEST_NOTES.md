# PLAYTEST NOTES

실제 플레이에서 발견한 재미/문제점을 기록한다.

## 기록 원칙
- 플레이 중 메타 피드백 때문에 몰입을 깨지 않는다.
- 세션 종료 후 또는 사용자가 명시적으로 피드백할 때 기록한다.
- 감상보다 재현 가능한 문제를 우선한다.

## 분류
- PACING: 너무 느림/빠름
- IMMERSION: 몰입을 깨는 요소
- CHOICE: 선택지가 의미 없거나 정답이 너무 뻔함
- CONTINUITY: 시간/위치/자원/인물 설정 모순
- CHARACTER: 가족 자율성·성격 표현 문제
- REALISM: 실제 재난 원리와 어긋남
- UI: 상태 표시와 읽기 편의성
- IDEA: 다음 시즌/기능 아이디어
- CONSEQUENCE: 선택의 대가/장기 회수 문제
- INFO: 정보 불확실성/출처 충돌 문제
- SOCIETY: 정상사회 의무·일상 연속성 문제

## T01 지진 튜토리얼 프로토타입 v0.1
상세 기록: `playtests/T01_EARTHQUAKE_TUTORIAL_V0_1.md`

### PACING
- 재난 발생부터 안전한 친척집 거점 확보까지 너무 빠르게 안정화됨.
- 정식 시즌 하나로 느껴질 만큼의 중간 전환과 장기 압박이 부족함.

### CHOICE / CONSEQUENCE
- 대부분 `좋은 선택 → 더 안전` 구조라서 좋은 선택끼리 충돌하지 않음.
- 물자, 시간, 이동수단, 관계, 거점의 실질적 포기 비용이 약함.
- 초반 선택이 몇 시간/며칠 뒤 다시 돌아오는 장기 분기 회수가 거의 없음.

### INFO
- 정보를 확인하면 정답이 비교적 명확해짐.
- 공식정보, 주민 말, SNS, 직접 목격, 관리사무소, 경찰·소방 정보가 서로 부분적으로 충돌하는 구조가 필요함.

### CHARACTER
- 아내/아이/아버지가 플레이어 지시에 대부분 순응함.
- 가족별 독립 목표, 피로, 공포, 설득, 거부, 우선순위 충돌이 본편에 필요함.
- 반면 가족별 동시 역할분담은 매우 좋은 시스템 가능성을 확인함.

### REALISM
- 지진 후 아파트 1층 출입문이 단순히 잠겨 있다는 설정은 부자연스러웠음.
- 문틀 변형, 자동문 오작동, 유리 파손, 낙하물, 잔해, 화재 등 구체적인 현실 원인으로 장애를 구성해야 함.

### UI
- A/B/C보다 `1, 2, 3...` 숫자 선택지가 선호됨.
- `3 → 5 → 1`처럼 여러 행동을 순서대로 지정할 수 있어야 함.
- 행동 순서와 소요시간이 결과에 반영되어야 함.

### IMMERSION
- `좋은 선택이다`, `장기전으로 넘어간다`, `위험한 선택` 같은 GM 메타 해설이 몰입을 끊음.
- 정식 본편은 `상황 → 행동 → 결과` 중심으로 진행하고 평가는 종료 후 AAR로 이동.

### IDEA
- 차량을 이동형 비축공간/임시 거점으로 활용하는 시스템은 유지 가치가 큼.
- 가족이 각자 동시에 다른 임무를 수행하는 파티 시스템을 정식 시스템으로 발전.
- 차량/가방 자원을 `즉시 이동 가방 / 차량 비축 / 당장 필요 없음`처럼 접근성 기준으로 분류하는 방식 검토.
- `[삽화 후보]` / `[영상 후보]` 태그를 시나리오 제작 중 기록하되 시즌 동결 전 실제 제작은 하지 않음.

### 총평
교육적 튜토리얼로는 유효하지만 정식 본편 품질에는 미달. 본편은 Standard~Hard 사이 난이도로 설계하고, 선택의 대가·정보 불확실성·가족 갈등·장기 인과관계·Fail-Forward를 핵심 강화한다.

## 정전 본편 초기 플레이 — 시작정보/거점 설정 오류

### CONTINUITY / CHOICE
- 아버지의 위치와 거주 형태가 첫 선택 전에 명확하지 않은 상태에서 플레이어가 `전화로 위치 확인 후 데리러 간다`고 판단함.
- 이후 GM이 아버지가 별도 자택에 있다고 뒤늦게 설정하면서 이전 선택의 의미가 달라짐.
- 이는 단순 묘사 누락이 아니라 플레이어 상식 정보를 사후 공개한 공정성 문제로 판정.
- 해당 선택 이후 진행은 플레이테스트상 무효 처리하고, 공정한 시작정보가 공개된 시점에서 재시작하는 것이 적절함.

### 공통 개선
- 가족별 현재 위치 또는 마지막 확인 위치를 첫 의미 있는 선택 전에 공개.
- 평소 거주 구조, 도심 아파트/외곽 주택의 기본 특성, 차량 위치·대략적 연료, 평소 비축품처럼 플레이어가 당연히 알고 있을 정보는 숨은 정보로 취급하지 않음.
- 평소 거주지는 고정 Canon, 재난 발생 순간 위치는 시즌별 변수로 분리.
- 자세한 공통 기준은 `core/FAMILY_RESIDENCE_AND_START_INFO.md`를 따름.

### 반복성 위험
- 아버지가 항상 외곽에 있고 나머지 가족이 항상 도심에 있으면 매 시즌 `가족 분산 → 데리러 감 → 합류`가 첫 에피소드로 반복될 위험이 있음.
- 해결책은 거주지를 바꾸는 것이 아니라 시즌 시작 위치를 가변화하는 것.
- 가족 합류는 첫 목표, 압축 도입, 이미 완료, 중반 목표, 미완료 조건 등 다양한 역할을 가질 수 있어야 함.

## S01 불길 E02 — 정상사회 지속 규칙 발견

### SOCIETY / REALISM
- 공식 대피 권고가 해제되고 가족이 안전하게 아파트로 복귀했지만, 플레이어의 일상 의무는 즉시 사라지지 않음.
- 회사 출근/휴가/재택/결근 처리, 아이 학교·학원, 아버지 자택 통제 해제, 관리사무소/주거 확인, 재난 지출, 비축품 재보충 등이 후속 압력으로 남음.
- 일반적인 산불·지진·침수·정전을 자동으로 사회붕괴 상태처럼 처리하면 현실감과 노말 난이도의 핵심 압박을 잃음.

### 공통 개선
- 날짜·요일·시간대·평일/주말/공휴일·재난 규모를 월드 시드에 포함.
- 국가기능 붕괴 수준이 아니라면 정상사회 의무를 계속 추적.
- 급성 재난 종료 후 필요한 경우 `생활 복구 단계`를 플레이하되, 의미 없는 행정은 압축.
- 상세 기준은 `docs/NORMAL_SOCIETY_CONTINUITY_RULE.md`를 따름.

### 핵심 문장
`재난이 발생했다고 플레이어의 평범한 인생이 사라지는 것은 아니다.`
