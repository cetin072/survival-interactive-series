# PLAYTEST NOTES

실제 플레이에서 발견한 재미/문제점을 기록한다.

## 기록 원칙
- 플레이 중 메타 피드백 때문에 몰입을 깨지 않는다.
- 세션 종료 후 또는 사용자가 명시적으로 피드백할 때 기록한다.
- 감상보다 재현 가능한 문제를 우선한다.

## 분류
- PACING: 너무 느림/빠름
- IMMERSION: 몰입을 깨는 요소
- CHOICE: 선택지가 의미 없거나 정답이 너무 뻔함
- CONTINUITY: 시간/위치/자원/인물 설정 모순
- CHARACTER: 가족 자율성·성격 표현 문제
- REALISM: 실제 재난 원리와 어긋남
- UI: 상태 표시와 읽기 편의성
- IDEA: 다음 시즌/기능 아이디어
- CONSEQUENCE: 선택의 대가/장기 회수 문제
- INFO: 정보 불확실성/출처 충돌 문제

## T01 지진 튜토리얼 프로토타입 v0.1
상세 기록: `playtests/T01_EARTHQUAKE_TUTORIAL_V0_1.md`

### PACING
- 재난 발생부터 안전한 친척집 거점 확보까지 너무 빠르게 안정화됨.
- 정식 시즌 하나로 느껴질 만큼의 중간 전환과 장기 압박이 부족함.

### CHOICE / CONSEQUENCE
- 대부분 `좋은 선택 → 더 안전` 구조라서 좋은 선택끼리 충돌하지 않음.
- 물자, 시간, 이동수단, 관계, 거점의 실질적 포기 비용이 약함.
- 초반 선택이 몇 시간/며칠 뒤 다시 돌아오는 장기 분기 회수가 거의 없음.

### INFO
- 정보를 확인하면 정답이 비교적 명확해짐.
- 공식정보, 주민 말, SNS, 직접 목격, 관리사무소, 경찰·소방 정보가 서로 부분적으로 충돌하는 구조가 필요함.

### CHARACTER
- 아내/아이/아버지가 플레이어 지시에 대부분 순응함.
- 가족별 독립 목표, 피로, 공포, 설득, 거부, 우선순위 충돌이 본편에 필요함.
- 반면 가족별 동시 역할분담은 매우 좋은 시스템 가능성을 확인함.

### REALISM
- 지진 후 아파트 1층 출입문이 단순히 잠겨 있다는 설정은 부자연스러웠음.
- 문틀 변형, 자동문 오작동, 유리 파손, 낙하물, 잔해, 화재 등 구체적인 현실 원인으로 장애를 구성해야 함.

### UI
- A/B/C보다 `1, 2, 3...` 숫자 선택지가 선호됨.
- `3 → 5 → 1`처럼 여러 행동을 순서대로 지정할 수 있어야 함.
- 행동 순서와 소요시간이 결과에 반영되어야 함.

### IMMERSION
- `좋은 선택이다`, `장기전으로 넘어간다`, `위험한 선택` 같은 GM 메타 해설이 몰입을 끊음.
- 정식 본편은 `상황 → 행동 → 결과` 중심으로 진행하고 평가는 종료 후 AAR로 이동.

### IDEA
- 차량을 이동형 비축공간/임시 거점으로 활용하는 시스템은 유지 가치가 큼.
- 가족이 각자 동시에 다른 임무를 수행하는 파티 시스템을 정식 시스템으로 발전.
- 차량/가방 자원을 `즉시 이동 가방 / 차량 비축 / 당장 필요 없음`처럼 접근성 기준으로 분류하는 방식 검토.
- `[삽화 후보]` / `[영상 후보]` 태그를 시나리오 제작 중 기록하되 시즌 동결 전 실제 제작은 하지 않음.

### 총평
교육적 튜토리얼로는 유효하지만 정식 본편 품질에는 미달. 본편은 Standard~Hard 사이 난이도로 설계하고, 선택의 대가·정보 불확실성·가족 갈등·장기 인과관계·Fail-Forward를 핵심 강화한다.
