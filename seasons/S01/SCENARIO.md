# Season 1 — Unstarted

## 상태
아직 시작하지 않음.

## 원칙
- 기존 홍수/정전 테스트 플레이는 공식 Season 1에 포함하지 않는다.
- 완전히 새로운 사건으로 시작한다.
- 평범한 일상에서 출발한다.
- 시즌 길이는 미리 고정하지 않는다.
- 실제 재난·생존 지식은 플레이 중 강의하지 않고 세계 내부 정보와 결과로만 드러낸다.
- 사용자가 모바일 플레이방에서 `새 생존게임 시작`이라고 입력하면 GM이 시즌의 숨은 구조를 먼저 설정한 뒤 Day 0 첫 장면을 제시한다.

## 플레이어에게 공개 가능한 시작 정보
- 가족 4인 파티가 존재한다.
- 모두 평범한 현대인이다.
- 시작 시점에는 특별한 재난이 발생했다고 단정하지 않는다.

## 시즌 종료
주요 갈등이 해소되고 가족·세계 상태에 의미 있는 결과가 남으면 종료한다. 종료 후 사용자가 원할 때만 After Action Report를 제공한다.
