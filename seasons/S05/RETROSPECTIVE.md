# S05 Retrospective — 신호가 끊긴 날

## A. 플레이어 생존 복기

### 총평
S05의 플레이는 전반적으로 매우 안정적이었다. 핵심은 `빨리 움직이는 것`보다 **가족 위치와 정보 확인 → 필요한 자원 선확보 → 단계적 재집결 → 위험 구간 회피 → 외곽 이동** 순서를 유지한 점이다.

### 잘한 판단
1. **초기 정보 우선**
   - 장애 직후 서윤·정호 상태와 학교 공지를 먼저 확인했다.
   - 학교가 민석을 보호하고 있다는 공식 정보를 확보한 뒤 이동해 불필요한 가족 분산을 줄였다.

2. **연료·물자 선확보**
   - 카드·ATM·주유 기능이 무너지기 전에 현금을 사용해 연료와 기본 식수·식품을 확보했다.
   - 외곽 이동 시 연료가 즉시 병목이 되지 않았다.

3. **단수 전 저장수 확보**
   - 서윤에게 수도가 살아 있을 때 물을 받아두도록 지시했고, 실제 야간 단수 전에 추가 저장까지 완료했다.
   - 사전 행동이 후속 위기에서 직접 보상으로 돌아온 좋은 선택-결과 연결이었다.

4. **위험 구간에서 무리하지 않음**
   - 낮게 처진 전선, 손상 의심 교량, 혼잡도로를 억지로 돌파하지 않았다.
   - 시간 손해를 받아들이고 관찰·우회·지역정보 확인을 우선했다.

5. **마을 운영의 위임**
   - 3인 연락망은 유지하되 평시 마을 관리는 이장에게 맡겼다.
   - 플레이어가 마을 모든 결정을 직접 처리하는 문제를 줄였다.

6. **개인자산 경계 유지**
   - 최씨 우물과 플레이어 태양광·배터리를 각각 개인자산으로 명확히 유지했다.
   - 협력과 공동소유를 구분했다.

7. **보안 이슈의 비대치 대응**
   - 반복 차량을 바로 범죄자로 단정하지 않고 CCTV·주민정보·경찰 기록으로 단계적으로 대응했다.
   - 직접 추적이나 대치를 선택하지 않았다.

### 플레이 성향
S05에서 플레이어 전략은 일관됐다.

`불확실한 위험은 굳이 통과하지 않는다 → 정보 확보 → 우회 가능하면 우회 → 자산과 가족의 선택권을 보존한다.`

Normal 난이도에서는 매우 강한 플레이였다.

## B. 게임 / GM 시스템 복기

### 잘 작동한 부분
1. **TURN STATE GATE 효과**
   - 시즌 초 가족 위치 오류에 대한 재발방지 체계를 다시 확인한 뒤 위치·동행 정합성이 크게 안정됐다.
   - 가족, 차량, 직장·학교 권한을 체크한 뒤 선택지를 만드는 구조는 유지 가치가 높다.

2. **MUD Text Visual Grammar 정착**
   - `SCENE HEADER / WORLD STATE / FAMILY / RESOURCE / AUTO / EVENT / PHASE CHANGE`를 이용한 텍스트 게임 화면이 본편의 시각 언어로 자리 잡았다.
   - 시즌 중 실제 이미지 제작과 플레이 UI를 분리하는 방향이 명확해졌다.

3. **AUTO가 반복운영을 압축**
   - 식량 확보, 거점 보수, 협업, 사회 복구 같은 반복 구간을 큰 분기점까지 넘기는 데 효과적이었다.
   - S02에서 드러난 건설 시뮬레이터식 늘어짐을 줄이는 핵심 장치다.

4. **정상사회 복귀 압력**
   - 회사·직장·학교가 복구되면서 `계속 거점에 있을 것인가 / 생활로 복귀할 것인가`가 새로운 문제로 바뀌었다.
   - 재난이 끝나도 세계가 계속 살아 있다는 느낌을 만들었다.

5. **소유권·위임 경계**
   - 이장이 마을 일상운영을 맡고, 플레이어와 최씨는 자기 가구를 운영했다.
   - 공용 관정 문제도 플레이어 태양광을 즉시 공동화하지 않고 공용 자원으로 먼저 해결했다.

### 핵심 문제
1. **MUD UI 의미를 한 차례 잘못 해석**
   - 사용자가 시즌 중 `그래픽 요소`를 확인했을 때 GM이 이를 삽화/영상 후보 관리로 잘못 연결했다.
   - 실제 의도는 본편의 MUD형 텍스트 UI였다.
   - 이 문제는 런타임 공통규칙으로 승격한다: **플레이 중 그래픽/UI 언급은 별도 요청이 없는 한 MUD 텍스트 시각문법을 우선 의미한다. 실제 이미지 제작은 별도 자산화 단계다.**

2. **상태 HUD 과다 가능성**
   - UI 교정 후 여러 턴에서 전체 상태판을 거의 반복 출력했다.
   - MUD 느낌은 유지하되 모든 패널을 매턴 반복하지 않는다.
   - 이번 결정에 필요한 변화만 짧게 보여주는 것이 목표다.

3. **중반 해결이 너무 매끈함**
   - `문제 발생 → 합리적 조사 → 해결`이 반복됐다.
   - 특히 공용 관정은 디젤 발전기가 비교적 쉽게 발견·작동해 긴장도가 빠르게 내려갔다.
   - 의미 있는 문제는 부분성공, 수리시간, 연료비용, 다른 선택의 포기 등 한 번 이상의 마찰을 가질 수 있어야 한다.

4. **강한 거점 때문에 Normal 체감 난이도 하락**
   - 태양광·배터리·저장수·식량·가스·최씨 협력까지 갖춰진 뒤 외곽 거점은 매우 강했다.
   - 해결책은 기존 능력을 임의로 무효화하는 것이 아니다.
   - 다음 시즌은 **기존 거점 능력이 실제로 효과를 내면서도 이동·의료·가족배치·직장·행정·지역재난 등 다른 압력축이 중요한 구조**를 택해야 한다.

5. **복수선택 비용이 여전히 약함**
   - 플레이어가 여러 좋은 행동을 순서대로 선택했을 때 상당수가 모두 성공했다.
   - 시간·거리·대기열·자원·세계 변화로 후속 행동이 지연되거나 사라지는 사례를 더 자주 자연스럽게 반영해야 한다.

6. **가족 갈등·자율제안 부족**
   - 가족이 역할은 수행했지만 대부분 플레이어 지시에 순조롭게 따랐다.
   - 다음 시즌에는 합리적인 범위에서 가족이 먼저 운영변경을 제안하거나 우선순위 충돌을 만들 수 있다.

7. **시즌 길이 과다**
   - 광역 기반시설 장애의 핵심 이야기가 종료된 뒤 회색 SUV 보안 이슈까지 본 시즌에 길게 포함됐다.
   - 후속 생활 이슈는 메인 재난의 의미 있는 결과일 수 있지만, 메인 압력이 해결된 뒤에는 `에필로그/미니 에피소드`로 분리하거나 더 빨리 종료하는 것이 좋다.

### S06 이후 우선순위
1. MUD UI를 본편 기본 시각층으로 명시하고 이미지 제작과 분리.
2. TURN STATE GATE 계속 강제.
3. 전체 HUD 반복 금지 — 결정 관련 상태만 노출.
4. AUTO는 큰 분기점까지 적극 사용.
5. 기존 거점 능력을 존중하되 새로운 압력축을 자연스럽게 이동.
6. 의미 있는 문제에는 마찰·기회비용·부분성공을 더 자주 적용.
7. 메인 재난이 끝나면 시즌 종료를 우선 검토하고 후속 사건을 무리하게 붙이지 않음.

## 최종 판정
S05는 **Runtime v2의 정합성 개선과 AUTO, MUD UI가 실제 플레이에 정착한 시즌**이다. 플레이 자체는 너무 안정적으로 풀린 구간이 많아 Normal 난이도 체감은 낮았다. 다음 단계는 시스템을 더 늘리는 것이 아니라, 현재 시스템으로 더 비싼 선택과 더 선명한 압력 이동을 만드는 것이다.
