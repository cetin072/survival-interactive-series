## 1. 현재 가족 생활 Canon
- 준호·서윤·민석: 평일 도심 생활.
- 정호: 외곽 거점 상주.
- 주말: 가족 4인이 외곽 거점에 재결집.
- 이 구조는 S06 시작사건이 자연스럽게 바꾸지 않는 한 기본 생활상태다.

## 2. 이미 확보된 실제 능력
외곽 거점:
- 제한적 태양광 + 배터리
- LPG 등 대체 조리
- 물 저장
- 장기보관 식량 + 순환재고
- 공구·보수·예비부품
- 보관구역 개선
- CCTV·출입 기록
- 정호의 평일 상주관리
- 가족 주말 유지보수

관계/네트워크:
- 최씨 가구와 핵심 협력
- 노동·정보 협력 / 자산·재고 소유 분리
- 최씨 우물은 최씨 개인자산
- 플레이어 태양광·배터리는 플레이어 가족 개인자산
- 평시 마을 운영은 이장 중심
- 필요 시 3인 연락망과 과거 비상협력 경험 재가동 가능

**S06에서 난이도를 맞추기 위해 이 능력을 임의 무효화하지 않는다.**

## 3. S06의 최우선 테스트 목표

### A. Decision Collision
최소 2회 이상 중요한 장면에서:
- 좋은 행동 여러 개를 모두 할 수 없거나
- 한 행동을 선택하면 다른 기회가 늦어지거나 사라지고
- 시간·거리·현금·역할·세계변화가 실제 비용으로 작동
해야 한다.

복수선택 `3 → 2 → 1`은 계속 허용한다.
단, 뒤 행동이 부분성공·지연·기회상실될 수 있다.

목표:
`강제 실패`가 아니라 `무엇을 우선할지 고민되는 비용`.

### B. 가족 자율성
가족 2명 이상이 시즌 중 최소 한 번씩 자연스럽게:
- 문제를 먼저 발견하거나
- 자기 역할에서 독립적으로 처리하거나
- 역할변경/운영변경을 제안하거나
- 중요한 순간 다른 우선순위를 제시
하도록 한다.

억지 가족갈등은 만들지 않는다.

### C. 다른 플레이 행동군
S02/S03/S05에서 반복 검증한 다음 루프를 S06의 기본 구조로 삼지 않는다.

`통신/정전 → 가족 위치확인 → 물/연료 확보 → 합류 → 외곽거점 이동 → 전력/물 운영`

특히:
- 전력·통신·단수를 시즌 주 압력으로 다시 쓰는 것을 우선 피한다.
- `가족 분산 → 전원 합류`를 자동 첫 퀘스트로 만들지 않는다.
- `외곽으로 가면 정답`인 시즌을 반복하지 않는다.

기존 거점이 실제 도움을 주는 것은 허용한다.
다만 거점이 답하지 못하는 다른 현실 압력을 선택한다.

### D. Phase별 플레이 동사 변화
장기형이면 각 Phase에서 실제로 하는 일이 달라져야 한다.

예시 방향만 참고:
- 초기: 판단/확보가 아닌 다른 종류의 즉시 대응 가능
- 중기: 배분·협상·역할 변화
- 장기: 생계·생활체계·거점/도심 사용방식 재편
- 최고조: 이미 존재한 압력 2개 이상이 한 결정구간에 합류

구체 장면은 미리 고정하지 않는다.

### E. 빠른 종료 판단
메인 압력이 새로운 안정상태에 들어가면 시즌 종료를 먼저 검토한다.
재미있는 후속 문제가 생겨도 메인 재난과 결이 달라졌다면 에필로그/미니에피소드/다음 시즌 후보로 넘긴다.

## 4. S06 Hidden World Seed 실험 기준
월드 시드는 대본이 아니라 최소 골격이다.

기본:
- 핵심 외생 압력 2~3개
- 예비 압력 1개 이하
- 최근 시즌과 다른 행동군
- 가족 시작배치 변형 가능
- 최소한의 장기 인과고리
- 종료 가능한 안정상태 조건

예비 압력은 플레이어가 잘했다는 이유로 자동 활성화하지 않는다.

## 6. S06 종료 후 판정 질문
S06 회고에서는 새 규칙을 많이 만들지 말고 아래만 우선 평가한다.

1. S05보다 실제 고민되는 선택이 늘었는가?
2. 복수선택의 순서와 비용이 체감됐는가?
3. 가족이 명령대기 인물이 아니라 독립 파티로 느껴졌는가?
4. 최근 정전/단수/외곽 이동 시즌과 플레이 감각이 달랐는가?
5. Phase가 변할 때 행동 종류도 달라졌는가?
6. 메인 압력이 끝난 뒤 불필요하게 시즌을 늘리지 않았는가?
7. 새 시스템 없이 Runtime v4만으로 충분히 재미가 개선됐는가?

이 7개가 S06의 핵심 성공기준이다.
