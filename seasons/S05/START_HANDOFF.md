# S06 START HANDOFF — S05 종료 상태

## 0. 먼저 읽을 것
새 시즌 시작 시 기본 런타임 로드:
1. `runtime/GM_KERNEL.md`
2. `core/CHARACTERS.json`
3. `core/PERSISTENT_CANON.md`
4. `players/main/SAVE_STATE.json`

이 문서는 S05에서 S06로 넘어가는 짧은 인계용이다.

## 1. 현재 가족 기본 생활
- 준호·서윤·민석: 평일 도심 생활.
- 정호: 외곽 거점 상주.
- 주말: 가족 4인이 외곽 거점에 재결집.
- 이 구조는 S06 시작 사건이 별도로 바꾸지 않는 한 기본 출발점이다.

## 2. 외곽 거점 현재 능력
- 제한적 태양광 + 배터리.
- LPG 등 대체 조리.
- 물 저장.
- 장기보관 식량과 순환재고.
- 공구·보수·예비부품.
- 보관구역 개선.
- CCTV·출입 기록.
- 정호의 평일 상주관리.
- 가족 주말 유지보수.

거점은 실제로 강해졌다. S06에서 난이도를 맞춘다는 이유로 이 능력을 임의로 고장내거나 삭제하지 않는다.

## 3. 최씨와 마을
- 최씨 가족은 핵심 협력 가구.
- 두 가족은 노동·정보는 적극 협업하되 재산·재고는 분리.
- 최씨 우물은 최씨 개인자산.
- 플레이어 태양광·배터리는 플레이어 가족 개인자산.
- 평시 마을 관리는 이장에게 위임.
- 장기위기 시 나·최씨·이장 3인 연결망과 과거 협력 가구 중심 비상운영회를 재가동할 수 있다.

## 4. S05에서 검증된 플레이어 성향
- 정보 확인 후 이동.
- 불확실한 위험은 굳이 돌파하지 않음.
- 시간 손해를 감수하고 우회 가능.
- 연료·물·정보처럼 선택권을 보존하는 자원을 우선.
- 공동체 협력은 하되 개인자산 경계를 명확히 함.
- 직접 대치보다 기록·공식채널 활용을 선호.

## 5. S06 GM 주의점
### 반드시 유지
- TURN STATE GATE.
- 기관 의사결정권 경계.
- AUTO로 반복운영 압축.
- MUD Text Visual Grammar.
- `NPC` 등 메타용어는 본편에 쓰지 않음.

### MUD UI
플레이 중 사용자가 `그래픽`, `UI`, `화면`을 말하면 별도 이미지 제작 요청이 없는 한 **텍스트 기반 MUD 화면 연출**을 뜻하는 것으로 우선 해석한다.

필요할 때만:
- SCENE HEADER
- WORLD STATE
- FAMILY
- RESOURCE
- AUTO
- EVENT
- PHASE CHANGE

를 사용한다. 모든 패널을 매턴 반복하지 않는다.

### S06 재미 과제
- 거점이 정답인 재난을 반복하지 않는다.
- 그렇다고 거점을 억지로 무효화하지도 않는다.
- 가족 위치, 이동 가능성, 의료/행정/직장 의무, 지역 특성, 다른 재난축 등에서 새로운 압력을 만든다.
- 복수선택은 시간·거리·기회비용 때문에 후속 행동이 실제로 사라질 수 있다.
- 가족이 합리적으로 먼저 제안하거나 반대하는 장면을 늘린다.
- 메인 재난이 새로운 안정상태에 도달하면 시즌 종료를 먼저 검토한다.

## 6. 미디어
S05에서 다시 확인된 원칙:
- 플레이 중 실제 삽화/영상 제작을 끼워 넣지 않는다.
- 현재 본편의 `그래픽 요소`는 MUD 텍스트 시각문법이다.
- 이미지·영상 자산화는 시나리오를 별도로 정제하기로 결정했을 때만 TIER 3에서 진행한다.
