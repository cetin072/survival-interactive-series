# S02 Design Status

STATUS: READY FOR HIDDEN WORLD SEED
TITLE: 미정

## 현재 지위
S02는 아직 플레이되지 않았다.
재난 종류, 시작 사건, 주요 위험, 엔딩을 미리 공개하거나 완성 대본으로 작성하지 않는다.

## 시작 규칙
플레이 직전 GM은 `docs/WORLD_SEED_PROTOCOL.md`와 최신 공통 규칙을 읽고 비공개로 최소 월드 골격만 생성한다.

반드시 반영:
- S01에서 검증된 가족 4인 파티와 현실 한국형 세계
- Player Known Information Rule
- Multi-Base Rule
- Normal Society Continuity Rule
- Risk Exposure Rule
- Post-Disaster Secondary Hazard Rule
- Decision Cost over Event Count

S02 체감 목표:
- S01보다 사건 수를 억지로 늘리지 않는다.
- 선택의 비용과 포기 구조를 한 단계 강화한다.
- 자원 부족, 정보 불확실성, 시간 압박, 가족 이해 충돌, 되돌릴 수 없는 선택, 장기 인과를 강화한다.
- 이동/대피만 반복하지 않고 다른 종류의 문제 해결을 포함한다.

## 금지
- S01 구조를 이름만 바꿔 반복
- 정답 루트 선작성
- 위험 선택을 자동 사고로 처벌
- 플레이어가 원래 아는 정보를 선택 후 공개
- 모든 재난을 사회붕괴로 과장
