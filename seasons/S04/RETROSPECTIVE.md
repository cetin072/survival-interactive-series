# S04 Retrospective — 해협

## A. 플레이어 생존 복기

### 총평
S04의 핵심 성공은 `전쟁 = 즉시 외곽 대피`로 단순화하지 않고, 한국의 정상사회 기능이 유지되는 동안 도심 생활과 외곽거점을 동시에 살린 것이다.

### 잘한 판단
1. **초기 선제확보 후 구매전 종료**
   - 차량 연료, 평시 범위의 비상연료, 장기보관 생활물자를 초기 단계에서 보강했다.
   - 이후 공급불안이 커져도 계속 사재기하지 않고 현금 보존으로 전환했다.

2. **도심 + 외곽 이중거점 유지**
   - 회사·병원·학교가 작동하는 동안 가족 전체를 조기 외곽이주시키지 않았다.
   - 외곽은 대피소가 아니라 장기 공급차질에 대응하는 제2 운영거점으로 강화했다.

3. **정비·예비부품 우선**
   - 큰 설비를 무조건 추가하기보다 고장 시 복구를 가능하게 하는 정비·예비부품을 먼저 확보했다.
   - 전력·물은 병목 핵심부품만 얕게 선점하고, 가격·납기가 악화되자 대규모 추가투자를 중단했다.

4. **소득감소 전에 지출구조 조정**
   - 주4일제·순환휴업이 실제 소득감소로 이어지기 전에 비필수지출·큰 구매·추가설비 투자를 줄였다.
   - 현금 소모속도를 낮추고 유동성을 보존했다.

5. **가족 역할 위임**
   - 정호에게 외곽 일상운영과 민석 생활관리까지 맡겼다.
   - 민석은 정보취합·재고기록·생활역할을 수행하며 독립성이 강화됐다.
   - 서윤의 병원 노동부담이 증가할 때 가족 내 부담을 다른 구성원이 흡수했다.

### 개선할 판단
1. **가계 현금 런웨이 확인 부족**
   - `현재 생활비 기준 몇 개월 / 긴축 기준 몇 개월`을 초기에 명확히 확인하지 않았다.
   - 장기 위기에서는 물자재고와 함께 현금 런웨이를 핵심 상태로 봐야 한다.

2. **서윤 추가소득의 성격 구분**
   - 추가근무 수입은 가계 완충재였지만 장기적인 안정소득 증가가 아니라 노동부담 증가의 결과였다.
   - 장기화 시에는 서윤 부담 완화가 별도 대응축이 되어야 한다.

3. **외곽 노동과 현금소득의 구분**
   - 준호의 비근무일 외곽 노동은 정비비·생활비 감소와 회복탄력성 향상에는 유효했다.
   - 그러나 장기적으로 회사소득 감소가 커질 경우 새 현금흐름 탐색과 비교해야 한다.

4. **도심↔외곽 전환 기준 구체화**
   - 전환 조건은 만들었으나 단계별 행동기준은 추상적이었다.
   - 향후에는 `관찰 → 부분체류 → 전환검토`처럼 단계적 트리거를 둘 수 있다.

### 생존 결론
S04의 생존은 대피 성공이 아니라 **대피할 필요가 없도록 선택권과 현금·시간·거점 여유를 유지한 것**이 핵심이었다.

## B. 게임 / GM 시스템 복기

### 총평
S04는 정상사회·경제·공급망이 재난 속에서도 계속 작동하는 세계를 구현하는 데 성공했다. 반면 중후반은 경제·가계 운영 시뮬레이션 비중이 커졌고, 생존게임으로서 급박한 사건과 선택 비용이 부족했다.

### 유지할 강점
1. **독립적으로 움직이는 세계**
   - P1 초기충격 → P2 공급망 압박 → P3 국내 적응·제한 → P4 장기 재편·긴장완화가 플레이어와 독립적으로 진행됐다.

2. **Normal Society Continuity**
   - 회사·병원·학교·정부가 사라지지 않고 각자 적응했다.
   - 회사: 긴급구매 → 재택 → 주4일 → 순환휴업 → 공급망 재편.
   - 병원: 비상대기 → 소모품 관리 → 대체품 전환 → 정상화.
   - 학교: 정상수업 유지 + 일부 활동 축소.

3. **가족 4인 역할 분화**
   - 정호는 외곽 독립 운영축.
   - 민석은 정보·기록·생활 역할.
   - 서윤은 병원이라는 독립 압력축.
   - 준호는 모든 일을 직접 처리하지 않고 위임하는 방향으로 변화.

4. **Anchor NPC 박재현**
   - 익명 기관 공지보다 회사 세계를 인간적으로 전달하는 역할이 효과적이었다.
   - 향후에도 반복 회사 NPC로 유지 가능.

5. **AUTO + Text Visual Grammar**
   - Scene Header, 정보출처 태그, 가족위치, AUTO, Phase Change, 경량 상태판은 가독성과 게임감을 높였다.
   - 반복 구매·정비를 압축하는 데 효과적이었다.

### 핵심 문제
1. **복수선택 비용 부족**
   - `3 → 2 → 1` 같은 복수선택이 너무 자주 모두 성공했다.
   - 복수선택은 순서·시간·거리·자원 때문에 뒤 행동이 부분 성공하거나 기회가 사라질 수 있어야 한다.

2. **강한 외생 충격 부족**
   - 전쟁 규모에 비해 가족 체감은 가격·납기·근무감소 중심으로 지나치게 점진적이었다.
   - 장기재난에도 플레이어와 독립적인 강한 외생 사건이 1~2회 이상 필요하다.
   - 단, 임의 사고나 플레이어 처벌이 아니라 Hidden World Seed와 현재 세계상태에서 자연스럽게 발생해야 한다.

3. **Phase별 플레이 방식 변화 부족**
   - P2와 P3의 세계 상태는 달라졌지만 장면 구조는 `회사 → 병원 → 학교 → 외곽 → 뉴스 → 선택`이 반복됐다.
   - Phase 전환은 수치 악화가 아니라 플레이어가 해야 하는 행동 종류와 장면 구조를 바꿔야 한다.

4. **사건 밀도 부족**
   - AUTO로 반복 실무는 줄였지만 `AUTO 보고 → 선택 → AUTO 보고` 패턴이 반복됐다.
   - 평온한 1주를 여러 번 보여주기보다 압축 후 바로 의미 있는 사건·갈등·기회로 이동해야 한다.

5. **기관 권한 경계 오류**
   - 한 차례 회사의 구매·협력업체 정책 결정을 준호에게 선택시키는 GM 오류가 있었다.
   - 플레이어가 기관 책임자가 아니라면 기관 의사결정은 NPC/기관이 한다.
   - 플레이어는 자기 업무·시간·가족·개인 리스크에 대한 대응을 선택한다.

6. **가족 자율성은 개선됐지만 아직 플레이어 지시 의존**
   - 가족이 맡은 일을 잘 수행했으나 새로운 운영방식을 먼저 제안하는 빈도는 더 높일 수 있다.
   - 핵심 가족은 필요할 때 `내가 이걸 맡겠다`, `이 방식은 바꾸자`처럼 자율 제안을 할 수 있어야 한다.

7. **저장 운용 과다 및 정합성 버그**
   - 초반에 선택마다 GitHub 접근으로 플레이 흐름이 느려졌다.
   - 한 차례 SAVE_STATE와 GM_STATE의 Phase가 불일치했다.
   - 일반 선택은 채팅에서 진행하고 Phase·거점·가족구조·장기자산·시즌 종료 등 의미 있는 체크포인트만 저장한다.

### S05 이후 핵심 수정 우선순위
1. **강한 외생 충격 1~2회 이상** — 장기재난의 평온한 운영을 깨는 실제 상태변화.
2. **복수선택 비용 강제** — 모든 좋은 선택을 동시에 획득하지 못하게 시간·기회비용 반영.
3. **Phase마다 플레이 방식 전환** — 장면의 문제 유형·행동 유형 자체를 변화.
4. **장면 밀도 상승** — 일상·반복은 과감히 압축하고 중요한 장면으로 빠르게 이동.
5. **기관 권한 경계 유지** — 회사·병원·학교·정부의 결정은 해당 기관이 한다.
6. **가족 자율제안 강화** — 가족이 플레이어 명령 없이도 합리적 새 행동·운영변화를 제안.
7. **GitHub 저장 최소화** — 1세션 1~3회 수준의 의미 있는 체크포인트 중심.

## 최종 판정
S04는 **현실적인 장기재난 세계 시뮬레이션으로는 큰 발전**이었다. 다음 단계는 시스템 추가가 아니라 **현재 시스템에 더 강한 사건, 더 비싼 선택, 더 빠른 전개를 적용해 생존게임의 박동을 높이는 것**이다.
