# S01 산불 Storytelling Baseline

## 용도
이 파일은 현재 웹 AI GM과 과거 Canon v2 S01 플레이의 **스토리텔링 비교 기준**이다.
런타임 입력이나 현재 세계 사실 소스로 사용하지 않는다.

## 근거
- `seasons_v2/S01/raw_transcript/INDEX.md`
- `seasons_v2/S01/raw_transcript/PART_001.md` ~ `PART_009.md`
- `canon_v2/CHARACTERS.json`

S01 RAW INDEX 기준으로 시즌 시작부터 종료까지 플레이 순서가 연속 보존되어 있다.

---

## 과거 시작 조건
- 현대 한국 / 2026년 9월 초 저녁
- 한준호: 회사, 퇴근 직전
- 서윤: 병원
- 민석: 학원
- 정호: 산림·밭과 가까운 외곽주택
- 가족 네 명이 서로 다른 위치
- 휴대전화·통신 정상
- 차량 이용 가능
- 퇴근시간 교통 증가
- 강풍과 산불 확산 우려 긴급 안내
- 외곽 방면 도로 통제 가능성
- 병원 비상대응 가능성

## 과거 GM의 초반 전개 특성
- 플레이어의 짧은 복수선택을 여러 실제 장면으로 풀었다.
- 서윤·정호·민석과 각각 직접 대화가 발생했다.
- 한 번의 선택 뒤에도 도로 정체, 대피방송, 병원 비상대응, 학원 조기 귀가 같은 세계 변화가 추가로 발생했다.
- 가족은 플레이어 지시를 자동 수행하지 않았다.
  - 정호는 이웃을 먼저 확인하려 했다.
  - 서윤은 병원에 남을 가능성을 전제로 독자적인 안전 기준을 제안했다.
  - 민석은 자신의 이동 가능성과 정보를 직접 제시했다.
- 다음 선택지는 직전 선택의 단순 변형이 아니라 새로 발생한 문제에서 나왔다.

## 실제 과거 사용자 경로 일부 — 비교 전용
이 경로는 현재 웹 AI GM에 주입하지 않는다.

초반 실제 입력 예:
- `321`
- `2 4`
- `2 5`

이 입력들은 당시 GM이 각각 가족 합류 판단, 아버지 대피 압박, 서윤의 병원 상황, 민석 이동, 새 합류점 설정 등 여러 장면으로 확장했다.

## 과거 품질에서 유지하고 싶은 것
1. 선택 후 충분한 장면량
2. 가족의 실제 대화
3. 가족의 수정·거절·독립 판단
4. 선택 이후 세계가 한 번 이상 추가로 움직임
5. 새 정보가 다음 선택을 자연스럽게 만듦
6. 위기와 안정기의 리듬 변화
7. 단기 선택이 장기 거점·가족 전략으로 이어짐
8. 설명문보다 실제 플레이 장면을 읽는 느낌

## 현재 테스트와 의도적으로 다른 것
- 과거 문장을 복제하지 않는다.
- 과거 선택 경로를 강제하지 않는다.
- 정확한 사건 순서를 고정하지 않는다.
- 현재 AI GM은 같은 출발 압력에서 플레이어의 새 선택을 보고 독립적으로 전개한다.

## 비교 시 확인
- 과거와 현재의 턴당 장면 밀도
- 직접 대화 빈도와 자연스러움
- 예상 밖의 외부 변화
- 가족 자율성
- 선택 회수
- 상태 연속성
- 선택지의 자연스러움
- 장기 국면 확장
- 반복 문장·매크로 반응
- 계속 읽고 싶은 정도
