# Survival Interactive Series

가칭 **《생존기록》** — 현대 가족을 중심으로 한 현실형 생존 인터랙티브 드라마 프로젝트.

> 가칭은 정식명 확정 전까지 사용하는 작업명이다.

## 목표
- 재미와 몰입이 0순위
- 30~40대 남성 플레이어가 가족 4인을 실제 파티처럼 운영
- 재난·인프라 장애·대피·자원관리·정보판단을 실제 원리에 가깝게 경험
- 플레이 중에는 강의하지 않고, 시즌 종료 후 원할 때만 현실 대응을 복기
- 시즌 길이는 고정하지 않고 시나리오 완성도에 따라 유연하게 운영
- 최초 플레이에서 공동 생성된 이야기를 시즌 종료 후 재사용 가능한 시나리오와 삽화 자산으로 정리

## 새 채팅 시작점
ChatGPT GM은 가장 먼저 `START_HERE.md`를 읽는다.

장기 방향은 `core/PROJECT_DECISIONS.md`, 자동 저장은 `docs/AUTOSAVE_POLICY.md`, 시즌 완료 후 자산화는 `docs/SEASON_COMPLETION_PIPELINE.md`, 삽화 계획은 `docs/ILLUSTRATION_PIPELINE.md`를 기준으로 한다.

### 기본 명령
- `생존기록 시작` → 새 시즌 시작
- `생존기록 이어서` → 최신 저장 상태에서 계속
- `메모: ...` → 아이디어 장기 저장
- `저장` → 현재 체크포인트 저장
- `종료` → 저장 후 세션 종료

## Source of Truth
이 저장소가 게임의 장기 설정·세이브·시나리오 기록의 원본이다. 이전 채팅 기억보다 저장소의 최신 Canon과 State를 우선한다.

## 구조
- `core/` : 세계관, 게임 규칙, 캐릭터, 장기 기획 결정
- `schemas/` : 상태 파일 형식 검증
- `seasons/` : 시즌별 시나리오와 GM 상태
- `players/` : 플레이어별 세이브, 체크포인트, 로그
- `idea_vault/` : 재난·딜레마·장소·NPC·생존지식 아이디어
- `knowledge/` : 현실 생존지식 검증 출처
- `playtests/` : 실제 플레이에서 발견된 개선점
- `docs/` : 자동저장, 시즌 자산화, 삽화 파이프라인
- `tools/` : 검증 도구

## 주의
이 저장소는 Public이다. 실제 주소, 전화번호, 계정정보, API 키, 비밀번호, 토큰 등 민감한 정보는 절대 저장하지 않는다.
