# Survival Interactive Series

현대 가족을 중심으로 한 현실형 생존 인터랙티브 드라마 프로젝트.

## 목표
- 재미와 몰입이 0순위
- 30~40대 남성 플레이어가 가족 4인을 실제 파티처럼 운영
- 재난·인프라 장애·대피·자원관리·정보판단을 실제 원리에 가깝게 경험
- 플레이 중에는 강의하지 않고, 시즌 종료 후 원할 때만 현실 대응을 복기
- 시즌 길이는 고정하지 않고 시나리오 완성도에 따라 유연하게 운영

## Source of Truth
이 저장소가 게임의 장기 설정·세이브·시나리오 기록의 원본이다.

## 구조
- `core/` : 세계관, 게임 규칙, 캐릭터
- `schemas/` : 상태 파일 형식 검증
- `seasons/` : 시즌별 시나리오와 GM 상태
- `players/` : 플레이어별 세이브와 로그
- `idea_vault/` : 재난·딜레마·장소·NPC·생존지식 아이디어
- `tools/` : 검증 도구

## 주의
이 저장소는 Public이다. 실제 주소, 전화번호, 계정정보, API 키, 비밀번호, 토큰 등 민감한 정보는 절대 저장하지 않는다.
