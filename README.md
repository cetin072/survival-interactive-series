# Survival Interactive Series

《생존일기》의 플레이 Canon, 세계선 기록, 웹게임, Archive와 Automation A/B/C를 함께 관리하는 저장소입니다.

## 시작점

- **현재 시스템과 책임 경계:** [SYSTEM_MAP.md](SYSTEM_MAP.md)
- **플레이 세계선과 정확한 boot 라우팅:** [WORLDLINE_ROUTER.md](WORLDLINE_ROUTER.md)
- **기존 가족 기반 플레이:** [START_HERE.md](START_HERE.md)
- **Canon v2 가족 시즌:** [REBOOT_START_HERE.md](REBOOT_START_HERE.md)
- **독립 AFTERFALL·STRONGHOLD:** Router에서 branch와 entrypoint를 확인한 뒤 해당 branch의 최신 boot/handoff를 사용합니다.
- **개발 및 안전 기준:** [AGENTS.md](AGENTS.md)

저장소에는 현행 구현과 과거 플레이·설계 자료가 함께 있습니다. 오래된 상태 설명을 현재 Save나 Canon으로 사용하지 마세요. 세계선 identity가 확인되지 않으면 다른 세계선으로 대체하지 않습니다.

## 제품 방향

- 플레이의 재미와 몰입을 우선합니다.
- 현실적인 생존 판단과 가족·동료 관계를 다룹니다.
- AI가 제안하고 authoritative engine이 최종 상태를 확정합니다.
- 플레이 기록은 RAW로 보존하고, Reader·Graph·Visual·Knowledge는 검증된 source에서 파생합니다.

Public 저장소이므로 주소, 전화번호, 계정정보, API 키, 비밀번호, 토큰, 개인 접근코드 등 민감정보를 커밋하지 않습니다.
