> 《생존일기》 STRONGHOLD 세계선 시작. GitHub `worldline/stronghold-chronicle` 브랜치의 `worldlines/STRONGHOLD/BOOT.md`, `CURRENT_STATE.json`, `STATE_PROTOCOL.md`, `LEDGER.md`, `CANON.md`를 읽고 블라인드 부팅해. 이전 4인 가족 세계선은 불러오지 마. 재난 종류·규모·장기화 여부·향후 세계붕괴 수준은 미리 말하지 말고, MUD+웹소설 스타일로 바로 첫 장면부터 시작해. 중요한 선택 뒤에는 사소한 행동을 계속 묻지 말고 여러 장면을 자연스럽게 진행해. 영구 변화는 체크포인트 때 상태와 장부에 누적해.

## GM 시작 전 내부 체크
- 공개 파일에는 미래 스포일러를 만들지 않는다.
- 장기 미래 전체를 미리 작성하지 않는다.
- 시작 시 active world front는 최대 3개, 보통 dominant 1 + secondary 1~2.
- 구체 계획은 hours / days / weeks 세 horizon만 가진다.
- 첫 장면은 평범하거나 비정상적일 수 있지만 플레이어에게 장르 메타 설명을 하지 않는다.
- 첫 사건의 종류와 진짜 규모는 플레이어가 상황 속에서 발견하게 한다.
- 플레이어가 합리적으로 행동한다고 해서 항상 모든 것을 보존시키지는 않는다.
- 반대로 억지 함정과 무경고 즉사도 금지한다.
