# STRONGHOLD — FEEDBACK — 2038-05 ~ 2039-12

Status: **POST-ARC REVIEW**

## 사용자 종료 피드백
- 최근 사용자는 코딩과 프로그램 제작에 관심이 크게 올라가 생존 게임에 손이 덜 가는 상태라고 직접 밝혔다.
- 머리가 복잡하고 현재 시즌에 대한 집중도가 떨어진 상태이므로 여기서 시즌을 닫고 다음에 새 시즌으로 다시 시작하기를 원함.
- 이번 시즌 중후반의 같은 사람 / 비슷한 기록 / 인커전 비슷한 감각이 이전 시즌과 반복된다고 느낌.
- 다음 시즌은 이 반복을 끊고 새로운 중심축으로 시작해야 함.

## 잘된 점
1. 초반 훅은 강했다.
   - 직사광선이 사람·차량·전력설비를 공격하고 낮 이동 자체가 위험해지는 문제는 즉시 생존동사를 만들었다.
   - 한지연을 물류센터에 남길지, 환자를 어떻게 이송할지, 전력을 어디까지 끊을지 등 실제 대가가 있었다.
2. 준비가 실제 보상으로 작동했다.
   - 1번/2번 집, 회사 조직, 물류망, 분산설비, 비축과 관계망이 피해 감소와 선택지 증가로 이어졌다.
   - 준비가 플롯 면역은 아니었고 차량·상품·설비·현금 등 실제 손실과 비용이 생겼다.
3. 세계가 실제로 바뀌었다.
   - 단기 재난 뒤 정상복귀가 아니라 야간사회 → 차폐/지하사회로 생활방식이 재편됐다.
   - 뒤 토지, 위 거점, 아래 거점, 지하통로가 누적 자산으로 성장한 점은 STRONGHOLD 세계선의 장점과 잘 맞았다.
4. 박도현이 다시 상시 지도자로 고정되지 않았다.
   - 광역거점에서도 설계/정보/연결만 제공하고 운영권·상시 책임을 제한하려는 선택이 유지됐다.

## 실패한 점
1. 한 시즌 중심축 하나 원칙을 크게 위반했다.
   실제로 한 시즌 안에서 이상 일사 생존 / 야간사회 전환 / 거점개발·사업성장 / 야간마저 위험해지는 변화 / 지하사회 / 시간·거리 불일치 / 조기경보망 / 미래기록·동일인물 기록 불일치를 모두 전면화했다.
   최소 3~4개 시즌 분량을 한 시즌에 붙였다.
2. 시즌 종료 타이밍을 여러 번 놓쳤다.
   - 첫 번째 좋은 종료 후보: 야간사회가 정착되고 뒤 토지의 새 역할이 열렸을 때.
   - 두 번째 종료 후보: 밤까지 위험해져 시간의 문제 → 공간의 문제로 플레이 동사가 완전히 바뀌었을 때.
   - 세 번째 종료 후보: 아래 거점/지하통로 구축이 안정됐을 때.
3. Concept Proof Budget을 다시 위반했다.
   - 다른 도로 → 다른 터널 → 다른 시설 → 다른 기록 → 다른 물건 식으로 이미 이해된 현상을 사례로 반복했다.
   - 새 가치충돌이나 영구손실이 없는 사례도 고해상도로 전면화된 장면이 많았다.
4. 이전 2032 인커전/기록중첩 계열 감각을 재사용했다.
   - 거리·시간 불일치에서 끝났어도 충분히 새로운 시즌이었는데, 동일인물 CCTV/미래 기록/현실 재작성까지 가면서 이전 시즌 핵심 감각과 겹쳤다.
   - 사용자가 지적한 같은 사람 반복은 정확한 문제점이다.
5. 생존 RPG가 관측·운영 시스템 게임으로 밀렸다.
   - 후반 주동사는 이동·구조·식수·연료·거점 선택보다 센서값·기록분류·네트워크 프로토콜 설계가 됐다.
   - 사용자가 현재 코딩/프로그램 제작에 몰입한 시기에는 이런 시스템 설계가 실제 관심사와 경쟁하며 게임의 휴식/유희 기능을 약화시킬 수 있다.
6. Rolling RAW 자동화가 실행되지 않았다.
   - 시즌 시작 지침에는 6~10왕복/큰 장면마다 Rolling RAW 저장이 명시되어 있었으나 실제 플레이 중 실행되지 않았다.
   - 이번 종료에서 RAW는 PARTIAL로 정직하게 남긴다.
   - 다음 시즌에는 큰 장면 단위로 실제 자동 flush가 수행되어야 한다.

## 다음 시즌 강제 교정
- 완전 새 중심축 하나.
- 첫 1~2응답 안에 명확한 생존 압력과 의미 있는 선택이 등장해야 한다.
- 고해상도 보조 스레드는 최대 2개.
- 이미 이해된 세계규칙은 추가 사례 1개 이하.
- 기록/신원/동일인물/미래문서/시간·거리 불일치는 다음 시즌 메인 재난으로 사용하지 않는다.
- 거점개발·사업·지역운영은 배경 자동처리하고 실제 생존 선택과 충돌할 때만 확대한다.
- 한 중심문제가 해결되거나 플레이 동사가 바뀌면 즉시 시즌 종료 후보로 처리한다.
- 기본적으로 이번보다 짧고 밀도 높은 시즌을 선호한다. 사용자의 몰입이 다시 크게 올라갈 때만 자연스럽게 확장한다.
- 현재 사용자의 생존게임 관심 저하는 영구 취향으로 단정하지 않는다. 다음 복귀 때 빠르게 재미를 확인하고 조정한다.

## GM 결론
이번 시즌은 초반 절반은 강했고 후반 절반은 과도하게 확장됐다.
좋은 핵심 아이디어였던 낮을 잃은 세계를 충분히 성공시킨 뒤 닫았어야 한다.
이후 밤의 붕괴, 지하사회, 시간/거리, 기록현실까지 모두 같은 시즌에 넣으면서 각 아이디어의 신선도와 플레이어 집중력을 서로 깎았다.

다음 시즌의 가장 중요한 목표는 더 복잡하게 만드는 것이 아니라 새롭고, 빠르고, 하나에 집중하는 것이다.
