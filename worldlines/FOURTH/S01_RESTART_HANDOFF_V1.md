## 초반 긴장도를 바로잡는 구체 기준

1. 시작 전 GM 내부에서 경보·충돌·지역 도달·기관 대응의 시간표를 정한다. 이동·대기·구매에도 시간이 흐르고, 다른 장소의 사람과 기관도 동시에 움직인다. 플레이어가 준비할 때마다 충돌이 뒤로 밀리지 않는다.
2. 기존 초고에서 모두 쉽게 성립한 연속 구매·결제·주유·귀가를 예정된 성공 동선으로 재현하지 않는다. 판매자 자신의 귀가, 재고, 줄, 도로, 운영 중단이 선택 비용과 연결된다. 준비에 성공하면 그 성과는 지킨다.
3. 경보를 안 사람들의 귀가·가족 확인·업무 중단·대피 문의가 실제 장면을 바꾼다. 모두 똑같이 공황에 빠질 필요는 없지만, 사회 전체가 평시 속도로 서비스해주는 식으로 쓰지 않는다.
4. 각 장면은 달라진 조건이나 의미 있는 선택을 남긴다. 같은 방송의 반복 청취, 이웃과의 무난한 확인, 생활 체크리스트만 이어가며 큰 사건을 미루지 않는다.
5. 전지적 시점을 이용해 충돌 현장과 기관의 한계도 보여주되, 독자가 본 정보를 주인공이 아는 정보로 바꾸지 않는다.
6. 긴장감을 높이려고 임의의 전국 EMP·창원 전면 붕괴·즉시 충돌겨울·준비품 소멸을 추가하지 않는다. 물리적 충격이 늦거나 약한 지역에서도 사람·교통·의료·물류의 부담을 인과적으로 보여준다.
7. 주요 인물 최초 의미 있는 등장에는 얼굴·체형·머리·복장·목소리·움직임 중 여러 특징을 2~5문장 정도로 장면 속에 담는다. 이후 장황한 재소개나 캐릭터시트 감사에 매몰되지 않는다.
8. 태준은 자기 집 구조와 평소 배송 동선을 이미 안다. 플레이어에게 일상 지식까지 다시 확인시키지 않는다.
9. 설명 자체를 일괄 줄이라는 요구로 오해하지 않는다. 독자의 이해를 돕는 구체적인 인과와 인물 묘사는 필요하다.
10. 본편에 DB·감사·개발 보고를 끼워 넣지 않는다.

## 물리 검토의 현재 한계

정확한 충돌점, 밀도, 속도, 각도, 지층, 대기 조건을 모두 확정한 창원 피해 시뮬레이션은 아직 없다.
대표 거리 2,000~3,000km를 놓으면 표면파 5km/s의 단순 거리 계산은 약 7~10분, 대기 전파 속도 330m/s의 단순 계산은 약 101~152분이다.
이는 도달 시간의 거친 비교이며 창원의 진도·최대압력·유리 파손율을 검증한 수치가 아니다. 실제 대기 전파는 고도·바람·굴절·지구 곡률 등에 영향을 받는다.
앞서 준비하던 답변은 이 계산을 사용했지만 공개·저장되지 않았다. 그 답변의 새 경보·현장 묘사는 이미 발생한 정사로 취급하지 않는다.
2km 크기만으로 즉시 전국 파괴나 장기 냉각 수치를 확정하지 않는다.

## 새 채팅방 첫 실행

1. 이 문서와 최신 BOOT.md / GM_RULES.md / WORLD_BIBLE.md를 읽는다. BOOT의 “현재 Save 이어가기”보다 사용자의 이번 재시작 요청을 우선 적용한다.
2. Supabase survival_rpg.saves의 WORLDLINE_04를 직접 다시 읽고, 기존 초고와 새 플레이를 구분한다. 현재 남아 있는 D0 13:22 장면을 이어 쓰지 않는다.
3. 활성 상태를 바꾸기 전에 실제 최신 Save의 원본 사본이 영속 보존되어 있는지 확인한다. 버전이 9보다 늘었으면 위 사본을 최신이라고 주장하지 말고 새 버전을 별도로 보존한다. 기존 RAW를 수정·삭제하지 않는다.
4. 기존 범용 세션 함수의 실제 시그니처를 확인해 새 플레이용 세션을 연다. 같은 WORLDLINE_04/C04/S01을 유지하고 새 session_id로 구분한다. 구 세션은 보존한다.
5. 최초 배송 시점의 상태를 기존 시작 RAW에서 확인해 구성한다. 집에 이미 있던 기초 물건과 과거 플레이에서 구매한 물건을 구별한다. 모르는 초기 수량은 임의의 확정 숫자로 채우지 않는다.
6. 활성 Save 교체는 실제 expected_version CAS로 수행한다. save_version을 1로 되감지 않는다. 구 시도의 사건·관계·물품을 새 초기 상태로 섞지 않는다.
7. 새 세션과 초기 Save 성공을 읽어 확인한 다음, 이름·나이 재설문 없이 첫 배송 장면으로 시작한다. 이후 사용자의 선택을 받는다.
8. 이후 USER/GM 공개 원문은 append_c04_public_turn으로 정확히 저장한다. Codex 이미지 오류 문자열은 사용자 발언에서 제외한다. 새 세션의 실제 메시지 순서에 맞춰 turn_no를 정하고 실제 저장 여부를 구별한다.
9. 운영 준비만 했으면 준비만 했다고 말한다. 활성 Save가 초기화되지 않았는데 “재시작 저장 완료”라고 주장하지 않는다.
