# AFTERFALL S01 — RAW TRANSCRIPT INDEX

Status: **COLD ARCHIVE / BACKFILL REQUIRED / NOT BOOT INPUT**

이 디렉터리는 AFTERFALL 시즌 1의 실제 USER/GM 공개 원문을 장기 보존하기 위한 Cold Archive 위치다.

## 현재 보존 판정

**RAW COMPLETE로 판정하지 않는다.**

현재 종료 작업 시점의 모델 컨텍스트에는 시즌 1 시작부터 종료까지 모든 사용자/GM 원문이 verbatim으로 남아 있지 않다.
초반~중반 일부 구간은 요약·구조화 상태만 확인 가능하다.

따라서 정책에 따라:
- 기억으로 원문을 재구성하지 않는다.
- 요약을 RAW처럼 변환하지 않는다.
- 접근 불가 구간을 숨기지 않는다.
- 현재 ChatGPT 원대화방을 해당 구간의 1차 원본으로 취급한다.

- 검증 가능한 원문 파일

그때:
