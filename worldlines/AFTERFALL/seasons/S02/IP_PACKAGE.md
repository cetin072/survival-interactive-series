# AFTERFALL S02 — IP PACKAGE

Status: **REUSABLE STORY ASSET / CANON-DERIVED**

## Logline

혹한에 대비한 거점은 살아남았지만 주변 생활망이 하나씩 끊어지기 시작한다. 간호사 서진우와 동료들은 모든 사람을 구하는 대신 연결망을 재설계하고, 겨울을 지나며 은신처 중심의 생존집단에서 주거·시장·생산·후퇴 기능이 분리된 작은 생활권으로 변한다.

## Core conflict

> 우리 거점은 살아남을 수 있다. 그러나 우리 주변의 생활세계까지 유지할 수 있는가?

## Character / relationship assets

- 서진우: 해결사·직접개입자에서 연결·선별·고위험 현장 역할로 이동.
- 윤서진: 핵심 4인의 생활 안정과 의료 판단축.
- 최은채: 장부·물류·권한선·운영체계를 조직으로 바꾸는 역할.
- 장태훈: 설비와 중복성, 후퇴선의 실무 핵심.
- 신하영: 독립적인 거래·정보·중개축으로 성장.
- 최유진: 생활지원과 숙박경계를 독립적으로 운영.
- 문하진: 공공시설·외부관문 운영축.
- 한미라: 생산거점의 자율성을 지키는 별도 리더.

## Strong scenes

- 서쪽 산업화재 방어와 실증단지 실제 손실.
- 광역 무선·전력 이상이 여러 지역에서 교차확인되는 밤.
- 대혹한으로 13인 생활노드가 폐쇄되고 인명피해가 발생하는 장면.
- 얼어붙은 관정·온실을 단계적 해빙과 바이패스로 살리는 장면.
- 백운 이탈자 12명이 제3거점 밖에 도착하는 밤.
- 체육시설·폐교·직업훈련원을 비교하며 ‘어디서 살 것인가’를 결정하는 과정.
- 핵심 4인의 직업훈련원 시험거주.
- 북서 실습센터를 공동 숨은 방공호로 바꾸는 합의.
- 체육시설 정기시장 정착.
- 첫 봄꽃과 동시에 동천교에 도착한 동일 표식 차량행렬.

## Reusable event archetypes

- 핵심기지는 생존하지만 주변 생활망이 먼저 죽는 재난
- 자원거점이 지역질서로 발전하는 과정
- 공개 관문과 숨은 후방기지를 분리하는 생활권
- 난민 ‘집단’이 아니라 각 개인의 목적을 분리해 처리하는 입구
- 임시 중개게시판이 시장/길드로 성장하는 과정
- 좋은 준비가 손실을 0으로 만들지는 않지만 피해를 크게 줄이는 구조
