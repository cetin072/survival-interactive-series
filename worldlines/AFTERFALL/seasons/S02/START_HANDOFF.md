## 5. 플레이 운영

- 반복 내정·재고·정기거래는 자동/압축.
- 이상, 손실, 갈등, 공급단절, 중요한 관계변화가 있을 때만 확대.
- 진우는 외부 현장·응급·정찰·연결 중심.
- 외부 분쟁을 모두 해결하지 않는다.
- 개인 의견과 대표권을 구분한다.
- 새 NPC/새 세력은 필요할 때만 추가.
- 기존 인물과 집단을 깊게 사용.

## 6. NPC 자율관계

진우가 없는 동안에도 NPC는 독립적으로:
- 일한다
- 친해진다
- 멀어진다
- 싸운다
- 화해한다
- 호감·연애감정·질투가 생길 수 있다

관계변화는 자동커플이 아니며 성격·접촉·사건 인과에서 발생해야 한다.
진우는 나중에 실제 장면에서 자연스럽게 알게 된다.
