# AFTERFALL — World Bible v1

Status: AUTHORITATIVE WORLD DESIGN
Runtime dynamic sources: Supabase `saves` + `world_pressures` + `clocks` + `scenes` + `events`

이 문서는 AFTERFALL 세계가 어떻게 작동하는지를 정의한다.
오늘 어느 도로가 막혔는지 같은 현재 사실은 Supabase가 우선하며, 이 문서는 세계의 법칙과 사건 생성 구조를 담당한다.
현재 Pressure 값은 `survival_rpg.world_pressures`가 유일한 runtime source다. 이 문서와 Live Save에 현재 레벨을 복제하지 않는다.

## 1. Worldline identity

AFTERFALL은 《생존일기》 IP의 Chronicle 03, 서진우 연대기의 worldline 이름이다.

주의:
초기 RPG_DESIGN 문서에서 장기 시즌 단계 이름에도 AFTERFALL이라는 표현이 쓰였다.
혼동을 피하기 위해 이 문서에서는:
- AFTERFALL = worldline 이름
- POST-APOCALYPSE / LOCAL ORDER ERA = 국가 기능 붕괴 이후의 시대 단계
로 구분한다.

## 2. Core premise

문명은 한순간 완전히 증발하지 않는다.

전기, 수도, 병원, 행정, 소방, 도로, 화폐, 통신은 서로 다른 속도로 망가지고,
어떤 지역에서는 아직 제복을 입은 사람이 일하는 동안 다른 지역에서는 이미 주민이 자체 규칙을 만든다.

핵심 문장:

문명은 사라지는 것이 아니라 조각난다.

## 3. Macro direction

플레이어가 알고 있는 장기 장르 방향:

1. 정상사회 균열
2. 지역별 패치형 공공질서
3. 유지되는 듯한 국가 기능의 급격한 실효성 붕괴
4. 주민이 체감하는 사실상 무정부
5. 지역별 새 규칙·세력·거래망 형성
6. Post-Apocalypse Local Order Era

정확한 발생일, 직접 촉발사건, 피해명단, 상실거점, 관계결과는 플레이 전에 잠그지 않거나 공개하지 않는다.

## 4. State function model

국가의 법적 존재와 주민에게 국가 기능이 닿는지는 별개다.

### Stage 0 — FUNCTIONAL
중앙명령, 통신, 보급, 인력이 연결됨.

### Stage 1 — STRAINED BUT COORDINATED
서비스가 느려지고 축소되지만 지휘와 보급이 아직 이어짐.

### Stage 2 — PATCHWORK LOCAL RESPONSE
현장 공무원·소방·의료인·시설인력이 지역별 임기응변으로 기능을 유지.
중앙 복구보다 현장 패치가 중요해짐.

### Stage 3 — BRITTLE RELAY DEPENDENT
몇 명의 사람, 한 개의 무전망, 제한 연료, 특정 시설에 공공기능이 매달림.
겉으로는 유지되지만 작은 연쇄실패가 전체 기능을 끊을 수 있음.

### Stage 4 — DE FACTO UNAVAILABLE
국가가 공식 소멸했다고 확인되지 않아도 주민 입장에서는 전화할 곳, 출동할 곳, 보급받을 곳이 없음.

무정부는 국가명 삭제가 아니라 Stage 4를 생활자가 체감하는 상태다.

## 5. Collapse rule

정부 기능 붕괴는 플레이어 체감상 급작스러울 수 있다.
하지만 작가/GM 관점에서는 반드시 이전부터 취약점이 누적되어 있어야 한다.

가능한 누적축:
- 통신 릴레이
- 연료·수송
- 광역전력 재기동
- 현장인력 피로·이탈
- 행정지휘 연결
- 병원·소방의 소모품
- 대규모 이동인구
- 지역 통제권 충돌

단 하나의 마법 스위치로 전국이 동시에 OFF 되는 식으로 만들지 않는다.

## 6. Pressure Engine

세계는 사건 목록보다 압력으로 움직인다.

각 Track:
- 0 STABLE
- 1 UNEASY
- 2 PRESSURE
- 3 SEVERE
- 4 FAILURE

### FOOD
생산, 유통, 저장, 조리연료, 배분.

### WATER
수원, 펌프, 전력, 배관, 소독, 용기.

### POWER
광역망, 로컬발전, 배터리, 부품, 재가압 위험.

### FUEL
수송, 발전, 난방, 농기계, 긴급차량.

### HEALTH
의료인력, 의약품, 이송, 감염, 만성질환, 피로.

### ORDER
경찰·행정의 실행력, 주민규칙, 병목통제, 폭력 억제.

### MIGRATION
피난, 귀가불가, 외곽이동, 거점 소문에 따른 인구흐름.

### TRUST
거래 신뢰, 소유권, 약속, 소문, 지역간 평판.

## 7. Pressure coupling

Pressure는 독립하지 않는다.

- POWER 악화 → WATER / HEALTH / FUEL 압박 가능
- FUEL 악화 → POWER / MIGRATION / FOOD 압박 가능
- WATER 악화 → HEALTH / MIGRATION / ORDER 압박 가능
- MIGRATION 악화 → FOOD / ORDER / TRUST 압박 가능
- ORDER 악화 → TRUST / 거래비용 / 사설권력 압박 가능
- TRUST 악화 → 정보왜곡 / 통행통제 / 폐쇄적 지역주의 증가
- WINTER → FUEL / WATER / HEALTH / FOOD를 동시에 압박

큰 사건은 가능하면 Pressure 2개 이상이 만나서 생긴다.

## 8. Economy

화폐는 하루아침에 사라지지 않는다.
경제는 겹겹이 존재한다.

- CASH
- BARTER
- LABOR EXCHANGE
- RELATIONSHIP CREDIT
- INFORMATION

예:
- 현금이 아직 통하는 거래
- 부품과 식량 교환
- 전기수리와 숙박 교환
- 지난번 도움에 대한 후불 신뢰
- 안전한 도로정보 자체의 가치

어느 하나가 전국 공통 표준이 되지 않는다.

## 9. Information

정보는 자원이다.

등급:
1. DIRECT CONFIRMED
2. TRUSTED REPORT
3. MULTI-SOURCE REPORT
4. RUMOR
5. INFERENCE

사실과 사람들이 믿는 이야기를 분리한다.

예:
- 사실: 농업시설에 관정이 있음
- 소문: 북쪽 농장에는 물이 무한대로 나옴
- 왜곡: 거기에는 식량도 산더미임

소문은 그 자체로 이동, 공포, 욕망, 공격, 거래를 일으킬 수 있다.

## 10. Violence

폭력은 가능하지만 값싸지 않다.

비용:
- 부상
- 의료품 소모
- 노동력 손실
- 보복
- 거래망 단절
- 평판 악화
- 내부 권력 강화

따라서 대부분의 평범한 집단은:
협상 → 경고 → 거래 → 우회 → 제한강제 → 폭력
순으로 내려가는 것이 자연스럽다.

모든 적대 집단을 총 든 약탈자로 만들지 않는다.

## 11. Local order

국가 기능이 약해질수록 지역마다 다른 질서가 생긴다.

가능한 원형:
- 주민회의형
- 공공기관 잔존형
- 기술자·전문가 중심형
- 농업공동체형
- 상인·교환지 중심형
- 자경단형
- 강한 개인지도자형
- 종교·신념공동체형

각 집단은 선/악 대신 다음으로 설계한다.

- 원하는 것
- 가진 것
- 부족한 것
- 두려운 것
- 절대 양보하지 않는 것
- 선을 넘는 조건

## 12. Local customs

지역마다 관습이 생긴다.

예:
- 외부인 보증인 필요
- 무기는 입구 보관
- 노동 2시간 = 하루 체류
- 응급의료인은 우선통과
- 야간 외부인 출입금지
- 차량은 현물기여, 도보는 무료

관습은 법과 다르며 상황·지도자·사건에 따라 변한다.

## 13. Power formation

지역 권력은 처음부터 악당일 필요가 없다.

전형적 변화:

선의 → 필요 → 규칙 → 반복운영 → 권한 → 권력

도로를 치우는 사람,
물을 배분하는 사람,
발전기를 고치는 사람,
의료를 제공하는 사람은
의도하지 않아도 권력을 얻을 수 있다.

핵심은 그 권력이:
- 합의받는가
- 공개되는가
- 견제되는가
- 떠날 자유를 인정하는가
이다.

## 14. Expertise

붕괴가 깊어질수록 전문기술의 가치가 상승한다.

대표:
- 의료
- 전기
- 발전기
- 배관
- 농업
- 차량정비
- 운전
- 단체조리
- 위생
- 기록·배분
- 무전·정보

전문가의 가치 상승은 보상만 만들지 않는다.
의존, 강제영입, 과로, 특혜, 정치적 책임도 만든다.

## 15. Winter

겨울은 날씨 이벤트가 아니라 시스템 공격이다.

동시에 흔드는 것:
- 난방
- 연료
- 배관
- 급수
- 건조
- 위생
- 세탁
- 수면
- 호흡기질환
- 감염
- 조리
- 이동
- 온실

온도 하락 하나가 여러 Pressure Track을 동시에 움직일 수 있다.

## 16. Reputation

평판은 단일 숫자가 아니다.

같은 인물도:
- 의원에서는 신뢰 가능한 의료협력자
- 어떤 주민에게는 자원 위치를 숨기는 사람
- 다른 기술자에게는 거래조건을 지키는 사람
일 수 있다.

집단별 Reputation을 다르게 본다.

## 17. No-free-answer rule

모든 중요한 선택에는 비용이 있어야 한다.

예:
- 물을 준다 → 생명을 돕지만 방문자가 증가할 수 있음
- 물을 거부한다 → 자원은 지키지만 적대·평판비용 발생
- 사람을 받는다 → 노동력과 정보 증가 / 소비와 보안부담 증가
- 거점을 숨긴다 → 안전 증가 / 영향력·정보 감소

정답을 없애는 것이 아니라 무료 정답을 없앤다.

## 18. Player preparation rule

진우 일행의 준비는 반드시 실제 효과가 있어야 한다.

좋은 준비:
- 피해 감소
- 철수시간 증가
- 선택지 증가
- 사람을 구할 여유
- 협상력
을 만든다.

그러나 지역·국가 규모의 거시 붕괴 자체를 플레이어가 최적해 하나로 취소하지는 못한다.

## 19. Scenario generation rule

Major scene 기본식:

2+ WORLD PRESSURES
+ 1 NPC INTERNAL CONFLICT
+ 1 RELATIONSHIP / REPUTATION CONSEQUENCE
+ NO FREE OPTIMAL SOLUTION

피한다:
- 무작위 약탈자 반복
- 준비를 무효화하는 억지 손실
- 한 사건 해결 = 세계 영구안정
- NPC를 기능 담당자로만 소비
- 같은 파밍 루프 반복

선호:
- 공공기능의 마지막 관성
- 권한 공백
- 지역규칙 충돌
- 소문과 실제의 차이
- 전문가 가치와 부담
- 살아남을 수 있는 곳이 알려졌을 때 생기는 사회압력

## 20. Spoiler boundary

공개 가능한 것:
- 세계의 기본 법칙
- 장기 장르 방향
- 이미 확인된 현재상태
- 플레이 원칙

GM-only:
- 정확한 다음 사건
- 발생순서
- 구체 피해
- 누가 다치거나 죽는지
- 어떤 관계가 깨지거나 생기는지
- 거점 상실 여부
- 재난의 최종 메커니즘과 시점
