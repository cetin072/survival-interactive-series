# AFTERFALL / 생존일기 — Visual Reference Notes

## Reference — Pastoral Fantasy Settlement

Source context: user-provided visual reference, 2026-09-23.

### Why it was saved
포스트아포칼립스 장면이 아니라도 사용자가 강하게 선호하는 시각적 정서의 참고자료.
한적한 판타지 농촌·산악 정착지의 생활감과 광활한 세계감을 보여준다.

### Visual DNA
- 거대한 자연 풍경 속 작은 인간
- 밝은 청색 하늘과 거대한 적운
- 초록의 초원·농경지·산악 지형
- 돌담, 흙길, 목조/석조 주택, 초가지붕
- 가축·밭·연기 등 실제 사람이 살아가는 생활 흔적
- 과장된 왕궁/마법보다 소박한 정착지와 일상
- 인물 클로즈업보다 '이 세계 안에서 살아보고 싶다'는 환경 중심 구도
- 평온함, 탐험 욕구, 귀환하고 싶은 장소의 감정
- 아름다움과 실용적 생활권이 동시에 존재

### Cross-genre relevance
이 레퍼런스는 판타지 전용으로 제한하지 않는다.
《생존일기》의 장기 미술 방향에서 다음과 같이 변주 가능하다.

- 포스트아포칼립스 장기 정착지
- 자연이 회복된 옛 문명 지역
- 농업·축산이 복구된 자급 거점
- 폐허를 재료로 다시 만든 마을
- 생존 단계를 넘어 '살 만한 세계'를 회복한 장면
- 향후 별도 판타지 세계선/작품의 생활형 정착지

### Creative insight
사용자 선호의 중심을 단순히 '포스트아포칼립스'로 한정하지 않는다.
현재까지의 레퍼런스에서 반복적으로 관찰되는 후보 축은:

> **아름답고 거대한 세계 속에서 작은 인간들이 실제 생활권을 만들고 살아가는 감각**

향후 이미지가 더 쌓이면 단일 샘플로 확정하지 말고 공통 패턴을 재분석하여 Visual Bible로 승격한다.

### Guard
