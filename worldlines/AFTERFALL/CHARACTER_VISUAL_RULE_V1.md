# AFTERFALL — Character Visual & Presence Rule v1

Status: **AUTHORITATIVE CHARACTER PRESENTATION RULE**

## 1. 목적
AFTERFALL의 중요 인물은 기능성 NPC가 아니라, 플레이어가 얼굴과 분위기를 기억할 수 있는 사람으로 등장해야 한다.

외모는 장식이 아니다.
- 캐릭터 애착
- 첫인상
- 연애/긴장 가능성
- 파티 기억성
- 장기 IP 시각자산
을 만드는 핵심 정보다.

## 2. 적용 대상
다음 인물은 첫 고해상도 등장 때 외모와 존재감을 자연스럽게 묘사한다.
- 주인공 후보
- 반복 등장 가능성이 높은 주요 인물
- 파티 합류 가능 인물
- 핵심 빌런/경쟁자
- 연애 가능성이 생길 수 있는 인물
- 시즌의 중요한 인간관계를 형성할 인물

일회성 배경인물까지 모두 상세 묘사하지 않는다.

## 3. 최소 외모 앵커
중요 인물은 가능하면 다음 중 4~7개를 첫 등장에 자연스럽게 보여준다.
- 대략적 나이 인상
- 키
- 체형
- 얼굴형/눈매/입매 등 얼굴의 핵심 특징
- 머리
- 피부/손/상처/생활 흔적
- 옷차림과 스타일
- 목소리
- 표정
- 걸음/자세/시선
- 한두 개의 기억나는 특징

설정집처럼 나열하지 않고 장면 안에서 보여준다.

## 4. 매력의 다양성
주요 인물을 모두 같은 미형으로 만들지 않는다.

매력은 서로 다른 축을 가진다.
예:
- 세련됨
- 건강함/운동한 체형
- 귀여운 인상
- 차갑고 선명한 인상
- 성숙함
- 관능적 분위기
- 거친 야성
- 평범해 보이나 웃을 때 강한 매력
- 지적/전문적인 분위기

플레이어가 각 인물을 구분해 기억할 수 있어야 한다.

## 5. 성별/몰입 대응
현재 AFTERFALL 기본 주인공은 남성이다.
따라서 주요 여성 인물, 특히 관계 가능성이 높은 인물은 외모와 첫인상을 흐릿하게 처리하지 않는다.

향후 여성 주인공 또는 다른 플레이 시점이 생기면 같은 원칙을 반대로 적용한다.
즉 플레이어가 몰입·관심을 가질 수 있는 주요 상대 성별 인물의 외모를 충분히 보여준다.

단, 같은 성별 중요 인물도 외모/분위기를 적절히 묘사한다. 외모 규칙은 연애 후보만을 위한 것이 아니다.

## 6. 외모와 연애는 분리
외모가 매력적이라고 자동 연애 후보가 되거나 주인공에게 호감을 갖지 않는다.

각 인물은 독립적으로:
- 기존 연애관계
- 성적/정서적 취향
- 현재 관심 대상
- 주인공에 대한 호감/반감/무관심
- 장기 가치관
을 가진다.

외모는 관심과 몰입의 재료다.
관계는 플레이로 만들어진다.

## 7. Canon 고정
중요 인물의 첫 고해상도 외모가 확정되면 이후 Canon으로 유지한다.

이유 없이 변경 금지:
- 키/체형
- 머리색·기본 스타일
- 얼굴 핵심 특징
- 목소리 인상
- 반복되는 버릇/자세

변화 가능:
- 체중 증감
- 머리 길이 변화
- 흉터
- 부상
- 노화
- 장비/복장
- 위생/생활상태

변화는 사건과 시간의 결과여야 한다.

## 8. 세이브
반복 등장하는 중요 인물은 공개 Save의 character/party entry에 필요 최소한의 `appearance_anchor`를 저장한다.

권장 구조:
```json
{
  "appearance_anchor": {
    "apparent_age": "30대 중반",
    "height": "큰 편",
    "build": "마른 근육질",
    "face": "긴 눈매와 선명한 턱선",
    "hair": "검은 머리, 평소 낮게 묶음",
    "voice": "낮고 또렷함",
    "distinctive": ["왼쪽 눈썹 위 작은 흉터"]
  },
  "presence": ["차분함", "단단함"]
}
```

정확한 수치가 플레이에 필요하지 않으면 숫자로 만들지 않는다.

## 9. 첫 등장 품질 Gate
중요 인물이 처음 등장했는데 플레이어 머릿속에 그림이 전혀 생기지 않는다면 실패다.

다만 외모 묘사만 길게 늘여 장면 속도를 죽이지 않는다.
기본 목표는 **2~5문장 안에서 기억 가능한 사람을 만드는 것**이다.

## 10. Existing character visual backfill

새 인물만 대상이 아니다. 이미 반복 등장하는 인물이라도
`survival_rpg.characters.known_facts.appearance_anchor`가 없다면, 다음 의미 있는
high-resolution 재등장을 visual backfill 기회로 사용한다.

- 현재 장면에 이미 로드된 인물만 판단한다. 전 인물 목록을 매 turn 감사하지 않는다.
- 얼굴·체형·머리·옷·목소리·분위기·기억나는 특징 중 장면에 자연스러운 2~5문장만
  보여준다.
- 장면 뒤 해당 인물 카드에 `appearance_anchor`와 필요한 `presence`만 저장한다.
- 이미 확정된 baseline(키/체형/얼굴/머리/특징)은 사건·시간의 이유 없이 다시 만들거나
  바꾸지 않는다. 부상·흉터·노화·위생·장비·헤어 변화는 `visual_changes`로 남긴다.
- Archive publication은 04:30 batch에서 이 PLAYER_SAFE anchor를 정적 snapshot으로
  반영한다. visual backfill은 live turn에 Archive/GitHub/Netlify 호출을 추가하지 않는다.
