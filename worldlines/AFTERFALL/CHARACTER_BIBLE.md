# AFTERFALL — Character Bible v1

Status: AUTHORITATIVE CHARACTER DESIGN
Runtime structured source: Supabase AFTERFALL state.character_bible

이 문서는 반복 NPC를 기능 담당자로 납작하게 쓰지 않기 위한 장기 정본이다.
현재 위치·부상·일시적 감정·최근 사건은 Supabase Save/Event가 우선한다.

## 1. Player character — 서진우

서진우는 플레이어가 직접 결정하는 주인공이다.

고정 가능:
- 이름 / 나이 / 직업 / 외형
- 실제 플레이에서 이미 선택한 행동
- 플레이 결과 형성된 관계와 평판
- 객관적으로 획득한 기술·물자·상태

GM이 선결정하지 않음:
- 고정 성격
- 도덕관
- 정치관
- 연애성향
- 타인을 향한 호감·혐오
- 특정 상황에서 반드시 해야 하는 행동

핵심: PLAYER AUTHORED. NPC trait 시스템을 진우에게 강제하지 않는다.

## 2. NPC Character Engine

행동 공식:

DESIRE + FEAR + CONTRADICTION + ACTIVE TRAITS + RELATIONSHIP LENS + CURRENT PRESSURE → BEHAVIOR

### Active Trait slots
- CORE: Strength 3 / Shadow 2를 기본 화면으로 사용
- MAJOR RECURRING: Strength 2~3 / Shadow 1~2
- RECURRING: Strength 2~3 / Shadow 1~2
- BACKGROUND: Strength 1 / Shadow 1

숫자는 캐릭터의 전체 인격이 아니라 GM이 현재 플레이에서 놓치지 않을 활성 슬롯이다.
장기 경험·상처·좋은 관계·실패에 따라 교체·완화·강화될 수 있다.

### Shadow
Shadow는 악한 성격이나 단순 페널티가 아니다.
강점·욕구·습관이 압박 속에서 지나치게 작동할 때 생기는 비용이다.

### Stress
압박이 커질수록 평상시 성격보다 Stress Response와 Shadow의 영향력이 커진다.
모든 Shadow를 매 장면 강제 발동하지 않는다.

## 4. Core characters

### 윤서진 — CORE
Role: 응급의학과 전공의

Desire:
- 자신이 책임지는 환자와 동료를 의료적 실수로 잃지 않는 것.

Fear:
- 살릴 수 있었던 사람을 자신의 판단 실수로 놓치는 것.

Contradiction:
- 누구보다 사람을 살리려 하지만 모두를 살릴 수 없다는 사실도 누구보다 잘 안다.

Strength:
- 침착함
- 임상판단
- 책임감

Shadow:
- 완벽주의
- 자기희생

Stress:
- 환자와 업무가 몰리면 휴식과 식사를 미루고 한 명만 더를 반복한다.
- 압박이 커질수록 말은 더 짧고 정확해진다.

Boundary:
- 서열·체면·거래대가 때문에 응급 우선순위를 왜곡하는 것.

Tells:
- 고민할 때 왼쪽 귀 뒤로 머리를 넘긴다.
- 불안할수록 설명이 짧고 명확해진다.

Relationship lens:
- 진우: 현장감각을 신뢰하지만 무리하면 가장 먼저 제동을 건다.
- 은채: 운영능력을 신뢰하되 의료판단이 규칙에 종속되는 것은 경계한다.
- 태훈: 기술영역은 맡길 수 있는 실무자.

### 최은채 — CORE
Role: 병원 행정직 출신 / 물류·기록·접근권·관계경계

Desire:
- 무질서와 특혜 때문에 사람이 다치는 상황을 막는 것.

Fear:
- 작은 예외가 누적돼 공동체 전체 기준이 무너지는 것.

Contradiction:
- 질서를 만들고 싶지만 자신이 사람을 통제하는 권력자가 되는 것은 원하지 않는다.

Strength:
- 계획성
- 기록습관
- 조직운영

Shadow:
- 통제욕
- 불확실성 과민

Stress:
- 상황이 통제되지 않을수록 규칙·명단·확인절차를 늘리고 이미 확인한 기록도 다시 본다.

Boundary:
- 기록되지 않은 특혜와 사람에 따라 달라지는 배분기준.

Tells:
- 불안하면 이미 정리한 장부를 다시 확인한다.
- 생각이 많아질수록 안경 위치를 바로잡는다.

Relationship lens:
- 진우: 현장판단은 신뢰하지만 즉흥 약속이 공동체 책임으로 번지는 것을 경계.
- 서진: 의료판단의 독립성은 존중하되 자원 사용은 기록되어야 한다고 봄.
- 태훈: 가장 믿을 만한 실행자 중 하나지만 현장과 규칙이 충돌하면 부딪힐 수 있음.

### 장태훈 — CORE
Role: 시설운영 기술자

Desire:
- 자신이 맡은 설비가 사람을 죽이는 원인이 되지 않게 하는 것.

Fear:
- 막을 수 있었던 시설사고가 무리한 운전이나 자신의 오판 때문에 발생하는 것.

Contradiction:
- 사람을 지키기 위해 설비를 지키지만 그 과정에서 사람에게 냉정해 보일 수 있다.

Strength:
- 현실감각
- 손재주
- 위험감지

Shadow:
- 고집
- 감정표현 미숙

Stress:
- 위험이 커질수록 설명을 줄이고 단정적인 안 돼가 늘어난다.
- 설비를 포기해야 하는 순간에도 마지막으로 한 번 더 확인하려 한다.

Boundary:
- 보호회로 우회, 무지한 통전, 체면 때문에 핵심설비를 위험하게 운전하는 것.

Tells:
- 화날수록 말수가 줄어든다.
- 판단 전에 기계 소리·진동을 잠시 듣는다.

Relationship lens:
- 진우: 현장에서 버틸 줄 아는 동료. 기술영역에서 무리하면 바로 막는다.
- 서진: 의료판단을 건드리지 않는 대신 자신의 기술판단도 존중받길 원한다.
- 은채: 규칙 필요성은 인정하지만 문서와 현장이 어긋나면 충돌 가능.

## 5. Major recurring characters

### 신하영 — MAJOR RECURRING
Role: 백운생활관 전 조리·위생 담당 / 현재 공개 생활운영 접점

Desire:
- 누군가에게 소모되지 않으면서 자신의 생활능력이 사람들에게 실제 도움이 되는 삶.

Fear:
- 다시 모두가 당연히 기대는 해주는 사람이 되어 책임과 비난을 혼자 떠안는 것.

Contradiction:
- 남을 먹이고 돌보는 데 보람을 느끼지만 그 역할에 갇히는 것은 강하게 거부한다.

Strength:
- 생활력
- 책임감
- 행동력

Shadow:
- 도움을 요청하지 못함
- 책임을 혼자 떠안음

Stress:
- 일이 몰리면 도움을 거절하고 혼자 처리하려 하며 말이 날카로워진다.
- 작업속도는 빨라지지만 피로를 숨긴다.

Boundary:
- 조리·위생 노동을 당연한 역할이나 무료봉사로 취급하거나 실패 책임을 떠넘기는 것.

Tells:
- 짜증날수록 손질·정리 속도가 빨라진다.
- 진짜 웃을 때 한쪽 볼에 얕은 보조개가 드러난다.
- 피곤할수록 목소리가 낮아진다.

Relationship lens:
- 최유진: 가장 가까운 생활 동료. 보호하려다 유진 대신 답해버릴 수 있다.
- 진우: 강제영입·백운정보 요구를 하지 않았다는 점에서 조심스럽게 신뢰가 쌓이는 중.
- 서진: 전문성을 존중하지만 자기 몸을 혹사하는지 볼 수 있다.
- 은채: 운영능력은 인정하나 생활노동을 규칙만으로 보면 충돌 가능.
- 태훈: 실제 손을 쓰는 사람이라는 점은 편하지만 둘 다 직설적이라 작은 충돌 가능.

- Fear: 자신이 포기하면 공공기능이 완전히 끊기는 것.
- Contradiction: 시스템이 죽어가는 걸 알면서도 공공책임을 쉽게 내려놓지 못함.
- Strength: 원칙준수 / 시설이해 / 공공책임감.
- Shadow: 철수 지연 / 책임 과잉.
- Stress: 주민 압박이 커질수록 더 오래 현장에 남을 수 있음.
- Boundary: 군중을 달래려고 보호회로나 시설안전을 무시하는 것.

### 한지수 — RECURRING
- Desire: 동천교가 실제 지역 통로로 남는 것.
- Fear: 병목이 무질서해져 다리가 닫히는 것.
- Contradiction: 규칙이 모두를 살리지만 규칙 때문에 예외를 놓칠 수 있음.
- Strength: 현장조정 / 공정성 / 응급우선 판단.
- Shadow: 절차 경직 / 지역우선 사고.
- Stress: 사람이 몰리면 차선을 더 강하게 통제하고 예외를 줄임.
- Boundary: 응급차선·긴급면제 악용, 무단 과적통과.

### 오세훈 — RECURRING
- Desire: 모르는 것은 모른다고 말하면서 설비를 안전하게 유지.
- Fear: 추측으로 손댄 전기·기계가 연쇄고장을 만드는 것.
- Contradiction: 신중해서 믿을 수 있지만 급박한 상황에서는 느림으로 보일 수 있음.
- Strength: 신중함 / 기술정확성 / 한계 인정.
- Shadow: 과도한 신중함 / 설명 부족.

### 김도윤 — RECURRING
- Desire: 자기 노동과 자기 몫이 흐려지지 않는 공정한 협력.
- Fear: 공동체라는 이름으로 개인 물건과 결정권이 흡수되는 것.
- Contradiction: 협력은 필요하지만 소유경계가 먼저 정리돼야 신뢰함.
- Strength: 현실감각 / 현장적응 / 꾸준한 실무.
- Shadow: 소유권 민감 / 외부인 경계.

### 배철수 — RECURRING
- Desire: 어느 집단에도 묶이지 않고 이동과 거래로 생존.
- Fear: 거래 상대에게 속거나 한곳에 붙잡히는 것.
- Contradiction: 호의의 가치를 알지만 대부분의 관계를 먼저 거래조건으로 환산.
- Strength: 협상감각 / 물건가치 판단 / 외곽 현장감.
- Shadow: 거래적 사고 / 의심 많음.

### 박재민 — RECURRING
- Desire: 배철수 보조가 아니라 자기 몫을 하는 동료로 인정받는 것.
- Fear: 자신의 실수로 동행이나 거래 전체를 망치는 것.
- Contradiction: 조심성이 있지만 인정받고 싶어 너무 빨리 나설 수 있음.
- Strength: 순발력 / 길·창고 기억 / 적응력.
- Shadow: 경험부족 / 인정욕구.

## 7. Scene checklist

반복 NPC가 장면에 나오기 전 최소 확인:

1. 이 인물의 Desire는 무엇인가.
2. 이 인물이 지금 두려워하는 것은 무엇인가.
3. 현재 World Pressure가 Shadow를 자극하는가.
4. 상대 인물에 대한 Relationship Lens가 있는가.
5. 기능 설명만 하는 대사가 되지 않았는가.
6. Tell 또는 습관을 필요한 순간에만 자연스럽게 사용할 수 있는가.
7. 미래 관계 결과를 미리 정해놓지 않았는가.

## 8. Off-screen autonomy

NPC는 진우가 보지 않는 곳에서도:
- 친해질 수 있음
- 멀어질 수 있음
- 다툴 수 있음
- 화해할 수 있음
- 호감·연애감정·질투가 생길 수 있음
- 자기 목표를 위해 독립행동 가능

단:
- 자동 커플 금지
- 자동 배신 금지
- 자동 영입 금지
- 확정 사망·확정 관계결과 사전잠금 금지

큰 변화는 플레이어가 나중에 장면·대화·분위기·결과로 발견한다.

## 9. New NPC gate

새 전문가 NPC를 만들기 전에:
1. known_characters 확인
2. 이 Character Bible의 기존 전문영역 확인
3. 기존 인물로 사건을 만들 수 없는 이유 확인

역할만 겹치는 NPC는 만들지 않는다.
새 인물은 새로운 인간관계·가치관·지역·권력·전문성 중 최소 하나를 실제로 확장해야 한다.
