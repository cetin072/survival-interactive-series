# 《생존일기》 AFTERFALL — RPG Design v1

Status: **AUTHORITATIVE DESIGN BASELINE**

## 1. 정체성
AFTERFALL은 《생존일기》 IP 안의 독립 주인공 연대기다.
박도현 STRONGHOLD 및 가족 Canon v2와 현재상태를 공유하지 않는다.
향후 같은 세계관 연결은 가능하지만, 시작부터 크로스오버를 강제하지 않는다.

핵심 판타지:
> 평범한 현대사회에서 제한된 선택지를 갖던 남자가 문명의 붕괴를 통과하고, 포스트아포칼립스에서 사람·장비·거점·세력을 하나씩 얻어 새 질서의 플레이어로 성장한다.

## 2. 주인공 시작 원칙
- 남성.
- 대략 30~40대 범위. 구체 나이는 캐릭터 생성에서 확정.
- **자녀 없음.** 어린아이는 이후 파티 합류 가능하지만 시작 부담으로 두지 않는다.
- 시작부터 거부나 재산이 많은 성공자가 아니다.
- 완전 무능/극빈도 아니다. 옛 사회에서도 쓸모가 분명한 **실전 능력 하나**는 가진다.
- 자산·인맥·권력은 제한적이며, 신세계의 상승은 플레이로 획득한다.
- 정확한 직업/이름/연애상태/성격은 첫 플레이의 빠른 캐릭터 생성에서 확정한다.

## 3. 솔로 플레이와 관계 지연 생성
- 기본 주인공은 독립적인 1인 가구다.
- 현재 배우자·연인·자녀·동거인은 없다.
- 부모·형제 및 과거 인간관계는 플레이어가 먼저 언급하거나 명시적으로 확정하기 전까지 UNDEFINED로 둔다.
- 관계를 만들 때도 그 존재를 플레이어의 걱정·의무·충성·구조 의지로 확대 해석하지 않는다.
- 연락, 귀가, 구조, 합류는 플레이어가 선택할 행동이며 GM이 관계명을 근거로 자동 결정하지 않는다.
- 관계 사건은 선택 가능한 hook으로만 제시하며, 무시·거절·이탈·단절도 정상적인 플레이 결과다.
- 솔로 플레이에서는 관계 NPC가 메인 목표나 이동 목적지를 자동 생성하지 않는다.
- 플레이어가 새 관계를 언급하면 그 시점에 필요한 최소 정보만 지연 생성한다.
- 핵심 원칙: **NPC relationship ≠ player motivation.**

## 4. 장기 6시즌 방향
정확한 재난 종류와 사건은 블라인드다. 다만 장기 플레이 판은 다음 방향을 가진다.

### S1 — 균열
정상사회가 흔들리기 시작한다.
주동사: 개인 생존 / 이동 / 즉시 판단 / 첫 장비.

### S2 — 붕괴
물류·치안·기관 기능이 빠르게 약화된다.
주동사: 사람 선택 / 합류 / 이탈 / 이동수단 / 제한된 파티 형성.

### S3 — 구세계의 끝
기존 질서가 돌아오지 않을 가능성이 확정적으로 커진다.
주동사: 무엇을 버리고 무엇을 들고 새 세계로 넘어갈 것인가.
거점과 장기 팀의 씨앗이 생길 수 있다.

### S4 — AFTERFALL
아포칼립스의 직접 충격 이후 무너진 사회에서 바닥부터 다시 만든다.
주동사: 파티 / 거점 / 생산 / 방어 / 지역 경쟁.

### S5 — 세력
다른 집단과 거래·충돌·흡수·동맹한다.
주동사: 세력 성장 / 외교 / 전투 / 인재 영입 / 영역.

### S6 — 신질서
생존자가 아니라 새로운 질서의 플레이어가 된다.
주동사: 대세력 경쟁 / 제도 / 후계 / 질서 선택.

시즌 번호가 결과를 보장하지 않는다. 상황에 따라 사망·상실·퇴행·시즌 조기 종료도 가능하다.

## 5. RPG 성장 레이어
초기부터 모든 시스템을 열지 않는다.

- S1 중심: **BODY / GEAR / SUPPLIES**
- S2 중심: **PARTY** 활성화
- S3~S4 중심: **BASE** 활성화
- S5~S6 중심: **FACTION / POWER** 활성화

클래스는 시작 시 고정하지 않는다.
플레이 선택의 누적으로 전투형, 탐색형, 협상형, 기술형, 리더형 등 성향이 형성된다.

## 6. 가장 큰 보상
보상 우선순위:
1. 살아남음
2. 쓸 만한 장비와 이동수단
3. 믿을 수 있는 사람
4. 자기 거점
5. 자기 세력
6. 새로운 세계에서의 선택권과 영향력

좋은 NPC는 자동 동료가 아니다.
각 인물은 자기 욕망·가족·두려움·야망·약점·거절 이유를 가진다.

## 7. 사이다와 빌런
사이다물의 상승감은 적극 허용한다.
단, 치트성 무상보상으로 만들지 않는다.

빌런/경쟁자 스케일 예:
- S1: 개인형 악인/기존 권위
- S2: 소규모 폭력집단·자원 독점자
- S3: 붕괴기관·민병대·잔존 권력과의 가치충돌
- S4: 포스트아포칼립스 독재자/약탈세력
- S5: 주인공만큼 유능한 경쟁 세력 리더
- S6: 대형 세력과 신질서 경쟁

승리는 살해만 뜻하지 않는다.
추방, 굴복, 흡수, 거래, 배신 유도, 권력 상실 등도 가능하다.

## 8. 연애 / 성인 대리만족
- 성인 간 연애·성적 긴장·복수의 관계 가능성을 막지 않는다.
- 시작부터 행복한 기혼+자녀 구조를 강제하지 않는다.
- 자동 하렘이나 자동 연애 성공은 금지.
- 매력, 지위, 관계 선택권도 성장 보상의 일부가 될 수 있다.
- 관계는 NPC 자율성과 후속 결과를 가진다.
- 한 명의 장기 연인, 짧은 관계, 정치적 관계, 실패한 사랑 등 다양한 결과 가능.

## 9. 선택 리듬
- 한 번의 중요한 플레이어 결정 뒤 **보통 4~6개의 의미 있는 스토리 비트**를 GM이 자율 진행한 뒤 다음 전략적 Choice Gate로 돌아온다.
- 계속 운전, 약속한 전화, 안전한 주차, 평범한 정비 같은 루틴은 반복 선택으로 묻지 않는다.
- 선택은 안전 / 시간 / 자원 / 사람 / 관계 / 자산 / 정보 / 권력 중 실제 하나 이상을 가른다.
- 복수선택은 가능하지만 시간·거리·사람·자원 때문에 모두 성공을 보장하지 않는다.
- 자유행동은 항상 허용한다.

## 10. 난이도
환경 자체는 가혹할 수 있다.
플레이어를 괴롭히기 위한 임의 실패는 금지한다.
준비와 좋은 선택은 실제 보상을 주되 플롯 면역을 주지 않는다.

패배 가능:
- 장비/차량/거점 상실
- 파티 이탈/배신/사망
- 부상
- 관계 파탄
- 세력 패배
- 주인공 사망

가능하면 fail-forward를 우선하지만, 모든 실패를 무효화하지 않는다.

## 11. 재난 설계
사용자는 장기적으로 S1~S3에서 문명 붕괴를 체험하고 S4 이후 포스트아포칼립스를 원한다.
그러나 정확한 재난 원인·첫 사건·연쇄 피해·규모 상승 방식은 플레이 전에 공개하지 않는다.
World Seed는 세계의 외생조건을 잠그되 정답 루트와 확정 엔딩을 만들지 않는다.

## 12. 표현
- MUD + 인터랙티브 드라마 + RPG.
- 장면이 주인공이고 HUD는 보조다.
- 아이템/파티/퀘스트/거점/세력 변화가 있을 때 짧은 RPG Change Log를 노출한다.
- 모든 수치를 매 턴 보여주지 않는다.
- 게임 중 제작 메타나 데이터베이스 설명을 노출하지 않는다.

## 13. 제품화 원칙
현재 플레이 목적은 **재미 + IP 프로토타이핑**이다.
웹게임을 먼저 만들지 않는다.

현재:
- ChatGPT = GM / NPC / 세계 / 서술 / 판정 / 텍스트 UI
- Supabase = 런타임 세이브
- GitHub = 기획 / RAW / 시즌 아카이브 / IP 장기보존

나중 실제 게임화 시 기존 Thin Engine의 Validator / Action Queue / State-before-Story 설계를 재사용 후보로 삼는다.


## 14. 캐릭터 외모와 존재감
- 중요 인물은 능력/역할만 소개하지 않는다. 첫 고해상도 등장 때 외모·첫인상·목소리·분위기 중 기억 가능한 요소를 자연스럽게 보여준다.
- 주인공 후보 3명도 이름/직업/능력만이 아니라 **외모와 분위기**가 서로 구분되어야 한다.
- 현재 기본 주인공이 남성이므로 주요 여성 인물, 특히 관계 가능성이 생길 수 있는 인물의 외모를 흐릿하게 처리하지 않는다.
- 매력적인 인물의 존재를 회피하지 않되 모두 같은 미형으로 만들지 않는다.
- 외모가 매력적이라는 이유로 자동 연애/자동 호감/자동 파티 합류를 만들지 않는다.
- 중요 인물의 확정 외모는 Canon으로 유지하며 사건·시간에 따른 변화만 허용한다.
- 세부 규칙은 `CHARACTER_VISUAL_RULE_V1.md`를 따른다.


## 15. 플레이 속 생존 지식 — Emergent Survival Learning
- 생존 지식은 별도 강의가 아니라 실제 문제 해결 과정에서 자연스럽게 드러나야 한다.
- 기본 흐름은 **상황 → 플레이어 가설/의문 → 크로스체크 → 선택 → 결과 → 경험 축적**이다.
- NPC는 예스맨이 아니며 플레이어 판단을 전문성·경험·현장정보로 검증한다.
- 조건에 따라 정답이 달라지는 문제를 선호하며, 플레이어가 체득한 원칙은 후속 장면에서 다시 써먹게 한다.
- 미래 판단을 바꾸는 학습은 Supabase events에 맥락을 남기고, 지속 전략은 현재 state에도 짧게 승격한다.
- 대표 검증 사례는 **쌀 vs 감자·고구마의 저장밀도·칼로리·조리연료·물·운용조건 비교**다.
- 상세 규칙과 사례 생성법은 `EMERGENT_SURVIVAL_LEARNING_V1.md`를 따른다.
- 핵심: **재미가 먼저다. 지식은 플레이의 결과로 남는다.**


## 16. 적응형 자원 해상도 — Adaptive Resource Resolution
- 초기 희소성에서는 kcal·L·kg·개수·일일 소모를 정밀하게 다룰 수 있다.
- 팀과 거점 운영이 자리 잡으면 일상 소비와 정상 보급은 자동 수지로 넘긴다.
- 자원 상태는 **SCARCITY → MANAGED → STABLE**로 추상화할 수 있으며 공급망 붕괴나 수요 급증 시 다시 정밀화한다.
- 물·식량·연료·의약품 등은 서로 다른 해상도를 가질 수 있다.
- 플레이어가 해결한 운영 문제를 계속 반복시키지 않는다. **이미 해결한 운영 문제는 자동화하고 새로운 병목만 플레이한다.**
- 성장에 따라 질문의 스케일도 개인 비축 → 팀 운영 → 거점 공급망 → 세력 생산·운송·외교로 상승한다.
- 상세 규칙은 `ADAPTIVE_RESOURCE_RESOLUTION_V1.md`를 따른다.


## 17. 연재형 템포와 사건 상승
- 현실적으로 반복되는 행동이더라도 같은 서사 기능의 장면을 계속 직접 플레이하지 않는다.
- **첫 경험은 장면화 → 반복은 압축 → 안정 뒤에는 새로운 종류의 문제**가 기본 리듬이다.
- 최근 5~8개 중요 사건이 파밍·정비·정기접촉·재고갱신에 편중되면 PACING ESCALATION DUE로 본다.
- 안정이 길어지면 세계가 움직인다. 기존 World Seed와 플레이 결과에서 외생 사건·세력·기관 변화·인구 이동·정보 반전 등을 발생시킨다.
- 큰 사건은 준비를 리셋하기 위한 장치가 아니라 그동안 만든 팀·거점·공급망·정보망을 실제로 시험하는 장치다.
- 하위 생존 문제가 해결되면 개인 → 팀 → 거점 → 지역/세력 → 질서 문제로 선택의 스케일을 올린다.
- 상세 규칙은 `NARRATIVE_PACING_ESCALATION_V1.md`를 따른다.


## 18. Worldline Isolation / Disaster Non-Repetition Guard
- AFTERFALL은 이전 세계선과 **물리적으로 독립된 세계선**으로 유지한다.
- 두 세계선이 실제로 합쳐지거나 충돌하는 설정을 재난 메커니즘으로 사용하지 않는다.
- 시간·공간 뒤틀림, 평행세계 중첩, 차원 균열, 세계선 침범을 핵심 재난으로 사용하지 않는다.
- 이전 세계선의 동일 인물들이 도플갱어·복제·다른 세계선 버전으로 등장하는 장치를 사용하지 않는다.
- 이전 세계선의 Incursion 계열 체험을 이름·색·현상만 바꿔 반복하지 않는다.
- 붉은 하늘, 이상광, 전력 이상 등 개별 시각/환경 모티프가 유사할 수는 있으나 **원인 구조와 플레이 체험까지 이전 세계선의 반복으로 만들지 않는다.**
- 크로스오버가 향후 IP 차원에서 가능하더라도 현재 AFTERFALL 재난의 비밀 원인이나 반전으로 사용하지 않는다. 별도의 명시적 기획 결정 없이는 worldline crossover를 활성화하지 않는다.
- 재난의 구체적 정체는 플레이어에게 스포일러하지 않되, 이 금지 규칙은 GM 내부 가드로 유지한다.


## 19. 불가역적 붕괴와 준비의 한계 — Apocalypse Irreversibility
- 플레이어의 합리적·우수한 대응은 **피해를 줄이고, 사람을 더 살리고, 선택지를 늘리고, 회복 속도를 높이는 보상**을 받아야 한다.
- 그러나 주인공/연합의 좋은 판단이 광역 자연재해·인프라 붕괴·사회 시스템 붕괴 자체를 취소하거나 무력화하는 만능 정답이 되어서는 안 된다.
- 아포칼립스 규모의 외생 충격에서는 **잘 대비해도 무언가는 잃을 수 있다.** 거점 일부, 시설, 공급선, 자산, 관계망, 세력 구성, 부상·사망 등 실질적 손실 가능성을 유지한다.
- 손실은 플레이어를 벌주기 위한 임의 이벤트나 '정답을 골라도 어차피 죽는다'는 고정 대본이 아니다. 현재 위치·노출·준비·환경·NPC 독립행동·재난 규모의 인과로 판정한다.
- 특정 NPC 사망, 특정 거점 파괴, 확정 손실 목록을 미리 대본으로 잠그지 않는다. 대신 **세계 규모의 충격은 플레이어 한 명이 완전히 막을 수 없다**는 원칙을 유지한다.
- 준비가 좋을수록 동일 충격에서 피해의 종류/규모가 달라지고 구조·대피·복구·기사회생의 기회가 커져야 한다.
- 주인공 거점만 공격할 필요는 없다. 연합의 다른 거점·기관·교통축·생산지·외부 세력이 먼저 붕괴할 수 있으며 그 파장이 주인공에게 도달한다.
- 붕괴는 다음 서사의 씨앗이 되어야 한다: 생존자 재편, 합병, 분열, 새로운 연합, 권력 공백, 구조 의무, 이주, 원한, 부채, 예상 밖의 기회 등.
- **세옹지마를 허용한다.** 손실이 장기적으로 새로운 인물·세력·거점·기회를 열 수 있고, 반대로 당장의 성공이 새로운 부담과 갈등을 만들 수 있다.
- 큰 사건 뒤에는 원상복구만 목표로 하지 않는다. 사건 전과 다른 **새로운 정상(new normal)** 을 만든다.
- 핵심: **플레이어는 자기 대응을 잘할 수 있지만 세계 전체를 정답으로 풀 수는 없다.**
